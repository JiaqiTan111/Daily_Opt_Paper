Eventually Optimal and Scalable Multi-Agent Planning for Block Cave Mining

模型细分主题：多智能体路径规划与调度（MAPF）在块状崩落采矿中的应用

模型原始标签：块状崩落采矿、多智能体规划、混合整数线性规划、路径规划、任务分配、调度、可扩展性

研究设定
研究问题为在地下矿山环境中协调自动驾驶车队，最大化矿石运输量，同时满足每个放矿点的放矿比例约束。决策对象为多智能体的任务分配、调度和路径规划。目标函数为最大化矿石吞吐量。关键约束为放矿比例约束（每个放矿点的放矿率需保持在一定范围内且变化缓慢）。信息假设为材料未明确说明，但提及若放矿率更新则视为新问题。环境为动态的矿山环境，但规划为周期性或子循环方式，属于动态环境下的在线规划。
研究动机
地下采矿自动化可提升安全性、效率和可持续性，但协调动态矿山环境中的多自主车队在优化和运动规划方面具有挑战性。现有MAPF方法难以处理工业规模实例。
核心洞察
将任务分配、调度和路径规划整合进单一MILP公式中，方式上实现联合最优，但为了可扩展性，采用子循环分解（SAMMS）牺牲最优性换取效率，通过生成可无缝拼接的子循环，在运行过程中逐步逼近目标放矿率，实现渐近最优。
技术挑战
  • 协调自主车队在动态矿山环境中的复杂性
  • 混合整数线性规划求解的可扩展性问题
  • 实现工业规模实例的求解
问题分析
作者将BCM问题分解为任务分配、调度与路径规划三个子问题，并统一建模为MILP，以捕获它们之间的相互依赖。通过构建状态图表示离散姿态（位置-方向对），转换编码可行运动基元，处理狭窄隧道中的机动。为改进扩展性，提出SAMMS，将长周期分解为若干子循环，每个子循环服务部分放矿点，且起点与终点状态相同可无缝连接，从而在线构建运输计划，证明其渐近可行性并收敛。
方法
  • 将任务分配、调度和路径规划整合为单一混合整数线性规划(MILP),模型状态图（位置-方向对），编码可行运动基元，以单位时间步执行
  • SAMM：形式化BCM问题并建立最终最优的anytime求解器，联合决策任务分配、调度与路径规划
  • SAMMS：分解规划为较短子循环，每个子循环服务放矿点子集，循环间状态一致可拼接，以牺牲最优性换取计算效率
  • 在线构建运输计划：每完成一个子循环，选择新子循环执行，渐近逼近目标放矿率
实验
  • 在7个由真实矿山布局校准的基准场景上评估SAMM和SAMMS，场景复杂度递增；SAMM在场景1-3上获得吞吐量0.89、1.56、1.78，运行时间11.0、49.1、57.8秒；SAMMS吞吐量0.56、0.92、1.10，运行时间0.96、1.69、2.92秒；场景4-7，SAMM在60秒超时未成功，SAMMS吞吐量0.40、0.34、0.59、0.73，运行时间11.28、55.8、13.9、34.0秒
  • 实验比较了SAMM与SAMMS的吞吐量和运行时间，SAMMS始终快一个数量级，且用于现实工业场景
  • 实现使用Python、NetworkX、Gurobi，运行于Intel Core Ultra 9等硬件，代码公开
局限
  • 材料中作者未明确陈述局限性，但SAMMS在场景5和7上各有4/5的成功率，存在失败情况
与你的研究关系
该论文属于多智能体路径规划与调度，与智能优化和生产调度相关。其将任务分配、调度和路径规划整合为MILP的方法，以及分解为子循环的可扩展技术，可迁移到生产调度问题（如柔性作业车间或分布式制造），推测需要将放矿比例约束类似地转化为生产中的比率或节拍约束，并适应更复杂的机器约束和环境动态。论文未涉及神经网络或强化学习，属于传统优化方法，但可作为学习辅助搜索中的优化求解器组件。

模型细分主题：利用大语言模型自动设计调度优先级规则

模型原始标签：RCPSP、优先级规则、大语言模型、自动启发式设计、基于种群的搜索

第一单位：COSMO – Stochastic Mine Planning Laboratory, McGill University

通讯作者：Mario Vanhoucke

首次上传：2026-09

arXiv 摘要 ↗ PDF ↗官方 HTML ↗

研究设定
本研究针对资源受限项目调度问题（RCPSP），目标是最小化项目完成时间（makespan），需满足活动间的时序约束和可再生资源约束。决策对象是调度活动的优先级规则（可执行的优先级函数），用于构建可行调度。环境是静态确定的，规则设计在离线训练项目上进行，最终规则直接应用于未见过的项目。
研究动机
优先级规则启发式方法计算成本低、决策逻辑透明，在实践中广泛使用，但不存在对所有项目都有效的传统规则。自动设计规则的传统方法（如遗传规划）需要评估大量候选规则，成本高；而大语言模型能够生成并迭代改进规则，但用于标准RCPSP的离线规则设计尚缺乏系统研究。
核心洞察
利用大语言模型的先验知识生成候选规则，并通过训练项目上的调度质量反馈进行迭代修订，可以在有限的搜索预算内找到高性能的可复用优先级规则，无需对每个实例进行搜索。
技术挑战
  • 设计有效的LLM生成和修订机制，使得候选规则逐步改进
  • 在合理计算预算内与GP等传统自动设计方法竞争
  • 确保生成的规则在未见项目上的泛化能力
问题分析
作者将问题建模为基于种群的搜索过程，候选规则以统一格式表示，利用调度质量作为适应度，指导LLM进行结构化的规则修订。通过保留精英规则和参考规则，维持种群多样性。
方法
  • LLM生成初始种群：给定调度输入和函数格式，生成多条候选规则
  • 适应度评估：将候选规则应用于训练项目，构建调度并计算makespan作为适应度
  • 迭代修订：根据适应度反馈，LLM对规则进行修改，形成下一代种群，保留部分优秀规则
  • 最终输出：搜索结束后返回最优规则，无需再调用LLM即可应用于新项目
实验
  • 实验比较LLM设计的规则与传统规则和GP设计的规则，结果显示LLM规则在测试集上优于传统规则和同等搜索努力的GP规则，与更大规模GP搜索的规则竞争力相当
  • 在大规模高并行项目上，选定的LLM规则优于所有传统规则和两种GA配置（当每实例评估预算为1,000和5,000时），但差于50,000评估预算的GA
  • 消融研究探讨了主要搜索组件的影响，规则分析描述了LLM设计规则的结构和决策行为
局限
  • LLM设计的规则在所有测试集上不一定一致优于传统规则，例如J30训练的规则在五个测试集上AvgDevLB均低于AllPR，而扩展训练后在某些数据集上才反转
与你的研究关系
本研究与智能优化和调度领域紧密相关，展示了如何将LLM作为搜索机制自动设计可复用的调度优先级规则。这与生产调度中的学习辅助搜索和自动设计方向相似。推测：该方法可迁移到其他调度问题（如流水车间调度）的规则设计，但需要重新定义调度输入、规则格式，并评估计算成本。

本文档仅提供了摘要和部分正文片段，缺少一些关键实验细节，例如具体测试集名称、性能数据等，因此分析可能存在不精确之处。

先问再优化：面向交互式优化的动态预建模澄清

Ask Before You Optimize: Dynamic Pre-Formulation Clarification for Interactive Optimization

Sihan Ge · Yichen Lin · Chenyu Zhou · Jianghao Lin · Tao Yao · Dongdong Ge

研究设定
研究问题为在优化建模前，如何判断并执行必要的需求澄清。决策对象为大语言模型驱动的智能体，其目标是在有限交互中获取完整且正确的优化模型规格，关键约束是公共问题描述不完整，隐藏了结构化槽位，且交互次数有限。信息假设为存在一个模拟用户，可以回答澄清问题；环境是动态的，智能体需决定是继续提问还是停止。
研究动机
大语言模型常被用于从自然语言问题描述中构建优化模型，但现实中的运筹学请求往往不完整，缺少目标、约束或业务规则会改变最终的数学模型。现有评估大多假设规格完整，忽略了智能体在建模前是否知道何时需要澄清，因此需要新的基准和方法来研究这一关键能力。
核心洞察
将优化的辅助从'一次性建模'重新定义为'选择性完备性决策'，即智能体应主动识别建模前遗漏的关键信息，并在必要时提问，在信息足够时停止，同时量化剩余缺失，从而提高最终模型的可靠性。
技术挑战
  • 如何判断问题描述中哪些隐含信息是建模必需的
  • 如何在有限交互中平衡澄清收益与交互成本
  • 如何处理开放式澄清和基于选项的澄清两种模式
  • 如何度量澄清过程的效率，包括槽位恢复率、停止行为、隐含假设和交互成本
问题分析
作者构建了基准OR-Clarify，每个任务提供部分公共问题描述，隐藏结构化槽位，通过模拟用户限制交互来评估智能体。他们提出两阶段框架InterOPT，先识别出未被解决的公式关键差距，再利用这些差距指导下一步行动（提问或停止）。分析侧重于将澄清过程分解为槽位恢复和停止决策，并引入多种度量指标。
方法
  • 构建OR-Clarify基准：包含部分问题描述和隐藏槽位，支持开放式和基于选择的澄清，模拟用户交互
  • 提出InterOPT两阶段框架：第一阶段识别公式关键差距，第二阶段基于差距决定是否提出下一个问题或停止
  • 度量指标包括槽位恢复、停止行为、隐含假设和交互成本
实验
  • 基于选择的实验中，InterOPT在精确槽位恢复上大幅优于所有基线
  • 在开放式设定中，InterOPT与强大的先前方法保持竞争力
局限
