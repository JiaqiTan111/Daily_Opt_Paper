MiLoop：面向神经组合优化的选择性记忆传播

MiLoop: Selective Memory Propagation for Neural Combinatorial Optimization

Changliang Zhou · Yuanyao Chen · Rongsheng Chen · Zhiyun Lin · Zhenkun Wang

核心洞察

构造式rollout本身已经包含多步前向计算，这些计算中的历史表示可以被选择性地传播和复用，而不必在每一步丢弃并从头重建。通过在注意力层之前将当前嵌入与历史记忆融合、在注意力层之后进行自适应门控更新，浅层策略即可获得跨步的表示连续性，从而在保持对当前子问题敏感的同时积累结构信息，替代深层每步重计算。

为什么值得看：论文提出的记忆传播机制为构造式神经求解器提供了一种降低每步重计算开销、同时保持跨尺度泛化的思路，这与生产调度中大规模实例的快速求解需求相关。浅层策略加记忆复用的设计对计算资源受限场景有参考价值。消融实验清晰分离了融合与门控的贡献，方法论上对学习辅助搜索和强化学习求解器的表示设计有借鉴意义。此外，论文在4类COP上验证到千万节点规模，其泛化评估思路对调度问题的跨规模泛化研究有启发。

研究设定
论文研究组合优化问题（COP）的构造式神经求解，决策对象是在每个构造步选择下一个节点或元素以逐步构建可行解，目标是最小化目标函数 f(y|G)，关键约束为解的可行性（y∈Ω(G)），信息假设为仅使用强化学习rollout中产生的解质量反馈而不依赖外部解标签或伪标签，环境为静态的组合优化问题实例（未说明动态扰动），实例规模从100到1000万节点。
研究动机
现有动态嵌入方法在每一步都用深层注意力栈从头重建子问题表示，计算开销大；许多高性能方法依赖解标签或伪标签训练，或在强化学习中进行激进的搜索空间剪枝，限制了适用性和泛化能力。作者希望仅用纯强化学习、不依赖外部标签、不做训练时搜索空间剪枝的前提下，让浅层策略也能学到有效的动态嵌入。
核心洞察
构造式rollout本身已经包含多步前向计算，这些计算中的历史表示可以被选择性地传播和复用，而不必在每一步丢弃并从头重建。通过在注意力层之前将当前嵌入与历史记忆融合、在注意力层之后进行自适应门控更新，浅层策略即可获得跨步的表示连续性，从而在保持对当前子问题敏感的同时积累结构信息，替代深层每步重计算。
技术挑战
  • 如何在浅层策略下获得有效的动态嵌入而不依赖解标签或伪标签
  • 如何在不做训练时搜索空间剪枝的情况下保持强化学习训练效率
  • 如何选择性保留历史信息而不被过时或无关表示干扰
  • 如何在从100到1000万节点的巨大规模范围内保持解质量和泛化能力
问题分析
作者将构造式求解建模为逐步决策过程，把每个rollout的多步前向计算视为可复用的资源。通过对比传统动态嵌入基线在相邻步和首步的嵌入余弦相似度，作者分析了表示在构造过程中的演化特性，指出基线存在较大的相邻步波动、且与首步表示较相似，而MiLoop在相邻步间保持强连续性并随步数形成累积变化。消融实验进一步分离了当前信息融合与门控记忆更新对跨尺度泛化的互补作用。
方法
  • 将COP构造式求解形式化为逐步决策，每步从当前子问题状态选择下一元素，整体以最小化目标函数为目标
  • 在注意力层之前，将当前步嵌入与历史记忆状态进行融合，使策略同时感知当前子问题与历史信息
  • 在注意力层之后，应用自适应门控更新对表示进行选择性保留与更新，更新后的表示既用于当前决策也供后续步复用
  • 采用纯强化学习训练（主实验使用轨迹级比较的DPO式偏好优化，并评估了REINFORCE变体），利用rollout的解质量作为反馈，不使用外部解标签或伪标签，不做训练时搜索空间剪枝
  • 策略网络仅使用三层注意力（浅层策略），依赖记忆传播机制而非深层每步重计算来获得动态嵌入
实验
  • 在TSP、CVRP、PDTSP和KP四类组合优化问题上评估，实例规模从100到1000万节点
  • 在TSP100上MiLoop gap约0.84%-0.88%，TSP1K上约1.90%-2.90%（不同配置），具体数值随消融配置变化
  • 消融表明：仅用RSE无融合无门控时TSP100 gap 0.88%、TSP1K gap 9.17%；仅输入融合时0.84%/1.90%；融合加门控时表现最优（0.84%/1.90%，从节选数据看融合与门控组合为最佳配置）
  • 与Rec-NCO对比：Rec-NCO使用非线性循环状态嵌入加残差连接和两阶段监督学习，MiLoop通过完整RL rollout联合学习浅层策略和记忆，无需外部解标签
  • 注意力深度消融：3层DPO、6层DPO、3层RF等配置对比，融合加门控的3层DPO配置在TSP1K和TSP5K上取得最优或接近最优的gap
  • 使用NVIDIA GeForce RTX 4090 GPU和Intel Xeon Gold 6240R CPU进行实验
  • 节选未提供全部实验的完整数字、训练开销、公平计算预算对比和全部基线细节
局限
  • 作者在结论中指出未来将探索更有效的记忆融合与更新机制以进一步改进渐进式表示复用
  • 作者计划将MiLoop扩展到多任务学习，使单一策略求解不同类型的组合优化问题，暗示当前方法尚未支持多任务统一策略
  • 材料未说明其他明确局限

局部学习覆盖：硬信息视野下的图神经组合优化

Learning to Cover Locally: Graph Neural Combinatorial Optimization under a Hard Information Horizon

Johannes F. Loevenich · Thies Moehlenhof · Laurin Holz · Maxime Schwarzer · Tobias Huerten · Roberto Rigolin F. Lopes

核心洞察

信息视野半径而非模型容量是决定性能的主导变量。在硬信息视野下，深度只能购买计算量而不能扩展可观测半径：L层GNN在决策节点读出时恰好等价于L跳选择器，任何确定性选择器若视野少一跳，则必然要么覆盖失败要么与最优解相差Δ倍。恰好达到2跳视野时，GNN可以精确复现RFC 7181的贪心规则及其(1+ln Δ₂)近似保证，因为2跳球正是协议提供的信息边界。因此，将学习组件置于该视野内的贪心骨架上，仅让网络学习代价感知的排序，就能在加权目标上超越经典局部贪心并维持构造性可行覆盖。

为什么值得看：该论文将信息视野作为核心变量，从理论上澄清了图神经网络深度与可观测半径的区别，并把可行性保障下沉到构造性解码器，这与生产调度中约束可行性优先、公平计算预算和泛化能力的研究关切高度一致。其实验设计包含严格的精确最优基线、视野消融、结构可行性验证和真实网络迁移，可为智能优化研究者提供方法论参考：在局部决策不可撤销且必须组合成全局可行解时，如何分离可行性保证与代价优化，以及如何评估有限信息下学习辅助搜索的真实收益。

研究设定
研究在硬信息视野约束下的组合优化问题：全局目标是一个集合覆盖，但每个节点只能看到自身的k跳邻域并据此独立提交其局部选择，这些局部承诺必须组合成一个全局可行的覆盖。论文形式化为局部集合覆盖，并实例化在加权多点中继（MPR）选择上——这是OLSRv2路由协议（RFC 7181）中NP难的2跳覆盖问题，其视野由协议决定而非模型设计者选择。目标是使所选中继集的代价（如ETX或能量等链路度量）最小化，同时保证2跳邻域全覆盖。决策是每个节点的局部选择，约束是每个2跳邻居必须被至少一个被选中继覆盖，信息假设是每个节点仅能获知其k跳邻域，静态环境（随机几何单位圆盘图与真实营级机动网络）。
研究动机
主流神经组合优化假设集中式求解器能读取整个实例，但在链路状态路由等真实网络中，每个节点只能依据有限视野做出不可撤销的局部选择，且这些选择必须组合成全局可行解。作者以此逆向设定为研究对象，探讨信息视野本身对可学习性与可解质量的根本限制，并利用路由协议提供的真实问题场景验证。
核心洞察
信息视野半径而非模型容量是决定性能的主导变量。在硬信息视野下，深度只能购买计算量而不能扩展可观测半径：L层GNN在决策节点读出时恰好等价于L跳选择器，任何确定性选择器若视野少一跳，则必然要么覆盖失败要么与最优解相差Δ倍。恰好达到2跳视野时，GNN可以精确复现RFC 7181的贪心规则及其(1+ln Δ₂)近似保证，因为2跳球正是协议提供的信息边界。因此，将学习组件置于该视野内的贪心骨架上，仅让网络学习代价感知的排序，就能在加权目标上超越经典局部贪心并维持构造性可行覆盖。
技术挑战
  • 信息视野硬约束下，确定性局部选择器可能因视野不足而无法同时满足覆盖可行性与接近最优。
  • 加权MPR目标上，即使公平的代价有效性贪心也留下明显经验差距，学习策略需在极局部视野内超越手工启发式。
  • 局部承诺必须组合成全局可行覆盖，需要构造性解码器将神经评分转化为保证覆盖的离散决策。
  • 在真实营级机动网络等分布外拓扑上保持泛化能力与100%可行性。
问题分析
作者通过理论分析与实证归因相结合的方式剖析问题。首先将问题形式化为局部集合覆盖，定义局部选择器的视野半径与全局可行性组合条件。随后证明两个理论结果：确定性选择器若视野少一跳，则必然覆盖失败或与最优解相差Δ倍；L层GNN在决策节点读出时恰好是L跳选择器，说明深度不能扩展半径。反过来，在恰好2跳视野下，O(Δ)深度的GNN可复现RFC 7181覆盖贪心，O(c_max Δ)宽度可复现度量感知的加权贪心，并继承(1+ln Δ₂)近似保证。实证上，作者将可行性分析与优化解耦，通过构造性解码器保证100%覆盖，使神经编码器专注于代价优化；并通过消融、泛化与真实网络迁移检查定位视野而非容量为主要变量。
方法
  • 问题形式化：将分布式局部承诺组合问题建模为局部集合覆盖，并实例化为加权MPR选择。
  • 理论边界：证明视野不足一小时的Δ倍最优性差距或不可行性，以及L层GNN等价于L跳选择器的容量-半径关系。
  • 构造性覆盖解码器：将神经评分贪婪地转化为每个节点的中继选择，保证组合后100%覆盖可行性。
  • GATv2编码器：在2跳视野内读取局部拓扑与链路度量，输出代价感知的中继排序。
  • 行为克隆训练：从CP-SAT整数规划最优解中克隆加权MPR决策，避免稀疏奖励与信用分配问题。
  • 模型选择：以解码后的验证集代价比作为选择标准，直接度量部署解码而非代理损失。
实验
  • 实验设置：随机几何单位圆盘图，n个节点均匀分布于单位正方形，半径r内连边，链路带与长度相关的整数度量；加权MPR目标为所选中继面向中心链路度量之和；CP-SAT整数规划求解每个实例至最优，定义cost/opt=1.0。
  • 主要结果：3层GATv2覆盖完成解码器，从CP-SAT最优行为克隆，达到cost/opt=1.030±0.001，贪心为1.138，在100%覆盖率下弥合79.1%的差距。
  • 视野消融：将同一学习器限制为1跳，在相同实例、解码器和示范下，性能坍缩至1.344，远逊于贪心。
  • 消融梯（E1，n=3200测试集）：随机可行1.641，无图MLP（DeepMPR式）1.218，贪心参考1.138，节点摘要代价GNN 1.057，完整GNN 1.029，CP-SAT最优1.000。
  • 结构可行性验证（E2）：解码器包装任意评分生成启发式（包括随机与MLP）均达到完美覆盖比1.0，而原始神经输出独立无法满足覆盖约束。
  • 泛化与迁移（E3）：n=80,r=0.30训练模型应用于n=160时弥合差距从约79%小幅降至约74%；密集网络r=0.46下降至51%，仍显著优于贪心且100%可行。
  • 真实网络迁移：OLSRv2未修改选择代码在200/200单位代价实例上与基数贪心匹配；在40,308个真实营级机动实例上，冻结模型在完全覆盖下弥合48%的差距。
局限
  • 信息视野设定了性能上限，深度只能购买计算量而不能扩展可观测半径。
  • 基数目标下贪心已近最优，改进空间主要在加权目标。
  • 加权优化剩余差距可能对特定架构选择敏感。

研究问题为图上的最小支配集（MDS）问题：给定图 G=(V,E)，求最小的顶点子集 D⊆V，使每个顶点要么属于 D，要么与 D 中某顶点相邻。决策对象是每个顶点是否被选入支配集；目标是最小化支配集规模；约束为覆盖全部顶点。MDS 是 NP 完全问题，并且与集合覆盖的近似困难性（Feige 给出的 (1-o(1))ln n 阈值）紧密相关。应用背景包括社交网络病毒式营销、影响力最大化、公共卫生干预、信息传播等，文中也提到 Positive Influence Dominating Set 变体。信息假设：训练阶段不依赖最优解或真实标签，仅使用图结构；推理阶段使用学习到的节点概率并配合多种解码策略。静态或动态：材料中讨论的图为静态图，未说明动态扰动环境。

研究设定
研究在凸优化问题族上为一阶方法（如步长与动量系数）自动学习超参数的问题：给定一组问题实例数据集，目标是最小化性能估计问题（PEP）的 Wasserstein 分布式鲁棒版本，使学到的算法在样本外实例上具有可证明的鲁棒性。决策对象是超参数（步长、动量系数），关键约束是子问题为半定规划，信息假设为存在有限问题实例数据集，环境为静态（非动态扰动）。
研究动机
经典 L2O 在训练分布上表现好，但样本外鲁棒性无法保证；而 PEP 的最坏情况算法设计过于保守。作者希望在两者之间建立一个连续可调的谱系，用分布式鲁棒刻画分布漂移，从而在学习效率与鲁棒性之间取得平衡。

问题分析
作者利用性能估计问题（PEP）这一凸优化算法分析的精确框架，将其扩展为 Wasserstein 分布式鲁棒版本，从而把分布不确定性显式建模进算法设计的优化目标中。通过分析鲁棒半径对目标函数的影响，作者证明该框架在极限情况下分别回退到经典 L2O 和 PEP 最坏情况设计，并给出高概率泛化界，刻画了样本内 L2O 最优值、样本量与最坏情况 PEP 界之间的关系。
方法
  • 构建 Wasserstein 分布式鲁棒版本的性能估计问题（PEP），决策变量为一阶方法的超参数（步长、动量系数）
