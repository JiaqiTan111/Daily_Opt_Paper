研究设定
研究问题为多车道道路上自车与多个反应型对手车辆交互的规划控制；决策对象包括整数型机动决策（换道与安全区域选择）和连续运动量，目标是在场景树采样下兼顾跟踪性能与对隐藏对手参数的不确定性削减，关键约束为混合整数非线性规划(16)及其安全/交互约束，信息假设为对手行为由隐藏参数驱动的多模态不确定性、场景树采样其可能交互，环境为动态闭环仿真中的交互式驾驶。
研究动机
对偶MPC可通过信息寻求动作减少对手行为不确定性，但其自动驾驶应用此前局限于单车道单一对手；扩展到多车道多反应型对手后，混合整数非线性规划的求解代价随交互复杂度急剧上升，需要降低计算负担以保持可实时性。
核心洞察
整数机动决策（如换道、安全区域选择）刻画了交互的组合结构，且同一场景会反复求解结构相似的问题实例；用GNN从图结构中学习最优整数决策的分布、固定高置信度决策，可在几乎不损失最优性的前提下显著缩小分支定界搜索空间并抑制求解时间随交互复杂度的增长。
技术挑战
  • 混合整数非线性规划(16)为NP-hard，求解时间随交互场景复杂度急剧增长
  • 多对手多车道下场景树规模膨胀，整数变量与连续运动耦合
  • 需保持安全关键场景下预测决策的可解释性与最优性
  • 需在固定高置信度决策时避免错误固定导致不可行或次优
问题分析
作者先建立含多车多车道的交互式驾驶系统模型，将对偶 MPC 表述为含整数机动决策与连续运动的混合整数非线性规划(16)，并用对手可能交互的场景树处理多模态不确定性；随后把该 MINLP 表示为变量节点、约束节点和边构成的二部图，将求解最优整数决策的问题转化为图上的节点分类/分布预测问题，利用训练实例共享的结构先验，由GNN预测每个决策的最优值分布，再用置信度阈值固定部分整数变量，仅在剩余模糊变量上调用求解器（如SCIP）完成分支定界。
方法
  • 构建多对手多车道对偶MPC问题(16)：联合优化整数机动决策（换道取{-1,0,+1}、安全区域取Q）与连续运动，场景树采样对手可能交互，目标包含跟踪与信息寻求
  • 把(16)的变量、约束及其边关系建成图G，作为GNN输入；变量节点V与约束节点C先经各自MLP嵌入为V1、C1
  • 约束侧消息传递：MLP由两端节点嵌入与边特征E计算每条边消息，约束节点聚合更新为C2；变量侧再聚合更新后的约束节点得到V2
  • 最后由MLP把每个变量嵌入V2映射为标量分数，对组成决策z的二值变量分数做softmax，得到p_z(ζ)=Pr(z*=ζ)，换道无变化选项分数设为零
  • 训练：在随机交通闭环仿真中收集每个MINLP的图G及其由SCIP求解全问题得到的最优机动决策{z*}，以交叉熵 -∑ log p_z(z*) 最小化训练GNN
  • 推理：用GNN预测的分布固定高置信度整数决策，仅将模糊决策留给分支定界求解，得到缩减后的问题并求解
实验
  • 仿真显示在复杂交互场景中出现了主动探测行为
  • GNN引导固定了76.3%的整数决策
  • 平均求解时间减少2.5倍，且最优性退化可忽略
  • 案例表明：对手谨慎让行时信念收敛到谨慎值、自车自信驶出环岛；对手激进不让行时自车推迟驶出并再绕环岛一圈
  • 对比基线、实例规模、训练开销、公平计算预算、泛化与消融等细节材料未说明
局限

研究设定
论文研究多模态运动规划（M³P）问题，属于任务与运动规划（TAMP）的特例：机器人需要在离散工作模式（如抓取、行走、导航）之间切换，同时对连续运动进行联合推理，决策对象是模式序列与连续轨迹的联合解，目标是在混合离散-连续决策空间中生成可行且鲁棒的运动路径。关键约束包括符号约束与几何约束的紧耦合、非凸性以及需要采用近似、基于离散化的混合整数规划（MIP）形式。信息假设为环境为静态、模型与任务信息已知，作者在结论中明确指出该流程主要面向静态环境，不支持带移动障碍或时变约束的动态场景。
研究动机
现有 TAMP 与 M³P 方法多依赖领域特定启发式或局部最优性、可微性等假设，常将任务规划与运动规划解耦，导致融合较弱；纯符号方法（如 PDDL）高层推理高效但难以处理连续可行性。MIP 虽提供统一框架，但针对非凸机器人任务构建可求解的近似离散化 MIP 公式通常需要人工、领域特定地完成，难以规模化。因此作者希望让 LLM 借助求解器反馈自动生成可执行的 MIP 建模代码，使语言推理与基于优化的规划真正衔接。
核心洞察
直接让大模型输出答案容易产生幻觉且不可验证，而让模型输出调用 MIP 优化库与约束接口的可执行 Python 代码，就能把正确性判断外包给求解器：生成结果是否可用由求解器实际求解结果决定，而不是由模型自我判断。这样，模型学习到的不是记忆的答案模式，而是如何组合模态级离散化原语与跨模态耦合约束，从而把语言模型的组合归纳能力锚定在可验证的数值优化执行之上。
技术挑战
  • M³P 同时包含离散模式转移与连续动力学，形成大规模且符号约束与几何约束紧耦合的混合决策空间。
  • 非凸机器人任务需要近似、离散化的 MIP 形式，而这类形式通常由人类专家手工、领域特定地构建。
  • 让 LLM 直接输出答案存在幻觉风险，且难以保证可执行性与可行性验证。
  • 需要通过求解器反馈训练模型组合离散化 API 与构造跨模态耦合约束，而非记忆固定模式。
问题分析
作者把 M³P 建模为 MIP 变量、约束与目标的分解问题，并利用问题结构将任务拆解为模态级离散化原语与跨模态耦合约束两类构件，由 LLM 依据任务描述组合这些构件并生成可执行程序。在训练环节，作者采用结果驱动的奖励，用求解器对生成代码的执行结果进行评估，从而为模型提供可验证的学习信号；同时构建了覆盖单模态与多模态组合的基准，用以检验模型在未见过任务难度上的泛化。
方法
  • 用强化学习微调大语言模型，将 M³P 任务分解为 MIP 的变量、约束和目标，而不是直接输出答案。
  • 模型生成使用 MIP 优化库与约束接口的可执行 Python 代码，由求解器执行以获得稳健且可验证的解。
  • 采用结果驱动、面向求解器的奖励进行训练，使模型学会组合模态级离散化原语并合成跨模态耦合约束。
  • 采用 GRPO 进行训练，使模型学习组合离散化 API 并构造 MIP 分解来求解 M³P 任务，而非依赖记忆的模式。
  • 面向非凸机器人规划的近似、基于离散化的 MIP 形式，区别于以往 LLM 优化工作所针对的精确 MIP/MILP。
  • 构建 LLMM³P Bench 基准，包含 1,316 个问题，覆盖 5 种单模态与 8 种多模态组合，用于评测与泛化检验。
实验
  • 在 LLMM³P Bench（1,316 个问题，5 种单模态与 8 种多模态组合）上评测。
  • M³P-R1 达到 91.7% 单模态与 80.9% 多模态任务成功率。
  • 相比最强的仅提示 LLM 基线（GPT-5.2），单模态提升 26.4 个百分点，多模态提升 40.6 个百分点。
  • 在真实硬件上迁移成功率达 87.5%，即 40 个场景中成功 35 个，使用 Franka Panda 与 DJI Tello 无人机。
  • 失败主要归因于仿真到现实的差异；Franka Panda 以 1 kHz 通过以太网运行，Tello 通过 2.4 GHz WiFi 通信。
  • 作者称模型能泛化到未见过（held-out）的任务难度；具体基线设置、消融与计算预算细节在给定材料中未完整给出。
局限
  • 受 MIP 形式固有局限，流程主要面向静态环境，尚不支持带移动障碍或时变约束的动态场景。
  • 研究聚焦于已由人类专家建立的基于 MIP 的机器人规划问题，尚未覆盖未见过的 M³P 问题。
  • 真实硬件失败主要来自仿真到现实的差异。

研究设定
面向地理分布式AI数据中心运营者，研究在时变电网供电约束与节点电价信号下，联合决策各站点LLM模型副本的加载(部署)时段与跨站点请求路由，目标是在满足LLM推理特有的服务延迟约束（TTFT与TPOT）并维持服务率的前提下最小化总运行成本；决策对象包括模型副本加载/卸载的时序承诺变量与请求分配量；关键约束为分时功率供应上限、电价信号、模型副本加载的时序耦合以及延迟决定的服务能力上限；信息假设为已知未来时段的电价与功率供应曲线（在算例中体现为可做全时段前瞻），环境为随电价与供电条件变化的动态但可预测场景，静态或动态的随机性材料未说明。
研究动机
AI数据中心在部分时段可能面临供电短缺，需要将LLM推理负载在地理上迁移以维持服务率。然而已有负载转移方法通常假设只要某数据中心计算资源充足就能立即服务转移来的请求，忽略了推理请求只能被转移到已加载对应模型副本的站点这一事实，可能导致不可行的转移决策与未服务需求；同时已有SLO建模多针对网络传输或排队延迟，未纳入LLM推理的prefill与decode延迟对可服务需求量的约束。
核心洞察
该工作有效性的关键在于把LLM推理的“模型副本加载”视为类似机组组合中机组启动的提前承诺过程，从而显式刻画负载转移的时序前置条件：只有提前完成加载并进入就绪状态的副本才能在后续时段承接被转移的请求；在此基础上，将prefill的TTFT与decode的TPOT延迟需求翻译为每个就绪副本在各时段可承接的需求量上限，使调度决策同时具备可行性与前瞻性，避免出现表面上有算力却无法实际服务转移请求的伪可行方案。
技术挑战
  • 模型副本加载与预热需要显著时间，导致请求路由与部署决策之间存在跨时段耦合，不能按单时段独立决策
  • LLM推理的prefill(TTFT)与decode(TPOT)延迟约束需转换为每副本每时段的容量上界，且需与功率约束、电价信号共同纳入统一优化
  • 若忽略加载时间或延迟约束，会导致物理上不可执行的转移与大量未服务需求，需要在模型中同时保证可行性并兼顾成本

研究设定
研究问题是在城市路网中，利用机器人出租车队作为移动传感器进行交通监控，同时提供出行服务。决策对象是机器人出租车的动态路径，优化目标为最小化总出行时间并最大化监控性能（时空覆盖）。关键约束包括车辆运动学、乘客需求（材料未明确说明）、以及路由决策必须适应实时交通状态。信息假设为部分可观测，交通状态通过车辆观测预测。环境为动态的，基于滚动时域的微观仿真。
研究动机
传统固定式传感器空间覆盖有限且成本高；探测车数据受个人出行需求驱动且不可控，且需要高市场渗透率才能保证足够的时空覆盖。机器人出租车作为新兴车队，既可为乘客服务，又可作为感知平台，若能将其路由决策与监控目标集成，有潜力实现网络级交通监控。
核心洞察
核心洞察是将交通监控性能（时空覆盖）显式纳入路径规划目标，可以引导车队绕行以覆盖未观测区域，而并非必然牺牲平均速度。在适当权重下，监控性能与平均速度可以同时提升，原因是更好的覆盖提高了交通状态预测精度，进而改善了出行时间估计和路径选择。
技术挑战
  • 网络表示：现有基于路径或链接的表示无法反映车辆感知范围空间不匹配，需要更高分辨率的表示以捕捉部分链路观测。
  • 监控性能指标设计：需要能够直接反映监控质量、可由个体车辆计算、并在网络层面有意义的指标。
  • 时变动态决策：路由决策必须实时适应交通状态与网络可观测性变化，计算复杂度与实时性挑战。
问题分析
作者采用基于单元的网络表示，将道路划分为细粒度单元以匹配感知范围；设计单元级时空覆盖度量指标；利用单元传输模型（CTM）进行交通状态预测，并据此生成时变行驶时间成本；将路由优化建模为混合整数线性规划（MILP），在滚动时域方案中求解。
方法
  • 基于单元的网络表示：道路被划分成单元，与自动驾驶车辆感知范围对齐。
  • 单元级时空监控指标：用于量化机器人出租车队的时空覆盖。
  • MILP 公式：目标函数同时最小化总行驶时间和最大化监控性能，受路由可行性和服务约束（材料未详细说明）。
  • 滚动时域方案：动态路由算法随时间重复求解以响应交通状态变化。
  • 微观仿真集成：利用 SUMO 模拟机器人出租车和背景车辆运动，基于车辆观测预测交通状态并反馈给路由优化。
实验
  • 在 SUMO 中构建了 5×5 的城市网格路网，设置了三种机器人出租车市场渗透率（2%、5%、10%），并测试多种目标权重组合。
  • 结果显示，将时空覆盖纳入目标函数能有效提高监控性能。
  • 在适当的权重下，监控性能与机器人出租车平均速度可以同时提升，表明存在双赢情形。
局限
  • 材料表示，增加覆盖并不单调地提高车队感知能力，过度的路由预算导致仅增加行驶距离而速度下降，部署需权衡。
