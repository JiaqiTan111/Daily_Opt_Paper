研究设定
研究问题为混合整数线性规划（MILP）的求解效率与解质量提升，决策对象是分支定界框架中的割选择与分支两个紧密耦合的求解器模块；目标是通过多智能体协同策略学习联合优化这两个模块的决策策略，以提升求解性能并保持跨实例集泛化能力；关键约束包括模块间的相互依赖性和联合训练中的非平稳性问题；信息假设为策略可基于求解过程中的状态特征与数据通信进行学习；环境为静态MILP实例分布，材料未说明是否涉及动态扰动或在线场景变化。
研究动机
传统MILP求解依赖人工设计的启发式策略，设计成本高且跨问题域鲁棒性差。近年来基于深度学习的求解方法展现出潜力，但现有工作通常孤立地为单个模块学习策略，忽略割选择与分支等模块之间的相互依赖关系，这限制了求解效率和最终解质量。作者因此提出协同策略学习以显式建模模块间协作。
核心洞察
作者的核心洞察在于：MILP求解器中割选择与分支等模块并非独立，孤立训练得到的策略在联合使用时可能出现次优协作。显式地将模块间交互建模为Stackelberg博弈（领导者-跟随者结构），并通过两阶段学习范式（数据通信预训练加并发在线微调）能够稳定多模块协同策略学习，从而在求解效率和解质量上均获得提升。这一洞察的有效性来源于对模块间耦合结构的刻画，而非单纯叠加更强的神经网络。
技术挑战
  • MILP求解器中多模块紧密耦合，孤立学习策略忽略相互依赖，导致求解效率和解质量受限
  • 多模块协同策略学习本质上是一个非平稳学习问题，并发训练时各模块策略同时更新，训练稳定性难以保证
  • 需要在不同问题类别和不同规模实例上保持泛化能力，避免对单一实例集过拟合
  • 割选择与分支的决策空间巨大且动作语义不同，如何设计有效的跨模块通信与协调机制
问题分析
作者首先识别出分支定界框架中割选择与分支两个模块的紧密耦合关系，指出孤立学习策略的局限性。随后将这两个模块之间的协作关系形式化为Stackelberg博弈，区分领导者与跟随者的决策层级。基于该博弈结构，作者将联合优化视为非平稳学习问题，并采用两时间尺度更新规则来稳定并发训练。作者还通过数据通信的预训练阶段为各模块策略提供共享信息基础，再在第二阶段进行在线并发微调，以协调各模块策略。
方法
  • 将MILP求解器中割选择与分支模块之间的协作建模为Stackelberg博弈，明确领导者-跟随者决策层级
  • 提出两阶段学习范式：第一阶段进行带数据通信的策略预训练，第二阶段对多个模块进行并发联合微调
  • 在第二阶段中，分支策略也参与轨迹生成，割选择策略的微调方式与第一阶段相同
  • 采用两时间尺度更新规则来应对联合优化中的非平稳学习问题，稳定并发训练
  • 针对每个MILP问题类别独立训练一个模型，材料未说明是否采用多任务或跨类共享参数
实验
  • 在六个NP-hard MILP基准数据集上评估：Set Covering、Maximum Independent Set、Combinatorial Auction、Capacitated Facility Location、Mixed Integer Knapsack和Production Planning，其中Production Planning为真实世界应用数据集
  • 合成数据集生成10000个训练实例、2000个验证实例和100个测试实例；真实世界数据集按80%/10%/10%划分训练、验证和测试集
  • 在Capacitated Facility Location数据集上，Collab-Solver在表5所示的三模块协作结果中取得最佳性能，如Ours行显示时间为1632、节点数为99391、PD gap为1.15%、某百分比为71%，优于GCNN-B、PnS等基线
  • 实验涉及5个随机种子并报告均值和标准差
  • 消融实验验证各组件，并将Collab-Solver扩展到三个模块的协作
  • 在扩展时间限制下的困难实例和不同实例规模上评估泛化能力
  • 对比基线包括基于学习的策略和超参数调优基线
局限
  • Collab-Solver当前为每个问题类别训练一个独立模型，跨类泛化能力有限
  • 未来工作将探索多任务学习以改进跨类泛化

研究设定
论文研究静态离线数据集下的作业车间调度问题（JSP）与柔性作业车间调度问题（FJSP），决策对象是每个调度步骤中机器-工序对的离散选择，目标为最小化最大完工时间（makespan），动作空间离散、可变大小且依赖实例；关键约束为工序先后顺序与机器能力；信息假设为仅有固定离线数据集、无环境交互；环境为静态离线设定，材料未说明任何动态扰动。
研究动机
在线强化学习方法虽在JSP和FJSP上表现良好，但需要大量模拟器交互，样本效率低；而实际生产中已有启发式算法可轻松生成大量次优数据。已有唯一离线方法Offline-LD依赖计算昂贵的CP近优解，可扩展性受限。因此，作者希望探索能否仅从静态、次优甚至随机数据中学习有效调度策略。
核心洞察
对于JSP和FJSP，离线强化学习性能更多取决于状态-动作覆盖度而非单个轨迹的质量。这是因为JSP/FJSP具有两个结构特性：奖励密集且与makespan目标对齐，以及不同启发式生成的轨迹长度相等。因此，随机策略生成的数据天然具有最大的每状态动作多样性，从而成为最强训练源。CDQAC通过分位数评论家和延迟策略更新，能够从广泛行为中准确估计动作价值并将高质量部分解拼接成新策略。
技术挑战
  • 动作空间离散、可变大小且依赖实例，无法直接使用连续动作或固定维度的离线RL方法
  • 离线数据可能分布外，易导致值高估
  • 需在无环境交互下稳定学习策略与价值函数
  • 次优甚至随机数据可能质量低，传统观点认为随机数据最弱
问题分析
作者通过分析JSP和FJSP的结构性质（密集且目标对齐的奖励、所有启发式轨迹等长）提出覆盖度比数据质量更重要的假设，并据此设计实验比较不同质量数据集（PDR、GA、PDR-GA、Random）的训练效果；同时使用分位数评论家学习回报分布，结合CQL保守正则化防止分布外动作高估，并用延迟策略更新防止早期噪声传播。
方法
  • CDQAC使用分位数评论家估计机器-工序对回报的分布，采用双头结构取最小值计算目标，每个头将回报近似为固定分位数上Dirac delta的均匀混合
  • 评论家采用分离输入的决斗架构，分别处理价值流和优势流，以适应可变大小的动作空间
  • 采用延迟策略更新，防止早期噪声评论家预测传播，确保策略与价值函数联合稳定学习
  • 在标量均值上应用CQL保守正则化，而非惩罚整个回报分布，因为目标是风险中性的makespan最小化
  • 策略通过评论家的自举目标训练，生成优于数据生成启发式的调度策略
实验
  • 实验在JSP和FJSP基准上进行，训练数据由PDR、GA和随机启发式生成，数据集质量不同
  • CDQAC匹配或超越数据生成启发式，并优于近期离线与在线RL基线
  • CDQAC具有高样本效率，仅需原始数据集的1%至5%即可学习高质量策略，即10-25个训练实例
  • 随机数据训练的CDQAC优于使用更强启发式（如遗传算法）生成的数据集训练的策略
  • 覆盖度是唯一与性能显著相关的数据集属性
  • 可从较小实例泛化到较大实例；具体基线、消融和计算预算细节材料未说明

研究设定
论文研究算法设计中的过程性知识（procedural knowledge）如何表示、获取与迁移的问题。决策对象是算法设计过程中的算子选择与算子组合顺序，目标是在更换目标领域时以极低边际成本复用已学得的过程性知识，而非追求超越专用最先进求解器。关键约束包括：节点必须承载经过验证的可执行算子，边只能表示模式允许的合法组合，RoleSchema 决定角色本体，部署阶段必须零语言模型调用、不做目标域边权再训练；信息假设是目标域需暴露兼容的 binding 接口（提供评估、有效性检查、复制等操作）；环境涵盖静态的离线生成与学习阶段，以及在线符号执行阶段，作者将图设计为无在线自适应，学习到的边权在部署中固定不变。
研究动机
算法设计中的过程性知识通常嵌在源代码、实验日志或隐性设计实践中，每当更换领域就需要重建、调参或重新演化，导致知识难以获取、检视和复用。作者希望将这类知识从源代码中解耦出来，变成一种可生成、可执行、可迁移的图表示，从而支持离线获取、压缩、检视与零语言模型调用的在线部署。
核心洞察
该方法之所以可能有效，关键在于把过程性知识按表示粒度分层：L0 角色本体给出抽象且可约束的算子类型，L1 提供经语言模型生成并验证的可执行算子，L2 用 ACO 在执行轨迹上学习边上的转移权重。作者的核心发现是“迁移什么取决于粒度”：在神经架构搜索同一族内，学习到的权重快照可跨数据集迁移并保持与 Regularized Evolution 竞争；而跨组合优化领域时，只有受本体约束的可执行结构能迁移，学到的权重不见得能迁移。进一步，迁移是否有收益取决于目标侧搜索成本：目标侧搜索昂贵时，迁移结构有正收益；目标侧存在廉价的强局部搜索时，迁移结构并无改善。
技术挑战
  • 如何将过程性知识表示为既能生成、又能执行、还可迁移的形式，同时不依赖部署时的语言模型调用
  • 如何在跨数据集和跨领域两种不同粒度上界定并验证到底迁移了什么
  • 如何设计 RoleSchema 使其同时具备语义约束力与跨域复用能力，而不至于只是限制搜索空间
  • 如何在目标侧搜索成本低廉或已有强局部搜索时避免迁移带来的无效开销
  • 当前图无在线自适应，如何在不破坏已学结构的前提下支持在线更新与顺序多域迁移
问题分析
作者通过三个研究问题组织分析：RQ1 考察同一引擎能否在不做框架级修改的情况下支持不同算法设计域；RQ2 考察过程性快照能否跨数据集和兼容优化域迁移；RQ3 考察迁移在什么条件下产生收益。分析手段包括分层消融（L0 本体、L1 算子质量、L2 排序）来定位迁移粒度，用随机排序替换学习到的边权作为对照，用图上的联合分布、逐边分布、平稳分布与谱间隙来分析所学策略是否稳定未坍塌，并通过扰动边权检查执行器输出是否平滑有界。作者还用代理保真度表检验 NAS 表格基准的秩保真性，并明确把执行器定位为可复用的过程性先验而非专用求解器。
方法
  • GEAKG 表示为带类型的知识图谱：节点对应抽象算子角色，节点负载为经验证的可执行算子，边编码允许的组合，边权记录学习到的有效转移序列
  • 离线阶段由 RoleSchema 决定拓扑与算子生成，语言模型在模式约束下生成算子，生成后需通过验证，随后用 ACO 在执行轨迹上精炼转移权重，得到可复用快照
  • 快照被序列化为可检视的工件 L0+L1+L2，同一引擎通过更换 RoleSchema 与 binding 即可在不同领域实例化
  • 在线阶段由 Symbolic Executor 遍历快照，按学到的转移分布采样下一个角色，并调用绑定到该角色的算子；NAS 中体现为图引导的架构变换并在表格基准上评估，优化中体现为对排列解进行构造、扰动与局部改进并立即由领域上下文评估
  • 零样本迁移定义：目标域部署使用固定的 L0、L1、L2 快照，不做目标域边权再训练、不重生成算子、不在运行时调用语言模型，唯一目标相关部分是模式兼容的 binding
  • 学习与搜索的结合位置在 ACO 精炼边权，执行器只读快照；当前不做在线权值更新

研究设定
研究问题为 VLSI 物理设计中的自动化宏单元布局（macro placement），决策对象是宏单元的位置与朝向，目标是在固定 floorplan 与 I/O 分配下取得更优的布线后 PPA（尤其是时序）并保持 DRC 干净；关键约束包括物理合法性、专家布局原则、早期实现反馈与最终布线后反馈；信息假设为可利用 floorplan 图像、宏单元规格与连接结构，以及实现阶段与布线后的物理反馈，属于带视觉与反馈信号的闭环动态决策环境，但摘要未说明是否在线学习或具体训练方式。
研究动机
作者认为宏单元布局长期被建模为手工代理目标（如预估线长）的一次性数值优化，无法在同一闭环内融合可视布局上下文、被编码的设计经验与下游物理设计反馈，因而限制了布局质量的进一步提升。
核心洞察
该工作有效性的关键在于把布局从黑箱一次性优化改为带验证反馈的闭环推理：VLM 依据图像、规格与连接关系生成候选，几何验证器保证合法性与专家原则、物理验证器与布线后优化器按阶段递进的物理反馈筛选与精化候选，使搜索信号从代理指标转向真实下游 PPA；同时用统一开放基准把差异限制在宏单元位置与朝向上，使比较可复现且公平。
技术挑战
  • 如何把布局经验与设计规则编码为可执行的验证准则，而非仅作为软性提示
  • 如何让 VLM 生成的候选满足物理合法性并避免无效搜索
  • 如何在闭环中整合早期实现反馈与布线后 PPA 两级异构信号
  • 如何构建可复现、任务定义固定且用真实下游指标评价的基准
  • 如何在未显式优化线长的情况下仍改善布线后线长与时序
问题分析
作者将宏单元布局重构为闭环推理问题，把问题分解为候选生成（VLM 规划器）、合法性过滤（几何验证器）、反馈精化（物理验证器）与最终择优（post-route 优化器）四个阶段；通过构建固定 floorplan 与 I/O 分配的开放端到端基准，把方法差异限制在宏单元位置与朝向，并以布线后 PPA 与 DRC 而非布线前代理指标评价，从而分析推理式搜索是否优于代理目标优化。摘要未提供更细节的问题结构分解、下界或图表示使用方式的说明。
方法
  • 整体为 verifier-guided 多智能体框架，将宏单元布局表述为闭环推理问题而非黑箱优化
  • VLM 规划器以 floorplan 图像、宏单元规格与连接结构为输入，输出候选布局（位置与朝向）
  • 几何验证器强制物理合法性与专家布局原则，过滤或修正候选
  • 物理验证器利用早期实现反馈精化候选
  • post-route 优化器使用最终 PPA 进一步改进有前景的布局
  • 引入 PlaceReasoner-Bench：基于开放 RTL 设计与 EDA 工具、工艺库构建的全开放端到端基准，含 8 个设计 × 2 种宽高比 = 16 个任务，floorplan 与 I/O 固定，仅宏单元位置与朝向可变，用布线后 PPA 与 DRC 评价
