Tree-Structured Synergy of Large Language Models and Bayesian Optimization for Efficient CASH

Beicheng Xu · Weitong Qian · Lingching Tung · Yupeng Lu · Bin Cui

核心洞察

论文的核心洞察在于，CASH 的跨算法选择与算法内超参数精炼本质上是轨迹结构化的问题，若将算法选择、超参数细化和 BO 与 LLM 提议者协同统一到一个共享的蒙特卡洛树搜索树中，可以保留路径信息并有选择地记忆历史；共享树状态使贝叶斯优化能针对特定算法建立代理模型进行定量搜索，同时使大语言模型能利用路径感知的选择性记忆生成语义提议与反思，从而在高维结构化空间中获得更好的协同探索与利用。随着代理模型改善，可靠性感知的提议者策略可自适应地从大语言模型驱动转向贝叶斯优化驱动，在统一搜索轨迹内动态平衡语义先验与定量模型。

为什么值得看：对研究 AI4OR 与学习辅助搜索的读者，该论文提供了一个将 LLM 语义先验与贝叶斯优化定量代理模型通过树结构共享状态进行协同的机制，并引入了随代理模型可靠性自适应切换提议者的策略。虽然其直接对象是 AutoML 的 CASH 问题，但其中关于高维结构化搜索空间中的轨迹保持、跨子空间协同探索利用以及 LLM 与经典优化器结合的思路，可能为生产调度、算法配置和一般组合优化中的混合智能优化方法提供参考。建议关注其机制设计而非仅因出现 LLM 或 agent 术语而采纳。

研究设定
论文研究 CASH（Combined Algorithm Selection and Hyperparameter optimization）问题，即联合自动化选择机器学习算法并调优其算法专属超参数。决策对象为候选算法与对应的超参数配置；目标是在高维、结构化搜索空间中高效找到高质量配置，缓解传统贝叶斯优化的冷启动问题。关键约束与信息假设材料未明确给出，环境是否可以视为静态同样材料未说明，仅从摘要可知搜索空间具有高维和结构化特征，且需要跨算法以及算法内部超参数空间进行协同探索与利用。
研究动机
作者指出，为降低机器学习使用门槛，AutoML 社区聚焦 CASH 问题；传统贝叶斯优化存在冷启动问题，大语言模型可通过语义先验缓解冷启动，但现有基于大语言模型的优化器对高维、结构化 CASH 空间泛化较差。CASH 需要跨候选算法及其算法专属超参数空间进行协同的探索与利用，而现有方法常依赖扁平的优化历史，将不同算法的观测混合在一起，掩盖了配置精炼轨迹。
核心洞察
论文的核心洞察在于，CASH 的跨算法选择与算法内超参数精炼本质上是轨迹结构化的问题，若将算法选择、超参数细化和 BO 与 LLM 提议者协同统一到一个共享的蒙特卡洛树搜索树中，可以保留路径信息并有选择地记忆历史；共享树状态使贝叶斯优化能针对特定算法建立代理模型进行定量搜索，同时使大语言模型能利用路径感知的选择性记忆生成语义提议与反思，从而在高维结构化空间中获得更好的协同探索与利用。随着代理模型改善，可靠性感知的提议者策略可自适应地从大语言模型驱动转向贝叶斯优化驱动，在统一搜索轨迹内动态平衡语义先验与定量模型。
技术挑战
  • 传统贝叶斯优化在 CASH 中面临冷启动问题
  • 现有基于大语言模型的优化器对高维、结构化 CASH 空间泛化较差
  • 需要在候选算法之间以及算法专属超参数空间内部同时进行协同的探索与利用
  • 扁平优化历史混合跨算法观测，难以显现配置精炼轨迹
  • 如何让 LLM 与 BO 在统一搜索过程中可靠地协同并动态切换提议来源
问题分析
作者从 CASH 问题结构出发，指出其包含算法选择与算法专属超参数细化两个层面，因此需要跨算法和算法内部的协调搜索。作者分析现有方法使用扁平优化历史，混合了不同算法的观测，从而掩盖配置精炼轨迹，导致 LLM 优化器在高维结构化空间泛化不佳。基于此，作者提出以蒙特卡洛树搜索树作为共享状态，将算法选择、超参数精炼以及 BO 与 LLM 提议者协同统一到同一搜索轨迹中，从而利用路径结构保留并选择性利用历史信息。具体如何利用问题结构进行分解、下界估计或图表示，材料未说明。
方法
  • 提出 LB-MCTS，一种轨迹结构化的优化框架。
  • 使用蒙特卡洛树搜索树作为共享状态，统一算法选择、超参数细化和 BO-LLM 提议者协同。
  • 在共享状态内，贝叶斯优化为算法专属代理建模提供定量搜索能力。
  • 大语言模型利用路径感知的选择性记忆生成语义提议与反思。
  • 随着代理模型改善，可靠性感知的提议者策略在统一搜索轨迹内自适应地从 LLM 驱动提议转向 BO 驱动提议。
实验
  • 在 104 个 AMLB 数据集上进行实验。
  • 实验结果表明 LB-MCTS 持续优于基于贝叶斯优化、基于大语言模型以及混合基线方法。

与你的研究关系
论文事实：该工作面向 AutoML 中的 CASH 问题，使用蒙特卡洛树搜索作为共享状态，协同贝叶斯优化与大语言模型进行算法选择和超参数调优，并采用可靠性感知策略动态切换提议者。迁移设想（推测）：其核心机制——以树结构保存搜索轨迹、对高维结构化空间进行路径感知记忆、以及基于代理模型可靠性动态切换 LLM 与定量优化器——在概念上与智能优化和生产调度中的学习辅助搜索有潜在相通之处，例如可用于柔性作业车间或分布式制造中的机器选择、规则选择与参数协同优化；但迁移到生产调度需要重新定义状态、动作、目标函数和约束可行性处理，并验证在调度问题上的公平计算预算与泛化能力。摘要并未讨论生产调度或约束优化，因此这种迁移属于推测而非作者结论。

论文研究 AutoML 中的 CASH 问题，即联合自动化算法选择与超参数调优。：the AutoML community has focused on the CASH problem, which jointly automates algorithm selection and hyperparameter tuning.
传统贝叶斯优化存在冷启动问题，大语言模型可通过语义先验缓解。：While traditional methods like Bayesian Optimization (BO) struggle with cold-start issues, Large Language Models (LLMs) can mitigate these through semantic priors.
现有基于 LLM 的优化器对高维、结构化 CASH 空间泛化较差，且扁平优化历史掩盖配置精炼轨迹。：However, existing LLM-based optimizers generalize poorly to high-dimensional, structured CASH spaces.
论文提出 LB-MCTS，以蒙特卡洛树搜索树作为共享状态，统一算法选择、超参数细化和 BO-LLM 提议者协同。：we propose LB-MCTS, a trajectory-structured optimization framework that uses a Monte Carlo Tree Search tree as a shared state for algorithm selection, hyperparameter refinement, and BO-LLM proposer synergy.
在共享状态内，BO 提供算法专属代理建模，LLM 利用路径感知选择性记忆生成语义提议与反思。：Within this shared state, BO provides algorithm-specific surrogate modeling for quantitative search, while the LLM exploits path-aware selective memory to generate semantic proposals and reflections.
随着代理模型改善，可靠性感知的提议者策略在统一搜索轨迹中从 LLM 驱动自适应转向 BO 驱动。：As the surrogate model improves, a reliability-aware proposer policy adaptively shifts from LLM-driven to BO-driven proposals within a unified search trajectory.
在 104 个 AMLB 数据集上，LB-MCTS 持续优于基于 BO、基于 LLM 以及混合基线。：Experiments on 104 AMLB datasets demonstrate that LB-MCTS consistently outperforms BO-based, LLM-based, and hybrid baselines.
