研究设定
研究问题为众包配送中的任务分配与补偿决策，决策对象是任务捆绑集合、捆绑到司机的分配以及每个捆绑-司机对的个性化补偿。目标是最大化总期望成本节省。关键约束包括每司机可接受任务的能力（隐含通过路径约束）以及接受概率依赖捆绑和补偿。信息假设包括司机接受行为不确定但可由逻辑函数刻画。环境为静态的、基于司机预计划行程的场景。其他细节（如时间窗、容量约束）材料未说明。
研究动机
最后一英里配送挑战促使众包配送出现，但司机对任务的接受行为不确定且受任务属性和补偿影响。现有文献缺乏同时且精确处理该挑战的模型，因此需要一种联合优化方法。
核心洞察
通过将接受概率作为捆绑和补偿的显式函数纳入优化，可以更现实地刻画司机行为，从而在捆绑结构和补偿决策上取得更优的期望成本节省。集成决策优于顺序方法，且补偿灵敏度是决定捆绑结构的最主要因素。
技术挑战
  • 任务捆绑数量巨大，导致变量指数级增长
  • 包含接受概率导致非线性混合整数规划
  • 子问题具有非线性非加性目标函数，需定制方法
问题分析
作者利用问题性质，将MINLP精确线性化，并设计定制列生成算法。子问题转化为具有资源约束的基本最短路变体，但其目标非线性非加性，为此开发了定制支配与剪枝策略以处理搜索，从而有效求解指数级变量问题。
方法
  • 建立集成优化模型：同时确定最优捆绑集合、捆绑分配和个性化补偿，目标最大化总期望成本节省
  • 将接受概率建模为捆绑和补偿的通用逻辑函数
  • 将MINLP精确线性化
  • 设计定制列生成框架，主问题处理线性化模型，定价子问题为具有非线性非加性目标的带资源约束的基本最短路变体
  • 开发定制支配与剪枝策略求解子问题
  • 引入启发式和精确变体以平衡效率与最优性
实验
  • 进行了广泛实验，测试实例规模达120个任务和60个司机，评估算法性能和解结构。结果表明算法有效（无具体数字），且集成决策优于顺序方法。灵敏度分析显示补偿灵敏度是影响捆绑结构的最主要因素。未报告具体基线或运行时间数字。

We simultaneously determine the optimal set of bundles, their assignment to drivers, and personalized compensations for each bundle-driver pair while considering bundle- and compensation-dependent acceptance probabilities, captured via generic logistic functions.

Our algorithm uses a variant of the elementary shortest path problem with resource constraints that features a non-linear and non-additive objective function as subproblem, for which we develop tailored dominance and pruning strategies.
