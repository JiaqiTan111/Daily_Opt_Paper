LINC: Decoupling Local Consequence Scoring from Hidden Matching in Constructive Neural Routing

Shaofeng Qin · Li Wang

核心洞察

作者的核心洞察是：确定性的一步转移后果不必依赖隐藏状态去隐式重建，而可以被显式计算并根据其决策角色分别使用——候选级别的后果适合用状态条件化的共享线性比较器来评分，可行集级别的汇总则适合用于调制解码器上下文。这种角色分离保留了标准全局匹配，同时减轻了隐藏状态的重建负担，因此有助于在约束更强、规模超出训练分布时保持优势。

为什么值得看：该论文与当前研究方向中的学习辅助搜索和神经组合优化直接相关，其核心机制——将确定性一步后果从隐藏匹配中解耦出来，并按候选级与可行集级角色分别使用——为在约束优化问题中设计解码器提供了可借鉴的结构性思路。尤其值得关注的是它在超出训练规模时优势更明显的现象，这与生产调度等领域对跨规模泛化的关切一致；虽然论文未涉及生产调度，但方法机制具有潜在的迁移价值。

研究设定
论文研究构造式神经路由求解器在组合优化问题上的下一步动作评分问题，决策对象是解码器在每个构造步骤中从候选动作集合里选择下一个动作；目标是在保留标准全局匹配机制的同时提升求解质量与跨规模泛化；关键约束体现在带时间窗的容量约束车辆路径问题（CVRPTW）中，涉及行驶、等待、松弛时间和容量变化等确定性一步后果；信息假设为模型可获得解码器上下文与候选嵌入；环境为静态组合优化实例，摘要未提及动态扰动或在线调度。
研究动机
既有构造式神经路由求解器通常通过将解码器上下文与候选嵌入匹配来给下一步动作打分，而行驶、等待、松弛、容量变化等确定性的单步后果被隐含在隐藏状态中，模型需要间接地重建这些转移算术，增加了学习负担，并可能在约束路由问题上限制求解质量与跨规模泛化。
核心洞察
作者的核心洞察是：确定性的一步转移后果不必依赖隐藏状态去隐式重建，而可以被显式计算并根据其决策角色分别使用——候选级别的后果适合用状态条件化的共享线性比较器来评分，可行集级别的汇总则适合用于调制解码器上下文。这种角色分离保留了标准全局匹配，同时减轻了隐藏状态的重建负担，因此有助于在约束更强、规模超出训练分布时保持优势。
技术挑战
  • 如何在保留标准全局匹配的同时显式引入确定性一步后果而不破坏原有解码器结构
  • 候选级后果与可行集级汇总具有不同决策角色，需要设计不同的使用方式
  • 在训练规模之外的测试规模上保持泛化能力，尤其是有约束的路由问题
问题分析
摘要表明作者将下一步动作评分分解为候选级显式后果评分与可行集汇总对解码器上下文的调制两部分，并说明这样可让隐藏状态不必重建转移算术；但作者具体如何利用问题结构、如何推导或定义这些后果，材料未说明。
方法
  • 提出 LINC，一种解码器侧候选决策架构，显式计算确定性一步后果，包括行驶、等待、松弛和容量变化。
  • 按决策角色使用后果：候选级后果由状态条件化的共享线性比较器评分。
  • 可行集汇总用于调制解码器上下文。
  • 保留标准全局匹配机制，同时减少隐藏状态重建转移算术的负担。
  • 以 CVRPTW 为主要约束路由测试平台，同一接口扩展到 CVRP 和 TSP。
实验
  • 在外部基准和无重训练的规模迁移设置下，LINC 一致地改进了强神经基线。
  • 随着测试规模进一步超出训练规模，优势更加明显，尤其是在约束路由问题上。
  • 摘要未给出具体基线名称、实例规模、解质量数字、运行时间、训练开销或消融结果。

既有构造式神经路由求解器通过匹配解码器上下文与候选嵌入来给下一步动作打分，确定性一步后果被隐含。：Constructive neural routing solvers usually score the next action by matching a decoder context to candidate embeddings, leaving deterministic one-step consequences such as travel, waiting, slack, and capacity changes implicit.
LINC 显式计算这些后果，并按决策角色使用：候选级后果由状态条件化的共享线性比较器评分，可行集汇总调制解码器上下文。：LINC uses them according to their decision role: candidate-level consequences are scored by a state-conditioned shared linear comparator, while feasible-set summaries modulate the decoder context.
该方法保留标准全局匹配，同时减少隐藏状态重建转移算术的负担。：This preserves standard global matching while reducing the burden on the hidden state to reconstruct transition arithmetic.
CVRPTW 是主要约束路由测试平台，同一接口扩展到 CVRP 和 TSP。：The Capacitated Vehicle Routing Problem with Time Windows (CVRPTW) serves as the main constrained-routing testbed, and the same interface extends to the Capacitated Vehicle Routing Problem (CVRP) and Traveling Salesman Problem (TSP).
在外部基准和无重训练规模迁移设置下，LINC 一致改进强神经基线，且测试规模越超出训练规模优势越明显，尤其在约束路由问题上。：Across external benchmarks and no-retraining scale-transfer settings, LINC consistently improves strong neural baselines, with the advantage becoming more pronounced as test size moves further beyond the training scale, especially on constrained routing problems.
