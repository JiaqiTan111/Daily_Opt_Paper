研究设定
研究问题是在有限评估次数下优化昂贵黑箱函数时，如何为贝叶斯优化（BO）算法自身预先指定算法配置参数（如探索-利用权衡参数、搜索策略设计参数）。决策对象是BO算法的配置参数 θ；目标是最小化给定先验分布下的贝叶斯累积遗憾（有限时域 T 内）。关键约束是：累积遗憾在运行前不可观测，只能借助对目标函数的高斯过程（GP）先验/后验分布做蒙特卡洛估计；参数优化本身也是黑箱问题。信息假设为：在BO开始时拥有关于目标函数的概率分布（可由初始观测的GP后验或相关任务的预训练GP先验给出）。环境是静态黑箱函数优化（非动态扰动），并扩展到多保真（以内层BO时域作为保真变量）与多阶段（算法参数可在优化过程中变化）配置。
研究动机
BO算法虽自动化目标函数优化，但自身含有多种算法配置参数（如采集函数中的探索-利用权衡、搜索策略设计参数），这些参数不同于代理模型超参数，无法由（边际）似然估计，通常只能设为默认值或启发式值，且对性能影响显著。作者提出基本问题：用于评估BO性能的同一准则（累积遗憾）能否也用于选择其配置参数。
核心洞察
核心洞察在于：既然在BO开始时已有关于目标函数的概率分布，就可以直接从该分布采样目标函数样本路径，并在每条路径上真实运行候选BO算法，从而将“预期有限时域累积遗憾”转化为可通过蒙特卡洛近似直接评估的量；这样，先验知识不再仅用于代理模型预测，还被用于配置BO算法本身。由于该评估本身是黑箱目标，再用一个外层BO（outer BO）去优化它，从而把算法配置问题纳入与性能度量一致的优化框架中。
技术挑战
  • 算法配置参数无法由代理模型似然估计，通常只能取默认或启发式值
  • 有限时域累积遗憾在运行前不可观测
  • GP采样路径上累积遗憾的方差是否有限并不显然
  • 参数优化本身构成黑箱优化问题
  • GP后验估计错误可能导向次优参数
问题分析
作者利用BO的贝叶斯视角，将目标函数视为服从GP分布，从而定义贝叶斯累积遗憾作为准则；通过从该分布采样 N 条样本路径并在每条路径上运行候选BO算法，得到期望累积遗憾的蒙特卡洛估计；再将该估计视为关于配置参数 θ 的黑箱函数，用外层BO优化。作者进一步分析了蒙特卡洛估计量的收敛性：在核函数连续、域紧致且满足增量方差界等条件下，证明近似误差为 O_p(T/√N)，并针对有限候选配置集给出所选配置与真实最优配置在期望累积遗憾之差的同阶保证，且该结论不依赖采集函数的具体形式。
方法
  • 将目标函数建模为GP分布 GP(μ0, Σ0)，定义贝叶斯累积遗憾作为BO算法配置的评价准则
  • 从GP先验/后验采样 N 条样本路径 f^(1),...,f^(N)
  • 对给定配置 θ 和时域 T，在每条样本路径上运行内层BO，计算累积遗憾 R_T^(j)，取平均得到 MC 估计 BR̂_T
  • 把 BR̂_T 作为关于 θ 的黑箱目标，构建外层BO：拟合GP到外层数据集 D^outer，最大化采集函数 a^outer 选择下一个 θ，评估后加入数据集，迭代 T^outer 次
  • 扩展到多保真优化，将内层BO时域作为保真变量
  • 扩展到多阶段配置，使算法参数可在优化过程中变化
  • 给出MC估计量 O_p(T/√N) 的收敛保证，以及有限候选配置下所选配置性能的保证
实验
  • 在TuRBO和LSBO上进行了实验，结果表明所提框架能够在一组候选配置中识别出具有强有限时域BO性能的参数配置。材料未提供具体的实例规模、基线细节、约束可行性、解质量数字、运行时间、训练开销、公平计算预算、泛化或消融的量化结果。
局限
  • 估计的GP后验若发生错误设定（misspecification），可能导致次优的BO参数选择；在这种模型错误设定下评估鲁棒性是未来重要方向。
与你的研究关系
该工作与AI4OR中“学习辅助优化”和“算法配置/元优化”方向相关：它提出用同一性能准则（累积遗憾）在贝叶斯框架下自动配置优化算法参数，并给出MC估计的收敛保证，这种“用优化来配置优化器”的机制可迁移到生产调度中求解器参数或启发式策略参数的自动整定。迁移设想（推测）：需要将调度问题嵌入可采样的先验分布（如将调度实例视为GP样本或构建实例分布），并把外层BO的目标改为调度解质量/约束可行性指标；同时需处理调度中约束可行性和离散决策带来的非光滑性，这些在本文中未涉及。当前论文本身并未研究生产调度或约束优化。

论文提出用目标函数分布下的期望累积遗憾来配置BO算法参数，并用外层BO优化该黑箱目标：We propose a framework for optimizing such parameters using sample paths drawn from a Gaussian process (GP) inferred from the information available at the start of BO.
性能度量采用累积遗憾，并通过在采样路径上运行BO算法获得期望累积遗憾的经验估计：We use cumulative regret as the performance metric for a BO algorithm. By running the BO algorithm on the generated sample paths, we obtain an empirical estimate of its expected cumulative regret for a given parameter configuration.
参数优化本身是黑箱优化，因此采用另一个BO程序（外层BO）求解：Since this parameter optimization is itself a black-box optimization problem, we employ another BO procedure to solve it, which we refer to as outer BO.
