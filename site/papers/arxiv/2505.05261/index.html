ICNN-enhanced 2SP: Leveraging input convex neural networks for solving two-stage stochastic programming

Yu Liu · Fabricio Oliveira · Jan Kronqvist

核心洞察

核心洞察在于：对于追索函数为凸的两阶段随机规划，可以用输入凸神经网络（ICNN）从架构上强制凸性，而ICNN在输入凸且权重非负的条件下可精确表示为线性规划（LP）。这样既保留了神经网络代理对追索函数的拟合能力，又使代理的嵌入不需要整数变量，将原本的MIP形式替换为LP形式，从而利用LP的高效求解器获得计算优势。有效性的来源不是单纯用神经网络替代追索函数，而是让代理的凸性与可LP表示性匹配问题结构，使精确嵌入与计算效率同时成立。

为什么值得看：对于关注学习辅助搜索与数学规划结合的研究者，本文提供了一个清晰的机制范例：通过选择具有可表示性保证的神经网络架构（ICNN）来匹配问题的凸结构，从而把昂贵的MIP嵌入替换为LP嵌入。这种“架构选择服务于求解器嵌入效率”的思路可迁移到生产调度中凸子问题的代理建模与约束生成。此外，论文强调随规模增大加速更明显，对关注可扩展性和公平计算预算的研究者有参考价值。

研究设定
论文研究两阶段随机规划（2SP）在不确定性下的决策问题：第一阶段决策在不确定参数实现前做出，第二阶段追索决策在参数实现后做出，目标是最小化第一阶段成本与期望追索成本之和，关键约束是追索函数的结构与可表示性。信息假设为随机参数服从已知分布且以场景形式离散化（由2SP的常规框架隐含），环境为静态的单期不确定决策，而非序贯动态决策。问题规模与场景数量导致追索函数评估计算复杂，可扩展性成为核心瓶颈。材料未说明具体应用领域、约束类型或场景生成方式。
研究动机
两阶段随机规划的可扩展性受限于追索函数评估的计算复杂度。已有的基于学习的方法（如Neur2SP）用神经网络作为追索函数代理，但将其嵌入优化模型时依赖计算昂贵的混合整数规划（MIP）形式，因为标准神经网络代理的嵌入通常需要整数变量或分段线性重构。作者希望利用凸2SP问题中追索函数的凸性结构，避免MIP嵌入，从而在保持解质量的同时显著降低求解时间。
核心洞察
核心洞察在于：对于追索函数为凸的两阶段随机规划，可以用输入凸神经网络（ICNN）从架构上强制凸性，而ICNN在输入凸且权重非负的条件下可精确表示为线性规划（LP）。这样既保留了神经网络代理对追索函数的拟合能力，又使代理的嵌入不需要整数变量，将原本的MIP形式替换为LP形式，从而利用LP的高效求解器获得计算优势。有效性的来源不是单纯用神经网络替代追索函数，而是让代理的凸性与可LP表示性匹配问题结构，使精确嵌入与计算效率同时成立。
技术挑战
  • 两阶段随机规划追索函数评估的计算复杂度导致可扩展性瓶颈
  • 标准神经网络代理嵌入优化模型时通常需要MIP形式，计算昂贵
  • 在避免整数变量的同时保持追索函数代理的精确嵌入与解质量
  • ICNN训练是否比标准NN更昂贵以及验证精度是否可比
  • 随问题规模增大时加速效果与解质量的平衡
问题分析
作者从两阶段随机规划的结构出发，指出追索函数在凸2SP中具有凸性，因此可以选择在架构上强制凸性的ICNN作为代理。分析路径是：先识别传统学习型方法（Neur2SP）因标准NN代理嵌入需要MIP而计算昂贵；再论证ICNN的凸性可转化为LP可表示性，从而在2SP框架内实现代理的精确嵌入而不引入整数变量；最后通过基准问题实验比较训练时间、验证精度、求解时间和解质量，并考察问题规模增大时优势的变化。材料未说明作者是否给出理论下界、分解策略或图表示。
方法
  • 使用输入凸神经网络（ICNN）作为两阶段随机规划中追索函数的代理模型
  • 在ICNN架构上强制凸性，使代理函数对输入保持凸性
  • 利用凸ICNN的线性规划（LP）可表示性，将ICNN代理精确嵌入2SP框架中，替代传统MIP嵌入
  • 消除传统MIP嵌入中固有的整数变量，形成基于LP的求解形式
  • 在2SP框架内保留ICNN代理的精确嵌入，同时保持求解质量
  • 与标准神经网络代理（如Neur2SP的NN代理）进行对比，评估训练时间与验证精度
  • 在基准问题上比较ICNN增强2SP与MIP形式在求解时间和解质量上的表现，并分析随问题规模增大的趋势
实验
  • 综合实验显示，ICNN的训练时间仅略微长于标准神经网络，验证精度与标准NN相当
  • 在多个基准问题上，ICNN增强2SP通常比基于MIP的形式求解时间显著更快，同时保持解质量
  • 随着问题规模增大，ICNN增强2SP相对MIP形式的优势变得更加明显
  • 在最困难的实例上，该方法实现了最高100倍的加速，且解质量优于基于MIP的形式

两阶段随机规划的可扩展性受追索函数评估计算复杂度制约，现有学习型方法依赖昂贵的MIP形式。：Two-stage stochastic programming (2SP) offers a basic framework for modelling decision-making under uncertainty, yet scalability remains a challenge due to the computational complexity of recourse function evaluation. Existing learning-based methods like Neural Two-Stage Stochastic Programming (Neur2SP) employ neural networks (NNs) as recourse function surrogates but rely on computationally intensive mixed-integer programming (MIP) formulations.
作者用ICNN利用凸2SP的LP可表示性，通过架构强制凸性和LP精确推断，消除MIP中的整数变量并保留精确嵌入。：We propose ICNN-enhanced 2SP, a method that leverages Input Convex Neural Networks (ICNNs) to exploit linear programming (LP) representability in convex 2SP problems. By architecturally enforcing convexity and enabling exact inference through LP, our approach eliminates the need for integer variables inherent in the conventional MIP-based formulation while retaining an exact embedding of the ICNN surrogate within the 2SP framework.
实验显示ICNN训练时间仅略长、验证精度与标准NN相当，且求解时间常显著快于MIP形式并保持解质量，规模增大时优势更明显。：Comprehensive experiments reveal that ICNNs incur only marginally longer training times while achieving validation accuracy on par with their standard NN counterparts. Across benchmark problems, ICNN-enhanced 2SP often exhibits considerably faster solution times than the MIP-based formulations while preserving solution quality, with these advantages becoming significantly more pronounced as problem scale increases.
在最困难实例上最高100倍加速且解质量优于MIP形式。：For the most challenging instances, the method achieves speedups of up to 100$\times$ with solution quality superior to MIP-based formulations.
