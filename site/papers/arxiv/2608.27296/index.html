研究设定
论文研究大语言模型能否为定义良好的运筹学问题自动设计有效算法，决策对象是算法或单个实例的解，目标是在给定基准实例上达到或超越已有专门方法，关键约束是仅提供一条未调优的提示、模型只能使用具有固定计算预算的 Python 沙箱工具、人类输入极少；信息假设分为两级，第一级模型接收单个问题实例并返回该实例的解，第二级模型仅接收问题类别描述与宽泛参数范围并返回一个从实例参数到解的算法；环境在第二级中体现为算法在见到评估实例之前就已固定，静态或动态性质材料未说明。
研究动机
作者希望检验前沿大语言模型是否已具备为定义良好的运筹学问题设计有效算法的能力，并由此判断其能否成为算法设计中严肃的经验基线；这一动机源于大语言模型能力快速演进，可能改变运筹优化算法研发的流程。
核心洞察
核心洞察在于，对于定义良好且参数范围清晰的运筹学问题，大语言模型无需针对具体实例调优，仅凭一条描述问题的未调优提示与固定计算预算的代码沙箱，就能生成在多数评估实例上匹配或超越已有专门方法的算法；第二级设定进一步说明这种能力不是对单个实例的过拟合，而是模型从问题类别描述中抽取可复用算法结构的结果，且不同代际模型之间的性能快速提升表明该能力正在迅速增强。
技术挑战
  • 如何让大语言模型仅凭问题类别描述和宽泛参数范围生成可泛化到未见实例的算法
  • 如何在固定计算预算和 Python 沙箱限制下保证生成算法的可执行性与有效性
  • 如何公平比较自动生成的算法与已有专门方法在基准实例上的表现
  • 如何评估模型代际差异对算法设计能力的影响
问题分析
作者通过设计两个层级的评估协议来区分实例级求解与类别级算法设计：第一级将单个问题实例交给模型求解释放其直接求解能力，第二级只给问题类别和参数范围要求模型返回通用算法，从而检验算法是否在见到评估实例前已经固定。作者选取库存控制、排队网络控制和选品优化三个已有近期基准的运筹学问题作为测试领域，并用一条未调优提示和固定计算预算的 Python 沙箱工具控制人类输入与计算资源，最后将最强模型 gpt-5.6-sol 的结果与各领域近期论文报告的最佳方法进行对比。材料未说明作者是否对问题结构、分解、下界或图表示进行进一步分析。
方法
  • 采用两级评估框架：第一级输入单个问题实例，要求模型返回该实例的解；第二级仅输入问题类别描述与宽泛参数范围，要求模型返回从实例参数映射到解的算法。
  • 人类输入最小化：只提供一条描述问题的未调优提示。
  • 模型可使用 Python 沙箱工具，该工具具有固定计算预算。
  • 在第二级中，算法在见到评估实例之前已经生成并固定，用于检验泛化能力。
  • 在库存控制、排队网络控制和选品优化三个问题上使用近期论文中的基准实例进行评估。
  • 将最强测试模型 gpt-5.6-sol 与各问题近期论文报告的最佳方法进行比较。
实验
  • 在库存控制、排队网络控制和选品优化三个问题上使用近期论文的基准实例进行评估。
  • 最强测试模型 gpt-5.6-sol 在几乎所有评估实例上匹配或超越这些论文报告的最佳方法。
  • 第二级设定下，即在看到评估实例之前固定算法，该结论依然成立。
  • 相隔不到八个月发布的模型之间性能提升明显，表明该能力正在快速进步。
