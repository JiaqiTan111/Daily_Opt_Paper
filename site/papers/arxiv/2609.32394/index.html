核心洞察

该工作的核心洞察在于：奖励搜索的效率瓶颈不只是候选生成质量，而是搜索策略能否随评估反馈动态调整。把历次评估的结构化证据（分数、逐项训练曲线、错误回溯）与智能体对失败原因的诊断、下一步意图一起作为持久工作区，使智能体能够用工具主动查询并按需形成下一批候选，而不是从固定提示一次性生成，从而在同等评估预算下把有限训练评估分配给更有希望的候选区域。

为什么值得看：论文提供了一种把昂贵黑盒评估历史显式结构化为“观测+信念”工作区、由 LLM 智能体运行时生成下一批候选的样本高效搜索范式。这一机制与 AI4OR 中“学习辅助搜索”“自动建模/自动设计目标函数”高度同构：在智能优化与生产调度中，目标权重、约束惩罚项或启发式参数的调优同样面临每次评估代价高、预算有限的问题。其消融与预算对齐的比较设计也值得在做算法机制对比时借鉴。需注意其应用域为 RL 控制奖励设计，迁移到调度问题需要重新论证评估接口与搜索空间性质。

研究设定
研究问题是为低层强化学习控制任务自动设计稠密奖励函数；决策对象是每一轮搜索中生成的奖励函数候选（含分项奖励项）；目标是在共享评估预算下提升控制任务表现，并提高奖励搜索的样本效率；关键约束是每次评估候选都需要一次完整的 RL 训练运行，因此评估次数构成昂贵预算；信息假设是智能体可访问由评估预言机维护的评估历史（候选分数、分项训练曲线、错误回溯）以及智能体自维护的信念记录（诊断与下一步意图）；静态或动态环境：材料未说明，仅提及四个控制域。
研究动机
低层强化学习控制的稠密奖励函数设计仍然困难；已有工作用大语言模型在脚本化搜索算法内迭代生成和精炼奖励函数，但每个候选都需要完整训练一次 RL 策略，使样本效率成为复杂控制任务上奖励搜索的核心瓶颈。作者希望突破固定提示、单次生成候选的脚本化流程，让搜索策略本身在运行时根据历史反馈自适应构建。
核心洞察
该工作的核心洞察在于：奖励搜索的效率瓶颈不只是候选生成质量，而是搜索策略能否随评估反馈动态调整。把历次评估的结构化证据（分数、逐项训练曲线、错误回溯）与智能体对失败原因的诊断、下一步意图一起作为持久工作区，使智能体能够用工具主动查询并按需形成下一批候选，而不是从固定提示一次性生成，从而在同等评估预算下把有限训练评估分配给更有希望的候选区域。
技术挑战
  • 每个候选奖励函数需要完整 RL 训练才能评估，评估代价高、预算有限
  • 奖励搜索空间大且搜索信号稀疏，需要有效利用历史评估信息
  • 如何把分数、训练曲线、错误回溯等多模态异构反馈组织为可查询的记忆
  • 如何让搜索策略在运行时自适应而不是依赖固定脚本
  • 在共享评估预算下与脚本化搜索基线进行公平比较
问题分析
材料未说明作者对问题结构的具体理论分析；从摘要可见其分析路径是把奖励搜索视为黑盒优化问题，将评估历史显式结构化为评估预言机维护的观测（候选分数、逐项训练曲线、错误回溯）和智能体维护的信念（诊断与下一步意图），并以此作为搜索策略生成的依据。
方法
  • 提出 Agentic Reward Black-box Optimization（ARBO）框架，用一个 LLM 智能体在运行时构建搜索策略
  • 维护持久工作区形式的评估历史，包含两个组成部分：评估预言机维护的观测（候选分数、逐项训练曲线、错误回溯）与智能体维护的信念（诊断与下一步意图）
  • 智能体通过工具查询上述两类信息，并据此生成下一批奖励候选，而非从固定提示单次生成
  • 将奖励候选评估视为黑盒函数调用，在共享评估预算下进行搜索
  • 通过消融实验考察各组成部分的贡献以及对骨干模型选择的敏感性
实验
  • 在四个控制域上评估 ARBO
  • 相对基线均值，在共享评估预算下实现操作任务成功率提升 29.9%、电网分数提升 192.8%
  • 通过消融实验考察各组成部分的贡献及对骨干模型选择的敏感性
