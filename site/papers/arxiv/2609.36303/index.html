研究设定
研究面向必须在严格运行时间预算内获得高质量解的数学优化问题，决策对象是完整的求解器增强混合算法，包括选用哪些启发式与求解器组件、它们的执行顺序与子目标、以及在共享运行时间预算下各阶段的计算分配；目标是在紧时间预算下最小化相对强基线的目标差距；关键约束是总执行时间预算（实验中为两分钟）以及各组件调用的可行性；信息假设为可以访问问题实例与执行反馈，但材料未说明训练与测试实例的分布假设是否显式给出；环境为静态的离线算法发现过程，而非在线动态调度环境。
研究动机
实际生产中高质量解只有在能及时获得时才有价值，因此需要结合问题特定启发式与数学规划求解器。然而已有自动启发式设计方法通常只在固定算法框架内改进单个启发式组件，或仅调优求解器配置，无法整体决定计算如何分配、如何利用求解器以及如何改进整体算法结构。
核心洞察
贡献之所以有效，在于将完整的求解器增强混合算法本身作为一等的搜索变量，而不是只搜索启发式组件或求解器参数：高层计划显式表达组件选择、组合与运行时间分配，代码实现与共享组件池同时被进化，从而让执行反馈既能修正算法结构又能修正实现，避免了结构固定或实现固定带来的局部最优。
技术挑战
  • 如何在高维、离散的组件选择、执行顺序与运行时间分配空间中进行有效搜索
  • 如何将高层算法计划可靠地落地为可执行代码
  • 如何在多个岛屿之间共享可复用组件并避免过早收敛
  • 当代码级改进停滞时如何触发并执行算法结构层面的修订
  • 如何在紧时间预算下公平评价候选算法
问题分析
作者将自动启发式设计形式化为对完整求解器增强算法的显式搜索：算法计划选择启发式与求解器组件、指定执行顺序与子目标并在它们之间分配共享运行时间预算，使算法组合成为一等搜索变量。方法通过岛屿式进化框架维护多个半独立种群以保持搜索轨迹多样性并减少过早收敛，使用执行结果作为反馈：代码进化在当前计划下改进实现，自适应计划评审在代码级进展停滞时修订算法结构，组件进化利用跨岛屿积累的执行经验精炼可复用组件。材料未说明是否使用下界或图表示等额外问题结构分析。
方法
  • 将混合优化算法表示为可进化的计划，计划包含组件选择、组合方式、执行顺序、子目标与运行时间分配。
  • planner 决定使用哪些算法组件、如何组合它们以及如何在各阶段间分配运行时间。
  • coder 将计划实现为可执行代码。
  • component evolver 更新共享的可复用组件池。
  • 在岛屿式进化框架中，计划与实现共同进化，并由 interpreter agent 分析执行结果、识别改进机会。
  • 代码进化改进当前计划下的实现；自适应计划评审在代码级进展停滞时修订算法结构；组件进化利用跨岛屿积累的执行经验精炼组件。
实验
  • 在 11 个合成任务、6 个 MIPLIB-NL 派生问题和 4 个非线性几何族上评估。
  • 合成任务上，HeurEvo 相对 Gurobi 的 48 小时 incumbent 在训练实例上取得 −2.22% 的平均 gap，在留出测试实例上取得 −1.45%。
  • 在这些 incumbent 上，HeurEvo 在八个训练任务和七个测试任务上超过它们。
  • 在 MIPLIB-NL 问题上，HeurEvo 在六个训练问题中的四个上改进 AdaEvolve。
  • 非线性几何方面，将 HeurEvo 阶段与后续 AdaEvolve 精炼结合，产生若干数值上优于已报告参考值的目标值。
  • 在 hexagon packing 等非线性几何问题上，改进了此前报告的最优结果。
  • 消融研究表明自适应计划修订与组件进化的结合带来收益；默认使用完整组件库生成的五个不同初始计划，取得最低训练 gap（−2.22%），分别比替代方案改善 0.91、0.46 和 0.81 个百分点。
  • 实验中执行预算为两分钟，并与竞争性的大模型进化基线以及 Gurobi 48 小时解比较。

HeurEvo 是一个计划-代码-组件共同进化框架，联合进化高层算法结构、其实现和共享的可复用组件池。：we propose HeurEvo, an automated plan–code–component co-evolution framework that jointly evolves the high-level algorithmic structures, their implementations, and a shared pool of reusable components.
planner 决定使用哪些组件、如何组合以及如何在阶段间分配运行时间，coder 将计划实现为可执行代码，component evolver 更新共享组件池。：A planner determines which algorithmic components to use, how to combine them, and how to allocate runtime across stages, a coder realizes the resulting plan as executable code, while a component evolver updates the shared component pool.
在岛屿式进化框架中，计划与实现借助 interpreter agent 的执行反馈共同进化。：Within an island-based evolutionary framework, plans and implementations co-evolve with feedback from an interpreter agent that analyzes execution results and identifies opportunities for improvement.
HeurEvo 在紧运行时间预算内找到高质量解，常常匹配或超过给定数小时或数天计算的先进求解器。：HeurEvo finds high-quality solutions within tight runtime budgets, often matching or surpassing state-of-the-art optimization solvers given hours or days of computation.
