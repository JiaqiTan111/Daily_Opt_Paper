LLM-Guided Transportation Hub Capacity Planning with Textual Business Inputs

Xiaoyue Liu · Zheng Dong

核心洞察

贡献的有效性不在于让 LLM 直接求解优化问题，而在于把 LLM 定位为“语境桥梁”：先由思维链把每条业务语境映射为容量调整的方向与幅度并形成结构化决策表，再由优化模型给出基于路由的性能反馈来筛选和修正候选决策，使定性信息以可验证的方式进入定量优化回路。

为什么值得看：对关注大模型智能体如何与数学规划/优化求解器结合的研究者有参考价值：它展示了把 LLM 限定在语境解析与候选生成、把可行性评估交由优化模型的职责划分，并以真实网络上的最优性差距对比说明收益；同时提示需关注评价基准（隐藏真值）与公平计算预算问题。

研究设定
研究运输枢纽容量规划问题：决策对象是各枢纽的容量调整方案，目标是在满足路由与网络性能的前提下逼近隐藏的真实最优容量；关键约束与网络结构细节材料未说明；信息假设是除定量输入外还存在自然语言描述的业务背景（定性上下文），传统模型无法消化；环境为静态规划场景，基于美国东南部真实 13 枢纽货运网络。
研究动机
传统枢纽容量规划模型只对定量输入有效，难以吸收定性业务语境，导致规划结果与真实业务需要偏离；作者希望把自然语言业务洞察接入运筹优化流程。
核心洞察
贡献的有效性不在于让 LLM 直接求解优化问题，而在于把 LLM 定位为“语境桥梁”：先由思维链把每条业务语境映射为容量调整的方向与幅度并形成结构化决策表，再由优化模型给出基于路由的性能反馈来筛选和修正候选决策，使定性信息以可验证的方式进入定量优化回路。
技术挑战
  • 如何把非结构化自然语言业务描述转成可执行的容量调整量
  • 如何判断 LLM 提议的容量决策在路由与网络层面是否可行、有效
  • 如何在缺乏真实最优解（hidden ground-truth）的情况下评价与引导智能体选择
问题分析
作者将问题拆为“语境理解”与“定量评估”两层：LLM 智能体负责把上下文条目逐条映射为容量调整，形成结构化决策表以显式化推理；优化模型作为评估器，计算路由相关的性能指标并回传给智能体，据以迭代选择新容量决策。材料未说明是否使用下界、分解或图表示等进一步的问题结构利用方式。
方法
  • LLM 智能体迭代提出枢纽容量决策，输入为自然语言业务背景描述
  • 采用思维链推理协议，构建结构化决策表，将每个语境条目映射为具体容量调整，依据隐含的变化方向与幅度
  • 新容量决策通过反馈回路交由优化模型验证，优化模型返回基于路由的性能指标
  • 智能体依据反馈指标迭代选择下一轮容量决策
实验
  • 在真实的美国东南部 13 枢纽货运网络上评估
  • 相对隐藏的真实最优解达到 2.8% 的最优性差距
  • 未引入文本业务输入的传统优化模型差距为 11.0%
  • 摘要未给出基线数量、训练开销、计算预算、消融与泛化实验的细节

证据与不确定性

仅有标题与摘要，缺少问题形式化、优化模型细节、反馈指标定义、智能体提示设计与迭代停止条件，也未知实验的重复性与计算开销，因此对方法可复现性和结论稳健性的判断存在较大不确定性。

论文提出由 LLM 智能体依据自然语言业务语境迭代提出枢纽容量决策，并与优化模型构成反馈闭环：We propose a novel framework where a large language model (LLM) agent iteratively proposes hub capacity decisions guided by natural-language business context descriptions.
核心机制是思维链协议构建把语境条目映射为容量调整的结构化决策表：The key mechanism is a chain-of-thought reasoning protocol: the LLM constructs a structured decision table that maps each contextual item to specific capacity adjustments based on the implied direction and magnitude of changes.
优化模型通过路由性能指标验证并引导智能体选择：The new capacity decision is then validated through a feedback loop with an optimization model, which provides routing-based performance metrics to guide the agent's selection.
在 13 枢纽真实货运网络上达到 2.8% 最优性差距，优于无文本输入传统模型的 11.0%：On a real-world 13-hub freight network in the southeastern US, our framework achieves a 2.8% optimality gap relative to the hidden ground-truth, a significant improvement over the 11.0% gap produced by the traditional optimization model without textual business inputs.
