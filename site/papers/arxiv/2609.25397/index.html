研究设定
研究问题为一维装箱问题（1D-BPP）：将 n 个已知重量 w_i 的物品装入容量为 C 的相同箱子中，使所用箱子数最少且每箱总重不超过 C。决策对象是装箱过程中如何将两个可兼容的部分箱合并，直至无法继续合并。目标是最小化装箱数，关键约束为容量约束与物品不可拆分。信息假设为物品重量与容量均已知且离线，环境为静态组合优化环境，材料未说明动态扰动或在线到达设定。
研究动机
1D-BPP 是物流、制造与云资源管理中的核心 NP-hard 问题，精确方法难以扩展到大规模或结构困难实例，而多数学习型装箱方法面向 2D/3D 变体，针对 1D-BPP 的智能学习求解器仍很稀缺。作者希望构建一个端到端、尺寸无关的学习求解框架，在无需逐实例搜索、无需人工设计交叉变异或修复算子的情况下超越构造启发式并在部分结构族上比肩求解器增强方法。
核心洞察
作者的核心洞察在于用物品兼容图作为状态的结构化知识表示：动作被定义为合并两个彼此兼容（重量之和不超过容量）的部分箱，而非逐物品插入。这种成对合并表示把容量可行性直接编码为图的边，使 GNN actor–critic 能从关系结构中提取特征，并让单一训练模型在任意规模实例上零样本泛化；同时，随机束搜索在解码阶段补偿成对贪心合并留下的残差间隙。
技术挑战
  • 1D-BPP 是 NP-hard，精确方法在大规模或紧容量结构实例上开销急剧增长
  • 多数学习型装箱方法面向 2D/3D，1D-BPP 的学习求解器稀缺
  • 逐物品级别的编码在元启发式中容易违反容量约束，需要频繁修复
  • 让单一模型零样本泛化到任意规模实例
  • 成对、构造式学习层面的残差间隙难以通过调参消除
问题分析
作者将装箱过程建模为物品兼容图上的马尔可夫决策过程，用图结构编码容量兼容关系；在此基础上使用图神经网络 actor–critic 策略提取关系特征，并以 PPO 训练、随机束搜索解码。作者通过对图编码器、DRL 算法、奖励函数、训练分布与超参数的系统实验分析设计选择，并在 BPPLIB 全部九族上对比构造启发式、分组遗传算法与近期学习型求解器，进而定位残差间隙来源于学习作用于成对构造层面而非调参。
方法
  • 将 1D-BPP 的装箱过程形式化为物品兼容图上的马尔可夫决策过程，图中边表示两个部分箱可合并（重量之和不超过容量）。
  • 每个动作合并两个互相兼容的部分箱，形成新的部分箱，作为状态转移。
  • 使用图神经网络 actor–critic 策略从兼容图表示中提取关系特征；编码器为 GCN，L=3 层，维度 d=128，带残差与 LayerNorm，dropout 0.1。
  • actor 与 critic 为 MLP：actor 输入 2d 经 128→64→1，critic 输入 d 经 128→64→1。
  • 使用 PPO 训练，ε=0.2，c_v=0.5，c_e=0.01，K=4 个内部 epoch，Adam 优化器学习率 3×10^-4，梯度范数裁剪 1.0，折扣 γ=1（有限时域）。
  • 训练数据为 n=50、C=100、权重取自 U{1,…,100} 的合成实例，训练预算为 2,000 个 epoch × 16 个 episode，训练种子为 42。
  • 解码阶段使用随机束搜索，每个实例用三个解码种子 {0,1,2} 求解，报告种子平均箱数对应的间隙，最优计数默认取种子 0。
  • 唯一的問題专用组件是定义边的兼容规则，可通过修改该规则适配约束变体。
实验
  • 在 BPPLIB 全部九个族、共 1,615 个实例上进行零样本评估，使用三个解码种子。
  • 指标为每个实例的最优性间隙 (b/opt − 1)×100%，其中 b 为方法使用的箱数，opt 为 BPPLIB 给出的最优或已知最好箱数；报告每族的均值与标准差、求解到最优的实例数、以及相对 FFD 使用更少或更多箱的实例数。
  • 基线包括构造式启发式（FFD）、分组遗传算法（GGA），以及近期学习型方法：Shi 等人的 bipartite-GCN 结合列生成（BGCN、BGCNMC）和其报告的三类 RL 基线（PTR、HRL-GPN、RRMCTS）。
  • 相对构造启发式 FFD，所提数据驱动策略将平均最优性间隙从 2.66% 降至 2.31%，增益集中在结构化实例上。
  • 与在同一基准上评估的学习型基线相比，所提方法在九个族中的多数上取得更低间隙，且跨实例分布更稳定；在最难的基准族上，它不依赖任何求解器即超过依赖列生成与整数规划的最优学习型求解器。
  • 分组遗传算法总体上仍领先，作者分析了残差间隙的来源。
  • 作者进行了跨图编码器、DRL 算法、奖励函数、训练分布与超参数的系统实证研究与消融，最终配置基于分布内验证数据选定。
  • 材料未说明训练开销的绝对时间、硬件细节或与基线在相同计算预算下的详细公平性对照。
局限
  • 当允许少量额外箱时 FFD 仍是首选，当需要最高质量时应用分组元启发式，所提方法位于二者之间。
  • 灵活性带来计算代价，材料指出尽管尺寸无关 GNN 策略取得有竞争力的结果且无需手工设计算子，但仍存在计算成本。
  • 作者明确将残差间隙归因于学习作用于成对、构造式层面而非调参。
与你的研究关系
该论文直接研究一维装箱这一经典组合优化问题，其核心方法——将可行合并关系编码为图、用 GNN actor–critic 学习构造策略并以束搜索解码——与学习辅助搜索、图神经网络求解组合优化、强化学习用于生产调度与装箱类问题高度相关。其零样本跨规模泛化与端到端无求解器的定位，可为柔性作业车间、流水车间、分布式制造中的分组与资源分配决策提供借鉴。迁移到生产调度需要把兼容边规则重新设计为工序—机器或任务—时段的可合并/可分配关系，并处理时间窗、顺序与设备能力等额外约束；这些属于推测，需进一步验证。
