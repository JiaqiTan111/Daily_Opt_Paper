定向以增广多样性：用于自动启发式设计的多方向搜索

Directing to Diversify: Multi-Directional Search for Automatic Heuristic Design

Jianghan Zhu · Jianan Zhou · Fei Liu · Ni Zhang · Yaoxin Wu · Zhuoyi Lin · Zhiguang Cao

核心洞察

启发式质量并不随结构复杂度单调变化：过简可能表达力不足，过繁可能臃肿、昂贵或过拟合。因此把启发式变换分解为扩张（增强表达力与结构丰富度）、压缩（去除过度特化与冗余）和微调（围绕有希望的结构做细粒度修正）三个互补方向，可将“多样性”从选择后的被动结果变为生成时可控的搜索原语，从而更广且更持久地覆盖设计空间中的不同区域。

为什么值得看：对关注 AI4OR 与自动算法设计的研究者，该文提供了一个把“多样性”显式嵌入生成过程的机制范例：方向化扰动算子、思想层与实现层分离、BFS 前沿保留与 UCB 算子控制，这些机制可被借鉴到生产调度规则的自动生成与学习辅助搜索中；其对评估成本与控制器手工规则的局限反思，也直接对应调度场景下仿真评估昂贵、约束可行性难保证的实际痛点。

研究设定
研究问题是在无人工干预下为 NP-hard 组合优化任务自动生成高质量启发式算法；决策对象是启发式算法的思想及其可执行代码实现；目标是在有限评估预算内搜索启发式设计空间，并兼顾解质量与设计多样性；约束包括生成结果必须可执行并且语义连贯，以便进行黑箱评估，同时受到 BFS 深度与评估预算限制；信息假设是：LLM 可以在给定父代启发式与方向指令时完成定向扰动与重写，并通过验证集得分评估候选；静态或动态环境材料未说明，摘要与节选仅描述离线迭代搜索过程。
研究动机
现有基于进化计算的 LLM 自动启发式设计主要依靠种群管理、候选选择、相似度度量或搜索空间划分来间接促成多样性，启发式的变化方向由通用变异、交叉、反思或新颖性压力自发涌现，缺少在生成层面显式控制搜索方向的手段，因此容易过早聚集到狭窄的设计族。
核心洞察
启发式质量并不随结构复杂度单调变化：过简可能表达力不足，过繁可能臃肿、昂贵或过拟合。因此把启发式变换分解为扩张（增强表达力与结构丰富度）、压缩（去除过度特化与冗余）和微调（围绕有希望的结构做细粒度修正）三个互补方向，可将“多样性”从选择后的被动结果变为生成时可控的搜索原语，从而更广且更持久地覆盖设计空间中的不同区域。
技术挑战
  • 在生成层面显式定义并控制启发式的变化方向，而非依赖通用 EC 算子
  • 在扰动思想与重写为可执行代码之间保持语义一致性与可执行性
  • 在有限评估预算下平衡利用当前最优启发式与探索其他父代，避免早熟收敛
  • 自适应探索控制器仍依赖预定义的调度规则与停滞阈值
  • 每个扰动想法都需先实现为代码再评估，评估成本高
问题分析
作者将问题结构化为“启发式思想层”与“实现层”的分离：先在思想层施加定向扰动，再由 LLM 重写为可执行候选，从而把算法层面的修改意图与底层实现细节解耦，使结构变化可控且仍可黑箱评估。搜索组织上采用 BFS，逐层扩展当前前沿父代，按验证集平均性能评估同层子代，并用 softmax 采样保留下一层前沿（当前最优候选保留概率为 1），以兼顾候选充分利用与持续探索；父代选择采用 ε-greedy（ε=0.5）在池中当前最优与其余启发式之间权衡；自适应算子控制基于 UCB 选择扰动算子，并在停滞时重启。
方法
  • 多方向扰动算子：Expansion 提示 LLM 引入额外决策信号、交互、条件规则或自适应机制并说明其对决策的影响；Compression 简化自适应阈值与全局加权等逻辑、去除过度特化；Steering 做细粒度精修。
  • 扰动—重写两阶段：对父代启发式 h_p 先施加方向性扰动得到修改后的启发式思想，再由 LLM 重写为可执行代码候选。
  • BFS 搜索：以当前池中最优启发式 h* 为根（概率 1-ε），其余按 ε/(|P|-1) 选择；每个非终止前沿父代选择一个扰动算子生成子代，同层子代按验证集平均性能评估，再以“最优保留 + softmax 采样”确定下一层前沿。
  • 终止与合并：达到最大树深或评估预算耗尽时终止；每棵 BFS 树完成后将存活前沿并入启发式池，保留最优并随机采样其余成员以维持多样性。
  • 自适应探索控制器：UCB 算子选择与停滞重启，用于平衡探索与利用。
  • 实验分析包含 LLM 成本分析、关键超参数敏感性、不同扰动方向与 ID/OOD 性能关系、各方向算子在不同问题设置下的贡献分析，以及 TSP/TSPLib、黑箱设置和跨 LLM 基准测试。

  • 其他设置：TSP 与 TSPLib、黑箱设置、跨不同 LLM 的基准测试；节选未提供相应数字。
  • 公平计算预算、约束可行性统计、训练或评估开销的完整量化材料未说明。
局限
  • 自适应探索控制器仍依赖预定义的调度规则与停滞阈值；虽然 UCB 算子选择能适应近期搜索结果，但整体探索调度与重启行为由人工指定，可能限制跨任务与跨搜索阶段的灵活性。
  • 启发式评估成本高：PRS 需先把每个扰动想法实现为可执行代码再评估，而并非每个想法都值得实现与昂贵评估，在大规模实例或计算昂贵的优化环境下尤为突出。
  • 作者提出的未来方向包括由 LLM 智能体自主决定算子选择、探索调度与停滞响应，以及引入替代模型（如学习的世界模型）在实现前估计扰动想法的潜在效用。
与你的研究关系
论文事实：该工作面向 NP-hard 组合优化，用 LLM 在生成层面定向搜索启发式，并与 BFS 及自适应算子控制结合，属于 AI 驱动运筹优化中“学习辅助搜索/自动算法设计”的方向。迁移设想（推测）：其多方向扰动（扩张/压缩/微调）与 BFS 前沿保留机制原则上可迁移到柔性作业车间、流水车间、分布式制造、生产运输协同等调度问题的启发式或规则自动设计中，但需要满足若干条件——调度问题需有可快速评估的仿真或验证实例集；启发式需能以代码或规则形式被 LLM 重写并保持可行性；需给出与约束可行性、多目标权衡相匹配的评估函数；并且需要在公平评估预算下重新调参 ε、BFS 深度与 UCB 停滞阈值。该迁移仅为推测，并非作者结论。
