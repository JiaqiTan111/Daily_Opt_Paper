通过求解器接地的自博弈学习优化建模

Learning to Optimize through Solver-Grounded Self-Play

Xia Jiang · Yaoxin Wu · Chenyu Zhou · Mengzhu Xu · Wim P.M. Nuijten · Yingqian Zhang

核心洞察

核心洞察在于：将优化建模任务的训练信号从静态数据集中解放出来，改为由外部求解器的执行反馈驱动一个生成与求解的闭环。Proposer 不断生成更难且有效的优化问题，Solver 在仅给定自然语言描述的条件下尝试建模求解，两者共享同一个 LLM 的参数并交替用强化学习更新。由于问题难度随 Solver 能力提升而自动加码，形成了一个自动课程，使得监督信号始终处在模型当前能力的边界上，从而同时缓解泛化天花板和能力锚定。

为什么值得看：对于研究智能优化和生产调度中自动建模、LLM 辅助求解的研究者，该论文提供了一种不依赖人工标注数据的自博弈训练范式，其求解器接地和自动课程思想可被借鉴到调度问题的自动形式化与求解中。同时，论文对泛化性和能力锚定的讨论对构建可扩展的 AI4OR 系统具有方法论参考价值。

研究设定
论文研究的是如何在不依赖人工标注或教师模型生成数据的前提下，训练大语言模型自动将自然语言描述的优化问题转化为数学规划模型并生成求解代码。决策对象是 LLM 的建模与求解策略；目标是提升模型在多种优化建模基准上的求解正确率与泛化能力；关键约束包括训练数据必须零外部标注、模型输出须能被外部求解器（如 Gurobi、CPLEX）执行验证；信息假设是只有外部求解器的执行反馈作为奖励信号，环境是交替训练 Proposer 与 Solver 的静态基准评测环境，材料未说明是否涉及在线动态环境。
研究动机
现有 LLM 优化建模训练范式依赖人工标注或教师模型生成的数据集，这带来了两个瓶颈：一是泛化天花板，模型容易过拟合到狭窄的数据分布；二是能力锚定，模型的推理能力被标注者水平或教师模型能力所限制。作者希望摆脱这种数据依赖，用自博弈机制让模型自己生成训练信号。
核心洞察
核心洞察在于：将优化建模任务的训练信号从静态数据集中解放出来，改为由外部求解器的执行反馈驱动一个生成与求解的闭环。Proposer 不断生成更难且有效的优化问题，Solver 在仅给定自然语言描述的条件下尝试建模求解，两者共享同一个 LLM 的参数并交替用强化学习更新。由于问题难度随 Solver 能力提升而自动加码，形成了一个自动课程，使得监督信号始终处在模型当前能力的边界上，从而同时缓解泛化天花板和能力锚定。
技术挑战
  • 零外部训练数据下如何获得稳定可用的奖励信号
  • Proposer 生成的问题必须数学有效且能被求解器执行
  • 避免自博弈中两个角色陷入退化或相互欺骗
  • 在共享参数下交替训练两个角色时保持训练稳定性
  • 奖励信号仅来自求解器执行反馈，可能稀疏或噪声较大
问题分析
作者通过将优化建模训练重构为自博弈问题来分析：把数据依赖问题转化为奖励信号来源问题，指出静态数据集会导致分布过窄和能力锚定。随后利用外部求解器的执行反馈作为客观 ground truth 来替代人工标注，将问题生成与问题求解建模为一个闭环博弈，通过共享参数和交替 RL 更新实现两个角色的共同进化，并借助自动课程让训练难度与模型能力同步增长。
方法
  • 使用单个 LLM 承担双重角色：Proposer 负责合成优化问题及其数学形式化与求解代码，Solver 负责仅根据自然语言问题描述进行建模与求解。
  • Proposer 和 Solver 共享同一个基础 LLM 的参数，在同一闭环中交替训练，形成互相增强的流水线。
  • 以外部优化求解器（如 Gurobi、CPLEX）的执行反馈作为奖励信号，接入强化学习来更新两个角色的策略。
  • 训练过程中形成自动课程：Proposer 学会生成更有效且更难的问题，Solver 随之提升建模能力以解决更难问题。
  • 材料未说明具体的强化学习算法细节、网络结构或状态动作空间定义。
实验
  • 在六个基准上评估平均性能，并与依赖标注数据的方法进行比较，显示在零标注数据下性能可匹配甚至超越部分数据依赖方法。
  • 消融实验表明 Solver-only 训练明显弱于联合训练（75.1 vs. 81.6 Macro Avg.），说明 Proposer 训练为 Solver 提供了更有信息量的问题实例。
  • 在附录 F.8 中报告了方法在不同架构和规模 LLM 上的增益持续性，表明改进不局限于特定基础模型。
  • 材料未提供具体的数据规模、运行时间、训练开销、公平计算预算或约束可行性的详细数字。
局限
  • 未来工作包括将框架扩展到更广泛的问题类，如非线性规划和随机规划，说明当前方法主要针对特定类型的问题。
  • 需要开发更精细的奖励机制（例如训练奖励模型）来更好地评估 Proposer 和 Solver 的输出。
  • 计划将求解器调用代码生成与自动启发式发现结合以进一步提升优化性能，暗示当前尚未集成这一能力。

论文提出首个完全自博弈的优化建模训练框架，无需外部训练数据。：In response, we propose OPT-Zero, the first fully self-play training framework for optimization modeling that requires zero external training data.
使用单个 LLM 承担 Proposer 和 Solver 双重角色，并通过外部求解器执行反馈进行强化学习。：OPT-Zero employs a single LLM in a dual-role closed loop: a Proposer that synthesizes increasingly challenging optimization problems alongside their mathematical formulations and solving code, and a Solver that attempts to resolve the problems given only natural-language problem descriptions.
自博弈形成自动课程，Proposer 和 Solver 共同进化，零标注数据下可匹配甚至超越依赖数据的方法。：Extensive results indicate that with zero curated data, OPT-Zero matches state-of-the-art data-dependent methods while exhibiting substantially stronger generalizability, establishing self-play training as a highly scalable paradigm for advancing LLM reasoning in modeling and solving optimization problems.
消融实验显示仅训练 Solver 弱于联合训练，表明 Proposer 训练为 Solver 提供更有信息量的问题实例。：Solver-only training underperforms joint training by a clear margin (75.1 vs. 81.6 Macro Avg.), suggesting that Proposer training supplies more informative problem instances for Solver improvement.
