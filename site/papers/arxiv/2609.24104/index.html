面向车辆路径问题中学习引导局部搜索的基于行为小生境遗传规划

Genetic Programming with Behaviour-based Niching for Learning Guided Local Search in Vehicle Routing Problems

Saining Liu · Yi Mei · Mengjie Zhang

核心洞察

该工作的核心洞察在于：GPGLS中的个体是搜索启发式而非直接路径解，因此其多样性不应仅由适应度或树结构刻画，而应由局部搜索过程中实际诱导的算子级行为来刻画。将搜索行为压缩为六个算子描述符并按行为得分分层，可以从每一层中选出适应度有竞争力且树规模紧凑的代表构成当代档案；以档案个体作为父代参与繁殖，相当于在不改变路径适应度定义的前提下，为种群引入行为上互补的遗传物质。适应性策略则依据训练适应度和标准化行为离散度信号决定是否激活档案父代，从而在需要时补充行为多样性、在收敛稳定时避免过度扰动。作者也明确指出，树规模下降不能单独归因于行为表示。

为什么值得看：该论文关注学习辅助搜索中的多样性管理与程序膨胀问题，提出用搜索行为而非仅适应度来组织种群，并给出了固定与自适应档案使用策略的对比。对于研究进化算法与局部搜索结合、学习型超启发式以及如何在约束可行性之外维持搜索多样性的读者，其行为描述符与分层档案的设计思路具有参考价值；同时作者对结论边界和未量化开销的明确说明，也有助于理解该类方法在公平计算预算与可复现性上的评估要求。

研究设定
论文研究带容量约束的车辆路径问题（CVRP），决策对象是引导局部搜索（GLS）中用于对不可取解特征施加自适应惩罚的效用函数，目标是在给定计算预算内构造服务全部客户且满足车辆容量与路径可行性约束的路线并最小化路径成本。效用函数由遗传规划以GP树形式进化，评估器将个体与训练实例映射为基于初始与最终解成本的适应度。实验使用生成的200客户欧氏距离实例，训练集与监控集各含90个实例，覆盖三种客户位置分布、六种需求分布和五种平均路径规模类别。所有方法使用匹配的30个随机种子和相同的18个五实例批次序列。环境为静态离线训练，材料未说明在线或动态扰动设置。
研究动机
GPGLS作为学习型超启发式能自动进化GLS效用函数，但继承遗传规划的搜索停滞与程序膨胀问题。仅以适应度管理种群多样性并不充分，因为进化出的程序可能适应度相近却诱导出不同的搜索行为。作者希望用程序在局部搜索过程中表现出的行为特征来维护种群多样性，从而在解质量与程序规模之间取得更好的权衡。
核心洞察
该工作的核心洞察在于：GPGLS中的个体是搜索启发式而非直接路径解，因此其多样性不应仅由适应度或树结构刻画，而应由局部搜索过程中实际诱导的算子级行为来刻画。将搜索行为压缩为六个算子描述符并按行为得分分层，可以从每一层中选出适应度有竞争力且树规模紧凑的代表构成当代档案；以档案个体作为父代参与繁殖，相当于在不改变路径适应度定义的前提下，为种群引入行为上互补的遗传物质。适应性策略则依据训练适应度和标准化行为离散度信号决定是否激活档案父代，从而在需要时补充行为多样性、在收敛稳定时避免过度扰动。作者也明确指出，树规模下降不能单独归因于行为表示。
技术挑战
  • 传统小生境方法直接应用于GPGLS并非易事，材料在此处被截断，未给出完整论述。
  • 如何在适应度之外定义并收集能够区分搜索行为的算子级描述符。
  • 如何从行为得分分层中选出既适应度有竞争力又紧凑的代表，构成当代的档案。
  • 如何设计固定与自适应策略来决定档案父代的使用时机，避免破坏搜索收敛。
  • 行为描述符的收集、批聚合与缩放、排序以及自适应成对离散度计算会引入额外开销，且材料指出未做受控计时分解，无法量化实际开销。
  • 在解质量差异很小的情形下，如何判断行为小生境带来的收益与权衡。
问题分析
作者将GPGLS视为两层学习到优化架构：底层GLS评估器在训练实例上执行局部搜索并返回基于初始与最终解成本的适应度，上层遗传规划按该反馈进化效用函数。分析从个体是搜索启发式这一前提出发，指出仅凭适应度无法区分诱导不同搜索行为的程序，因此把程序的行为刻画为局部搜索过程中收集的六个算子级描述符，再对行为得分分层。每一层中依据适应度与紧凑性选出代表，重构为当代档案，并使用固定或自适应策略将档案个体作为父代。适应性策略利用训练适应度和标准化行为离散度信号，可选地加入树规模条件。材料未说明作者是否使用了分解、下界或图表示等分析工具。
方法
  • 在GPGLS框架下保持初始化和局部搜索算子固定，仅进化GLS效用函数，个体表示为GP树。
  • 在局部搜索过程中收集六个算子级描述符，用以刻画每个程序诱导的搜索行为。
  • 以行为得分进行分层，从每一层中选出适应度有竞争力且树规模紧凑的代表，重构当代档案。
  • 固定策略持续使用档案父代；自适应策略依据训练适应度和标准化行为离散度信号激活档案父代，并可选用树规模条件。
  • 父代选择：当激活概率为0.20时，分别以独立的适应度锦标赛选择76个种群父代和19个档案父代；否则以适应度锦标赛选择95个种群父代；随后打乱父代并施加交叉与变异。
  • 训练后保存每一代训练适应度最好的个体，并在全部90个监控实例上评估；最终选取末代最优个体做最终评估。
实验
  • 在生成的200客户容量约束VRP实例上，使用遵循XML100与Uchoa基准框架设计因子的生成器，每个90实例集合覆盖三种客户位置分布、六种需求分布和五种平均路径规模类别，仓库位置随机，训练集与监控集为同一因子组合的独立实现。
  • 比较四种基于行为的变体、一个无档案的GPGLS对照以及基于适应度的小生境方法，在30个匹配随机种子上运行；训练实例用调度种子2026打乱一次，分为18个不重复的五实例批次，所有运行与方法共用同一批次序列。
  • 每个方法每代保存训练适应度最好的个体，训练后在全部90个监控实例上评估，得到每次运行18个监控块；最终评估使用末代最优个体。
  • BN-Adaptive在独立的90实例监控集上取得最佳描述性平均排名；总体路径成本差异很小；BN-SizeAware原始成本最低。
  • 五种档案策略的最终种群树规模中位数都低于GPGLS对照，配对Wilcoxon比较经Holm校正后仍显著。
  • 作者说明这些结果仅表明在所评估设定下存在有用的解质量与程序规模权衡，不将树规模下降单独归因于行为表示。
  • 材料未给出具体数值、运行时间、训练开销或计算预算的受控对比，也未提供消融实验的定量结果。
局限
  • 作者明确说明结果支持的是在所评估设定下的有用权衡，而非普遍的路径优越性，也不是树规模下降仅由行为表示解释。
  • 作者指出未进行受控计时分解，因此无法量化描述符收集、批聚合与缩放、排序和自适应成对离散度带来的实际开销或客户规模下的性能。
  • 未来工作需要研究时间性描述符与算子转移、参数敏感性、受控组件比较、激活条件轨迹，以及更大或不同分布的路径实例；跨代档案和直接计算开销测量也需进一步研究。
  • 材料在讨论直接应用传统小生境的困难处被截断，相关完整论述未提供。
