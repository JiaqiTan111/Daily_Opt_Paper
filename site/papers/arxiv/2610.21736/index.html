In-Context Preference-Conditioned Pareto Set Learning from Limited Offline Data

Yiming Yao · Liang Zhao · Qingfu Zhang

核心洞察

核心洞察在于把偏好条件的 Pareto 解模型本身视为可由先验知识快速生成的产物：通过在大规模多样合成先验数据上预训练一个基础式超网络，使其具备上下文学习能力，从而能在单次前向传播中为未见离线问题生成问题特定、偏好条件的 Pareto 解模型。该生成的模型可复用，对任意偏好直接预测，无需问题特定训练或逐偏好搜索，使跨偏好与跨问题的摊销成为可能。

研究设定
研究面向多目标优化中偏好条件 Pareto 集学习问题：给定用户指定的偏好，直接映射到对应的 Pareto 最优解，而非返回有限个折中解。关键约束是必须在离线条件下进行，不能进一步调用目标函数评估，仅有覆盖决策空间和目标空间较为稀疏的有限静态数据集。信息假设为可访问大量多样的合成先验数据用于预训练，并给定未见问题的离线观测。环境是静态离线场景，动态扰动未说明。
研究动机
实际多目标优化常需在离线、无额外目标评估的条件下进行，且只有覆盖稀疏的有限静态数据。现有方法要么对每个偏好单独优化，要么训练问题特定的 Pareto 解模型，导致跨偏好重复搜索或跨问题重复训练，效率低。作者希望摊销偏好维度的求解搜索和问题维度的模型构建两类成本。
核心洞察
核心洞察在于把偏好条件的 Pareto 解模型本身视为可由先验知识快速生成的产物：通过在大规模多样合成先验数据上预训练一个基础式超网络，使其具备上下文学习能力，从而能在单次前向传播中为未见离线问题生成问题特定、偏好条件的 Pareto 解模型。该生成的模型可复用，对任意偏好直接预测，无需问题特定训练或逐偏好搜索，使跨偏好与跨问题的摊销成为可能。
技术挑战
  • 离线场景下无法进一步评估目标函数，仅有稀疏覆盖决策与目标空间的有限静态数据
  • 偏好条件 Pareto 集学习需要覆盖偏好空间中任意偏好，而非仅有限折中解
  • 现有方法逐偏好搜索或逐问题训练，搜索与训练成本随偏好数和问题数放大
  • 如何从大量合成先验数据预训练出能泛化到未见真实问题的超网络
  • 如何保证生成的偏好条件模型在稀疏离线观测下仍能产生高质量 Pareto 解
问题分析
材料未说明作者对问题结构的具体数学分析方式；从摘要可推断其思路是将偏好维度的求解与问题维度的建模统一为对解模型的生成问题，借由先验数据预训练超网络实现摊销。
方法
  • 提出 ICPSL（in-context preference-conditioned Pareto set learning）框架，同时摊销偏好层面的解搜索和问题层面的模型构建
  • 在大规模多样的合成先验数据集上预训练一个基础式超网络（foundation-style hypernetwork）
  • 给定未见问题的离线观测后，预训练超网络在单次前向传播中学习生成一个针对该问题、偏好条件的 Pareto 解模型
  • 生成的模型可被复用，对任意偏好直接预测解，无需问题特定训练或逐偏好搜索
实验
  • 在合成问题和真实世界问题上进行实验；摘要声称 ICPSL 能产生高质量 Pareto 解，并在问题特定解模型构建上带来显著加速；摘要未给出具体数值、基线名称、实例规模、运行时间或消融结果，材料未说明。

研究目标是偏好条件 Pareto 集学习，将偏好直接映射到 Pareto 最优解：Rather than returning a finite set of trade-off solutions, preference-conditioned Pareto set learning seeks to map a specified preference directly to a corresponding Pareto optimal solution.
场景为离线且无进一步目标评估，仅有稀疏覆盖的有限静态数据：Yet in many real-world scenarios, optimization must proceed offline without further objective evaluations, leaving only a limited static dataset that sparsely covers the decision and objective spaces.
现有方法逐偏好优化或训练问题特定模型，导致重复搜索或重复训练：Existing methods either optimize separately for each preference or train a problem-specific Pareto solution model, requiring repeated search across preferences or repeated training across problems.
ICPSL 同时摊销偏好层解搜索与问题层模型构建：We introduce in-context preference-conditioned Pareto set learning (ICPSL), a framework that amortizes both preference-wise solution search and problem-specific model construction.
在大规模多样合成先验数据上预训练基础式超网络：ICPSL pretrains a foundation-style hypernetwork on a large and diverse set of synthetic prior data.
单次前向传播生成问题特定的偏好条件解模型：Given the offline observations of an unseen problem, the pretrained hypernetwork learns to generate a problem-specific, preference-conditioned Pareto solution model in a single forward pass.
生成的模型可复用，对任意偏好预测解且无需问题特定训练或逐偏好搜索：The generated model can then be reused to predict solutions for arbitrary preferences without problem-specific training or preference-wise search.
实验显示能产生高质量 Pareto 解并显著加速问题特定解模型构建：Experiments on synthetic and real-world problems show that ICPSL produces high-quality Pareto solutions while providing substantial speedups in problem-specific solution-model construction.
