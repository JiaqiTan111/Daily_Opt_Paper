使用大语言模型智能体改进约束模型

Improving Constraint Models with LLM Agents

Florentina Voboril · Stefan Szeider

核心洞察

其有效性来源于将正确性保证从构造性证明转移到经验验证：大语言模型智能体在开放式空间中提出模型变体，并通过将变体的解注入原模型来检验可行性，从而允许模型提出不可靠甚至错误的候选，再由验证-修复循环诊断并修正这些错误；这种闭环使得智能体可以探索预定义规则库之外的变换，同时不牺牲最终返回模型相对于原模型的正确性。但摘要指出，在候选数量相当时，非智能体基线也达到相近改进率，说明本实验规模下总体增益并非仅由迭代诊断-修复贡献。

为什么值得看：虽然论文不直接研究生产调度问题，但它提出了一种将大语言模型智能体用于约束模型自动重构与改进的框架，并强调经验正确性验证与迭代诊断-修复。这与当前研究中自动建模、学习辅助搜索以及大模型智能体优化方向高度相关，其验证-修复循环、正确性经验验证、基于少量训练实例的泛化评估等机制，可为生产调度问题的自动建模与模型改进提供可借鉴的方法论。同时，论文诚实地报告非智能体基线达到相近改进率，对评估智能体方法的实际贡献具有警示价值，有助于研究者在公平计算预算下审视智能体机制的必要性。

研究设定
研究问题为自动改进约束规划（CP）模型：用户以 CPMpy 建模库提供原始约束模型以及三个小规模训练实例，目标是在固定求解时限内自动获得一个修改后的模型，使其在保持与原模型解集可行（即解注入原模型后仍可行）的前提下提升优化目标质量。决策对象是模型的结构性变换（如对称性破除、隐含约束、全局约束、变量表示与约束重构）。关键约束包括：只考虑优化问题（以固定时间限制内的目标质量衡量性能）、训练实例仅三个且较小、正确性必须经验验证而非构造性证明、智能体运行最多 80 步且无固定时间限制。信息假设为智能体可访问原始模型、三个训练实例以及验证工具，测试实例仅在评估阶段使用。环境为静态的离线模型改进问题，但引入迭代诊断-修复的动态智能体流程。
研究动机
CP 求解器的运行时间高度依赖建模选择，但改进约束模型通常需要人类专家经验；现有自动重构系统局限于预定义的手工转换规则库，只能应用事先编码并证明可靠的变换。因此需要一种能从开放式空间提出任意重构、并通过经验验证保证正确性的自动方法。
核心洞察
其有效性来源于将正确性保证从构造性证明转移到经验验证：大语言模型智能体在开放式空间中提出模型变体，并通过将变体的解注入原模型来检验可行性，从而允许模型提出不可靠甚至错误的候选，再由验证-修复循环诊断并修正这些错误；这种闭环使得智能体可以探索预定义规则库之外的变换，同时不牺牲最终返回模型相对于原模型的正确性。但摘要指出，在候选数量相当时，非智能体基线也达到相近改进率，说明本实验规模下总体增益并非仅由迭代诊断-修复贡献。
技术挑战
  • 大语言模型从无界空间提出的重构不可靠，可能包含错误或静默改变问题语义
  • 必须同时保证所提模型相对于原模型的正确性（解可行性）与性能提升（更快或更优目标）
  • 仅用三个小训练实例引导改进，且需泛化到更大的测试实例
  • 验证过程本身需在合理时间内完成，以支持多次迭代
问题分析
作者将问题建模为智能体与环境（模型、训练实例、验证工具）的迭代交互：智能体分析原模型并应用潜在优化策略，每次提出候选模型后由自动化验证程序检查其解注入原模型后的可行性，并在训练实例上比较求解器性能；若验证失败则诊断并修复。方法不依赖预定义的规则库或问题结构分解，而是依赖大语言模型的推理能力与经验评估信号。
方法
  • 输入为 CPMpy 原始模型与三个小规模训练实例，输出为智能体认为最佳的修改后模型（proposed model）
  • 大语言模型智能体迭代提出替代模型变体，应用对称性破除、隐含约束、全局约束、约束重构、变量表示等优化策略
  • 每个候选模型通过自动化验证：将其解注入原模型检验可行性，并在训练实例上并行比较求解器性能
  • 验证失败时智能体诊断失败原因并尝试修复，继续迭代
  • 选择并保存最佳模型，同时生成日志与结果摘要，日志记录所用技术及原因与验证结果
  • 过程限制最多 80 个智能体步骤，无固定时间限制
  • 使用 ReAct 风格智能体（agentic Python coder），底层模型通过 OpenRouter 访问
实验
  • 在十五个组合优化问题上评估，包括若干知名基准问题和三个专门设计的新问题
  • 每个问题十个测试实例、十次独立运行，共 1500 次测试
  • 生成的模型在 1028/1500 个案例（68.5%）中优于原模型，平均相对目标变化为 14.7%
  • 智能体提出最终模型的中位运行时间约六至十分钟；实验共 187 次智能体运行，中位 7.0 分钟，总计约 27 小时智能体墙钟时间
  • 验证时训练实例与测试实例分别在独立节点上并行求解
  • 对比非智能体基线：使用相同验证与选择工具采样同样数量的候选模型，在 150 个测试实例中改进了 101 个，而智能体平均改进 102.8 个，表明在此候选数量下总体增益不依赖于智能体的迭代诊断与修复
  • 在四个问题的子集上比较不同大语言模型；Claude Fable 5 改进最多（40 个测试实例中的 38 个），但最终选用 GPT 5.6 Sol（40 个中 33 个）因其价格仅为前者的十八分之一
  • 硬件为双 Intel Xeon E5-2640 v4（20 核 2.40 GHz）、157 GiB RAM，每次运行内存上限 8 GiB，未使用 GPU；CPMpy 1.0.0，求解器为 Chuffed 0.13.2 通过 MiniZinc 2.9.2
  • 使用九个大语言模型，温度 0.3（GPT 5.6 变体使用提供商默认值）
局限
  • 在候选数量相当时，非智能体采样基线达到相近改进率，因此在此实验规模下总体增益不依赖于智能体的迭代诊断与修复
  • 摘要未提供其他明确陈述的局限
与你的研究关系
该论文属于人工智能驱动运筹优化（AI4OR）中自动建模的方向，与生产调度中的约束模型构建和重构有具体迁移路径：调度问题常以 CP 模型表达，而模型选择（如对称性破除、全局约束、变量表示）对求解时间影响显著。论文的智能体框架可直接用于自动改进调度问题的 CP 模型，但迁移需要条件：需将生产调度问题编码为 CPMpy 模型并提供少量小规模训练实例，且需验证生成的模型在大规模调度实例上的泛化与求解质量。需要指出，论文实验未涉及生产调度或柔性作业车间等具体场景，以上迁移为推测。论文的验证-修复机制与经验正确性保证思路，也可为学习辅助搜索中的模型正确性校验提供参考。

论文提出一个智能体框架，从开放式空间重构约束模型，并通过将解注入原模型来经验验证正确性。：We introduce an agentic framework that instead reformulates a constraint model from an open-ended space and establishes correctness empirically rather than by construction: a Large Language Model (LLM) agent, given a model and three training instances, proposes alternative formulations, validates each by injecting its solution back into the original model, and diagnoses and repairs failures
论文在组合优化问题上评估，报告生成模型在多数测试实例上优于原模型，并可实现显著加速。：Across nine combinatorial optimization problems, the generated models outperform the originals on 21 of 27 test instances, and on some problems solve more than two orders of magnitude faster.
非智能体基线复用相同验证与选择工具，具有可比的改进率。：A non-agentic baseline that samples the same number of candidate models and selects among them with the same validation tools reaches a comparable improvement rate.
实验共 1500 次测试，生成的模型在 1028 次（68.5%）中优于原模型，平均相对目标变化 14.7%。：Across fifteen benchmark problems with ten test instances each and ten agent runs, our approach performed better in 1028 of 1500 cases (68.5%) and yields a mean relative objective change of 14.7%.
智能体最多允许 80 步，无固定时间限制，提出最终模型的中位时间约六至十分钟。：The agent is not given a fixed time limit, but the process is restricted to a maximum of 80 agent steps.
实验使用九个不同的大语言模型，并使用 CPMpy 1.0.0 与 Chuffed 0.13.2。：As underlying model, we used nine different LLMs from six providers
在候选数量相当时，非智能体基线在 150 个测试实例中改进了 101 个，智能体平均改进 102.8 个，总体增益不依赖于迭代诊断修复。：A best-of-5 sampling baseline that reuses the same validation and selection tools reaches a comparable improvement rate (101 of 150 test instances, against 102.8 on average for the agent), so with this number of candidate models the aggregate gain does not depend on the agent’s iterative diagnosis and repair.
