研究设定
研究问题是在仅有源任务评估反馈、目标问题定义不可见且无法在目标上评估的条件下，为多个组合优化问题变体设计可零样本迁移的启发式集合；决策对象是启发式程序（启发式集合）本身；目标是最小化目标问题上的平均求解代价（VRP 距离、FJSP makespan），在相同设计预算下进行；关键约束是设计阶段不使用目标评估反馈、需要对源任务组合进行覆盖、最终集合紧凑；信息假设是仅有多任务源问题的评估反馈；环境包含 VRP 与 FJSP 两类共 32 个问题变体，并区分同域（ID）与异域（OOD）。
研究动机
为多样化的组合优化问题设计有效启发式需要大量领域专业知识与反复搜索。大语言模型虽然可以自动化启发式生成与改进，但启发式搜索通常依赖被优化问题本身的评估反馈，因此仅使用源任务反馈泛化到新问题定义仍是核心挑战。作者希望缓解新问题变体出现时启发式需要重新适配或重新设计的反复成本。
核心洞察
让多个任务条件下的启发式种群在搜索过程中交互、迁移和重组，并利用基于跨任务种群性能的“迁移差距”来决定交互方向，可以使启发式在源任务之间共享可迁移的结构；同时再以“对源任务组合的额外覆盖”为选择准则构造紧凑启发式集合，从而在目标问题上无需任何额外搜索或适配即可零样本应用。
技术挑战
  • 启发式搜索通常依赖被优化问题本身的评估反馈，难以在无目标反馈下泛化
  • 如何在多个任务间决定哪些任务应交互并有效迁移启发式
  • 如何在保持集合紧凑的同时覆盖多样化的源任务组合
  • 在同一设计预算下同时提升 ID 与 OOD 性能
问题分析
作者通过定义任务（为某一优化问题设计启发式）、区分任务特定 AHD 与跨任务 AHD 来分析问题，并引入基于跨任务种群性能的迁移差距来量化任务间可迁移性，从而指导任务种群的交互；再以互补覆盖准则分析启发式集合的构建。材料未说明更具体的问题结构分解或下界分析。
方法
  • MECo 维护任务条件下的启发式种群（task-conditioned heuristic populations）
  • 利用基于跨任务种群性能的 transfer gap 指导种群间交互
  • 交互实现启发式的迁移与重组（transfer and recombination）
  • 互补选择准则通过奖励每个成员对源任务组合的额外覆盖来构造紧凑启发式集合
  • 选出的启发式集合直接应用到目标问题，不进行进一步搜索或适配
  • 可将 EoH、ReEvo、HSEvo 等 AHD 的启发式生成与种群更新规则嵌入 MECo 的任务种群，MECo 决定哪些任务交互并传递父代启发式初始化组合任务种群
实验
  • 在 VRP 与 FJSP 两个族共 32 个问题变体上比较 MECo 与八种自动化启发式设计（AHD）基线，相同预算下 MECo 平均代价最低
  • 在异域（OOD）问题上，MECo 在两个族中均优于各自最强的基线
  • 将 MECo 框架与 EoH、ReEvo、HSEvo 结合后，其 ID 与 OOD 性能在两个族中均有提升（见表 3 报告的平均值与标准差）
  • 报告中提到平均排名 1.12、平均相对差距 0.02%（在 16 个变体上接近最佳观测方法），并给出图 4 中相对 MECo 的 OOD 平均代价

论文提出 MECo，一个由大语言模型驱动的多任务进化框架，用于零样本跨问题泛化：We introduce MECo, an LLM-driven multi-task evolutionary framework for zero-shot cross-problem generalization.
MECo 维护任务条件下的启发式种群，并使用基于跨任务种群性能的迁移差距指导交互：MECo maintains task-conditioned heuristic populations and uses a transfer gap based on cross-task population performance to guide their interactions.
互补选择准则通过奖励每个成员对源任务组合的额外覆盖来构造紧凑启发式集合：A complementary selection criterion then constructs a compact heuristic set by rewarding each member’s additional coverage of source combinations.
选出的集合直接应用于目标问题而不进行进一步搜索或适配：The selected set is applied to target problems without further search or adaptation.
在 VRP 与 FJSP 的 32 个问题变体上，MECo 在相同预算下平均代价低于八种 AHD 基线：Experiments on 32 problem variants across vehicle routing (VRP) and flexible job-shop scheduling (FJSP) show that MECo achieves the lowest mean costs compared with eight automated heuristic design (AHD) baselines under the same budgets.
在异域问题上 MECo 优于各家族中最强基线：On out-of-domain problems, it outperforms the strongest baseline in each family.
将 MECo 框架与不同 AHD 方法结合可提升其 ID 与 OOD 性能：Moreover, integrating the framework of MECo with different AHD methods improves their ID and OOD performance in both families, supporting its effectiveness across different methods.
仅有源任务反馈、不使用目标评估，是跨问题泛化的核心挑战：Generalizing to new problem definitions using only source-task feedback therefore remains a central challenge.
