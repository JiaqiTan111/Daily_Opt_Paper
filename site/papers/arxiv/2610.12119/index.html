Using Weisfeiler-Leman Features for Algorithm Selection in Constraint Optimisation

Alessio Pellegrino · Jacopo Mauro

核心洞察

贡献的有效性在于：1-WL测试为消息传递GNN的图区分能力设定了上界，因此基于WL的特征在表达能力上不劣于标准GNN，同时避免了训练GNN的计算开销。此外，作者提出基于割的表示（WLc）显式建模结构划分，能提供比标准图特征更细粒度的预测信号。这使得经典机器学习模型（如SVM）也能利用结构信息，从而在保持部署轻量化的同时提升算法选择的性能。

为什么值得看：对研究智能优化与生产调度的博士生而言，本文提供了一个新颖的视角：利用图核自动提取结构特征，无需训练GNN即可让经典机器学习模型感知问题结构，从而在保持低计算开销的同时提升算法选择性能。其方法论可启发将WL特征应用于调度问题的实例表示与求解器选择；消融实验和嵌套交叉验证设计也值得借鉴，有助于理解结构特征在算法选择中的鲁棒性和提取成本。此外，对学习辅助搜索与自动建模方向，本文的图转换与特征提取思路可作为预处理组件与强化学习或元启发式结合。

研究设定
本论文研究约束编程（CP）中的算法选择问题：给定一个约束优化问题实例，从求解器组合中选出最合适的求解器。决策对象是求解器选择，目标有两个任务——最大化Borda计分和最大化预测准确率。关键约束包括传统特征提取方法依赖人工设计的实例级统计量、无法捕捉问题潜在结构，而图表示虽能捕捉结构但通常与需要大量计算开销的深度神经网络耦合。信息假设是实例已转换为FlatZinc格式并可转化为图，环境为静态的离线场景（在MiniZinc Challenge 2023-2025实例集合上评估）。材料未说明实时动态或在线部署的具体约束。
研究动机
算法选择对约束编程的效率至关重要，因为不同求解器在不同实例上的性能差异显著。然而，传统特征提取方法（如fzn2feat）依赖手工决定的实例级统计量，无法捕捉问题底层结构或变量间的复杂互联，形成“表示鸿沟”：非神经网络的经典机器学习方法“结构盲”，而结构感知模型通常因深度神经网络的开销而难以实际部署。作者旨在通过自动化的图转换与Weisfeiler-Lehman图核特征来弥合这一鸿沟，无需训练GNN即可提供结构感知的表示。
核心洞察
贡献的有效性在于：1-WL测试为消息传递GNN的图区分能力设定了上界，因此基于WL的特征在表达能力上不劣于标准GNN，同时避免了训练GNN的计算开销。此外，作者提出基于割的表示（WLc）显式建模结构划分，能提供比标准图特征更细粒度的预测信号。这使得经典机器学习模型（如SVM）也能利用结构信息，从而在保持部署轻量化的同时提升算法选择的性能。
技术挑战
  • 传统实例级统计特征无法捕捉问题的潜在结构信息
  • 图表示虽能捕捉结构，但通常需要深度神经网络，计算开销大，难以实际部署
  • 经典机器学习方法缺乏结构感知能力，形成表示鸿沟
  • WL特征提取本身可能带来额外计算开销，需在特征质量与提取成本间权衡
  • 不同机器学习模型对特征表示的偏好不同，需验证特征的跨模型稳健性
问题分析
作者通过将约束编程实例转换为图结构，并利用Weisfeiler-Lehman图核生成结构表示，从而将问题结构编码为特征向量供经典机器学习模型使用。他们分析指出，1-WL测试界定消息传递GNN的区分能力上界，因此WL核特征可作为一种无需训练GNN的结构感知替代方案。进一步，他们设计基于割的表示（WLc）来显式建模结构划分，以提供更细粒度的预测信号。实验上通过Borda计分和预测准确率两项任务，对比WL/WLc特征与fzn2feat在不同分类器下的表现，分析特征有效性。
方法
  • 图转换：将FlatZinc格式的约束编程实例转换为图表示，以便应用图核方法。
  • Weisfeiler-Lehman图核特征：使用1-WL和2-WL聚合步骤生成结构特征，聚合步数通过后缀（如-1、-2）标识。
  • 基于割的表示（WLc）：在WL基础上显式建模结构划分，生成更细粒度的特征，增强预测信号。
  • 特征嵌入FlatZinc生态：将特征提取过程集成到FlatZinc工作流中，便于实际使用。
  • 分类器训练：使用SVM、随机森林（RF）和多层感知机（MLP，三个隐藏层）作为算法选择的预测模型。
  • 训练协议：采用重复五折嵌套交叉验证，10个随机种子，共50次外折评估；包括超参数网格搜索、模型选择（平局时偏向简单模型）、PCA降维（20到min(n_features, n_samples)步长20，MLP跳过降维）和最终特征选择。
实验
  • 在MiniZinc Challenge 2023-2025的实例上进行评估，构建两个算法选择任务：最大化Borda计分和最大化预测准确率。
  • 使用SVM、RF和MLP三种分类器，对比WL/WLc特征与fzn2feat特征。
  • 采用重复五折嵌套交叉验证（10个随机种子，共50次外折评估）确保稳健性。
  • 结果显示：WLc特征配合SVM时在两项任务上均优于fzn2feat；RF和MLP的对比差异较小，部分RF配置下fzn2feat略优。
  • 对特征提取成本进行了比较（WLc-n/WLc-ne vs fzn2feat），但具体数字材料未提供。
  • 消融方面评估了1步和2步聚合的WL特征，但详细消融结果未在节选中给出。
局限
  • 特征提取管道尚未完全优化，可通过算法改进和并行化独立图操作进一步降低大规模实例集的开销。
  • 未来工作将聚焦于优化计算效率、探索动态在线算法选择框架、结合经典特征集（如fzn2feat）以及推广到CP社区其他任务。
与你的研究关系
该论文直接涉及约束编程中的算法选择，属于AI4OR与智能优化范畴。其核心贡献——使用WL图核自动提取结构特征以辅助经典机器学习进行求解器选择——与生产调度中柔性作业车间、流水车间等问题的算法选择有相似的决策结构：都需要根据问题实例的结构特征从算法组合中选取最合适的求解器。论文提出的图转换与WL特征方法可迁移到生产调度问题，但需要条件：需将调度问题实例（如工序、机器、约束）转换为合适的图表示，并验证WL特征能否保留调度问题的关键结构信息；此外，生产调度常涉及动态扰动和多目标，而本文设定为静态离线，迁移到动态环境需重新设计特征提取与在线选择机制。以上迁移为推测，非作者结论。
证据与不确定性

本文发表于arXiv，尚未经过同行评审。全文节选缺失部分关键细节：具体实验数字（如Borda计分、准确率、提取时间）未在节选中完整呈现，无法核验性能提升幅度；WL与WLc特征的具体构造细节、图转换算法、PCA降维效果、消融实验完整结果等材料未提供；因此对方法创新性和实验充分性的判断存在不确定性。此外，生产调度迁移的可行性纯属推测，需进一步验证。
