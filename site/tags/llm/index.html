研究设定
面向地理分布式AI数据中心运营者，研究在时变电网供电约束与节点电价信号下，联合决策各站点LLM模型副本的加载(部署)时段与跨站点请求路由，目标是在满足LLM推理特有的服务延迟约束（TTFT与TPOT）并维持服务率的前提下最小化总运行成本；决策对象包括模型副本加载/卸载的时序承诺变量与请求分配量；关键约束为分时功率供应上限、电价信号、模型副本加载的时序耦合以及延迟决定的服务能力上限；信息假设为已知未来时段的电价与功率供应曲线（在算例中体现为可做全时段前瞻），环境为随电价与供电条件变化的动态但可预测场景，静态或动态的随机性材料未说明。
研究动机
AI数据中心在部分时段可能面临供电短缺，需要将LLM推理负载在地理上迁移以维持服务率。然而已有负载转移方法通常假设只要某数据中心计算资源充足就能立即服务转移来的请求，忽略了推理请求只能被转移到已加载对应模型副本的站点这一事实，可能导致不可行的转移决策与未服务需求；同时已有SLO建模多针对网络传输或排队延迟，未纳入LLM推理的prefill与decode延迟对可服务需求量的约束。
核心洞察
该工作有效性的关键在于把LLM推理的“模型副本加载”视为类似机组组合中机组启动的提前承诺过程，从而显式刻画负载转移的时序前置条件：只有提前完成加载并进入就绪状态的副本才能在后续时段承接被转移的请求；在此基础上，将prefill的TTFT与decode的TPOT延迟需求翻译为每个就绪副本在各时段可承接的需求量上限，使调度决策同时具备可行性与前瞻性，避免出现表面上有算力却无法实际服务转移请求的伪可行方案。
技术挑战
  • 模型副本加载与预热需要显著时间，导致请求路由与部署决策之间存在跨时段耦合，不能按单时段独立决策
  • LLM推理的prefill(TTFT)与decode(TPOT)延迟约束需转换为每副本每时段的容量上界，且需与功率约束、电价信号共同纳入统一优化
  • 若忽略加载时间或延迟约束，会导致物理上不可执行的转移与大量未服务需求，需要在模型中同时保证可行性并兼顾成本
问题分析
作者通过类比机组组合中的机组启动过程，识别出模型副本加载是一种具有跨时段耦合的承诺行为，因此将问题构造为联合调度模型部署与跨站点请求路由的混合整数线性规划；并利用LLM推理两阶段特性，将TTFT约束写成请求量不超过由该阶段时延参数、模型吞吐与副本就绪状态共同决定的容量上界（式11），将TPOT约束按剖面实验观察到的SLO合规比例与TPOT上限近似成正比的关系，表示为与实验标定系数相关的容量上界（式12），从而把延迟要求显式嵌入线性约束。
方法
  • 提出模型承诺（MC）框架，以混合整数线性规划联合调度模型部署（副本加载/卸载的时序承诺）与跨站点请求路由
  • 将模型副本加载建模为具有时序耦合的承诺过程，复制机组组合中启动时间的思想刻画loading/warm-up
  • 将prefill阶段的TTFT需求转换为每个就绪副本可服务请求量的上界约束（式11）
  • 将decode阶段的TPOT需求依据实验标定的近似比例关系转换为吞吐比例上界约束（式12）
  • 在功率约束与电价信号下联合优化部署与路由，决策变量包含副本就绪状态指示与请求分配量（材料未给出完整变量定义与求解器细节）
实验
  • 基于真实数据的案例研究，包含三个数据中心，使用美国三个地区的真实节点电价曲线作为电网信号
  • LLM请求到达基于真实OpenAI工作负载轨迹，选取Qwen2.5-32B、Llama-3.3-70B与DeepSeek-V3作为代表性负载
  • PUE、模型服务吞吐与GPU规格等参数依据已发表测量或实验结果标定，完整参数设置见参考文献[9]
  • 对比基线包括B1-Myopic（30分钟前瞻、无全时段信息）、B2-Static（固定副本部署）、B3-ZeroLeadTime（忽略加载时间）、B4-NoPriceSignal（忽略节点价差）、B5-NoTTFT（省略TTFT约束）、B6-NoTPOT（省略TPOT约束），其中B3、B5、B6在全约束下物理重演

研究设定
研究问题是如何将自然语言描述的组合优化问题自动转化为QUBO（二次无约束二元优化）公式，决策对象为二元决策变量 x∈{0,1}^n 以及QUBO矩阵Q和常数偏移c，目标形式为 min E(x)=x^T Q x + c。关键约束是需要正确识别二元变量、约束、目标函数、惩罚项及合适的惩罚权重。信息假设是输入为自然语言问题描述，可附带结构化或非结构化测试用例。环境为静态（公式生成任务），材料未说明动态扰动或在线求解设定。
研究动机
QUBO是组合优化的核心公式，且与量子、混合量子-经典及量子启发式求解器兼容，但将自然语言问题描述翻译为正确QUBO公式困难、耗时且需要大量领域专业知识。现有LLM方法主要面向LP/MILP等求解器就绪公式，QUBO设定探索较少；AutoQUBO依赖形式化程序输入，LLM-QUBO主要关注MILP转QUBO且验证有限。因此需要端到端、反馈驱动的自动QUBO公式生成框架。
核心洞察
该工作的核心洞察在于：QUBO公式生成不是一次性翻译，而是一个需要识别变量编码、约束、目标与惩罚权重的多步骤结构化过程；通过多智能体分工与迭代自修复，可以在出现错误时反馈式重述问题，从而提升最终公式的正确性。摘要明确指出迭代自修复是性能提升的最重要组件，说明其有效性来自错误反馈闭环而非单一模型能力。
技术挑战
  • 自然语言描述到QUBO公式的翻译需要同时识别二元变量、约束、目标函数、惩罚项和惩罚权重，步骤多且易出错
  • QUBO公式的正确性验证需要确保自然语言规范、结构化公式、生成实现和小规模最优解相互一致
  • 领域多样、问题类型广泛，单一直接生成调用难以覆盖
  • 惩罚权重选择影响约束可行性，但材料未说明具体处理策略
问题分析
作者通过构建端到端多智能体框架将QUBO生成分解为多个步骤，包括理解问题、选择二元编码变量和约束、定义惩罚项等。作者还构建QUBOBench基准，包含12个应用领域、100个组合优化问题，用于跨领域评估。分析指出迭代自修复是最重要组件，说明作者通过消融式分析识别各组件贡献。但材料未说明作者是否利用问题结构、分解下界或图表示等更具体的优化分析手段。
方法
  • 提出端到端多智能体框架，从自然语言问题描述自动生成QUBO公式
  • 框架支持结构化或非结构化测试用例作为输入
  • 生成过程涉及多个步骤：理解问题、选择二元编码变量和约束、定义惩罚项等
  • 包含迭代自修复组件，在出现错误时进行反馈式重述或修正
  • 构建QUBOBench基准，含100个组合优化问题、覆盖12个应用领域，来源包括同行评审文献、竞赛和经典NP-hard问题
实验
  • 在QUBOBench上达到68%准确率
  • 相比直接单次调用基线提升22%
  • 进一步分析识别出迭代自修复是贡献性能提升的最重要组件
  • 材料未说明基线具体设置、实例规模、约束可行性验证、解质量、运行时间、训练开销、公平计算预算、泛化和消融实验的完整细节
局限

与你的研究关系

研究设定
研究问题是：在真实运筹优化请求中，自然语言问题描述往往不完整，可能缺失目标、约束或业务规则，而大语言模型在将自然语言转化为数学规划模型时通常假定输入完整。决策对象是建模智能体在建模前是否提出澄清问题以及何时停止提问；目标是尽可能恢复隐藏的结构化槽位并避免静默假设，同时控制交互成本。关键约束包括有界交互、隐藏槽位不可见、用户模拟环境；信息假设为公共描述部分可见、隐藏槽位需通过提问获取；静态或动态环境未说明。
研究动机

核心洞察
论文的核心洞察是将运筹辅助重新定义为一种选择性的完整性决策：智能体应识别哪些未解决的信息对建模具有关键影响，据此决定是继续提问还是停止，并量化仍然缺失的信息；这种以未解决建模关键缺口为信号的停止与提问策略，比单纯追求问答轮次或直接建模更能提升槽位恢复并减少静默假设。

  • 同时支持开放式澄清与基于选项的澄清两种交互模式

研究设定
研究问题是如何高效解码大语言模型生成的排序结果。决策对象是待排序的N个物品的序数序列。目标是设计一种解码策略，使得生成排序仅需O(1)次前向传播，同时保持与自回归教师模型相当的排序质量。关键约束是解码必须产生有效的排列（即无重复且完整的序数序列），不允许通过修复产生。信息假设是LLM的预填充隐藏状态包含足够的排序信息。环境是静态的，因为排序针对固定的一组物品。
研究动机
大型语言模型在生成式排序中达到最先进质量，但其自回归解码每个输出词元需要一次顺序前向传播，导致推理延迟高。作者观察到排序器只需输出N个序数值，且其排列结构允许更高效的解码，因此希望利用这种格式特性打破自回归的顺序瓶颈，实现实时排序。
核心洞察
核心洞察在于生成式排序的输出空间是排列结构，而非任意文本；因此不必从左到右逐个生成序数，而是可以从LLM的预填充隐藏状态中一次性提取所有物品的位置分数，将解码转化为一个组合优化问题（最优二部匹配）。通过匈牙利算法直接得到有效排列，避免了自回归的串行依赖，也不需要修复步骤，从而将前向传播次数从O(N)降至O(1)。
技术挑战
  • 如何从LLM的预填充隐藏状态中提取可用于解码的N×K物品-位置分数矩阵。
  • 如何训练轻量级自注意力头以准确预测位置分数，同时保持排序质量。
  • 如何使LLM骨干适应这种非自回归解码方式，例如通过LoRA微调和蒸馏。
  • 如何确保解码结果总是有效排列，而不是需要通过后处理修复。
问题分析
材料未详细说明作者如何从理论上分析问题，但摘要表明作者将生成式排序重新表述为物品与位置之间的二部匹配问题，利用匈牙利算法求解最优分配。这种表述利用了排列的约束结构，将解码从生成问题转化为优化问题。作者进一步通过系统研究训练信号和骨干适配，分解了架构、训练信号和骨干适配的贡献，以理解各因素对质量和速度的影响。
方法
  • SPD解码策略：设计为单遍前向传播（O(1)），读取LLM预填充隐藏状态上的N×K物品-位置分数矩阵。
  • 使用轻量级自注意力头从隐藏状态中提取分数矩阵。
  • 将序数解码为矩阵的最优二部分配，采用匈牙利算法保证生成有效排列。
  • 训练方法：采用LoRA微调LLM骨干，并结合自回归LLM排序蒸馏，以对齐教师模型的排序质量。
