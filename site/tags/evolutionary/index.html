研究设定
研究问题是在仅有源任务评估反馈、目标问题定义不可见且无法在目标上评估的条件下，为多个组合优化问题变体设计可零样本迁移的启发式集合；决策对象是启发式程序（启发式集合）本身；目标是最小化目标问题上的平均求解代价（VRP 距离、FJSP makespan），在相同设计预算下进行；关键约束是设计阶段不使用目标评估反馈、需要对源任务组合进行覆盖、最终集合紧凑；信息假设是仅有多任务源问题的评估反馈；环境包含 VRP 与 FJSP 两类共 32 个问题变体，并区分同域（ID）与异域（OOD）。
研究动机
为多样化的组合优化问题设计有效启发式需要大量领域专业知识与反复搜索。大语言模型虽然可以自动化启发式生成与改进，但启发式搜索通常依赖被优化问题本身的评估反馈，因此仅使用源任务反馈泛化到新问题定义仍是核心挑战。作者希望缓解新问题变体出现时启发式需要重新适配或重新设计的反复成本。
核心洞察
让多个任务条件下的启发式种群在搜索过程中交互、迁移和重组，并利用基于跨任务种群性能的“迁移差距”来决定交互方向，可以使启发式在源任务之间共享可迁移的结构；同时再以“对源任务组合的额外覆盖”为选择准则构造紧凑启发式集合，从而在目标问题上无需任何额外搜索或适配即可零样本应用。
技术挑战
  • 启发式搜索通常依赖被优化问题本身的评估反馈，难以在无目标反馈下泛化
  • 如何在多个任务间决定哪些任务应交互并有效迁移启发式
  • 如何在保持集合紧凑的同时覆盖多样化的源任务组合
  • 在同一设计预算下同时提升 ID 与 OOD 性能
问题分析
作者通过定义任务（为某一优化问题设计启发式）、区分任务特定 AHD 与跨任务 AHD 来分析问题，并引入基于跨任务种群性能的迁移差距来量化任务间可迁移性，从而指导任务种群的交互；再以互补覆盖准则分析启发式集合的构建。材料未说明更具体的问题结构分解或下界分析。
方法
  • MECo 维护任务条件下的启发式种群（task-conditioned heuristic populations）
  • 利用基于跨任务种群性能的 transfer gap 指导种群间交互
  • 交互实现启发式的迁移与重组（transfer and recombination）
  • 互补选择准则通过奖励每个成员对源任务组合的额外覆盖来构造紧凑启发式集合
  • 选出的启发式集合直接应用到目标问题，不进行进一步搜索或适配
  • 可将 EoH、ReEvo、HSEvo 等 AHD 的启发式生成与种群更新规则嵌入 MECo 的任务种群，MECo 决定哪些任务交互并传递父代启发式初始化组合任务种群
实验
  • 在 VRP 与 FJSP 两个族共 32 个问题变体上比较 MECo 与八种自动化启发式设计（AHD）基线，相同预算下 MECo 平均代价最低
  • 在异域（OOD）问题上，MECo 在两个族中均优于各自最强的基线
  • 将 MECo 框架与 EoH、ReEvo、HSEvo 结合后，其 ID 与 OOD 性能在两个族中均有提升（见表 3 报告的平均值与标准差）
  • 报告中提到平均排名 1.12、平均相对差距 0.02%（在 16 个变体上接近最佳观测方法），并给出图 4 中相对 MECo 的 OOD 平均代价

BiFE：基于大语言模型的双保真度演化实现纯 CPU 分支策略的高效搜索

BiFE: Search-Efficient Discovery of CPU-Only Branching Policies via LLM-based Bi-Fidelity Evolution

核心洞察

论文的核心洞察在于：低保真模仿分数与高保真在线求解表现之间存在由分布漂移导致的系统性偏差，因此低保真代理不能完全替代真实评估。将低保真评估用作快速预筛选、把昂贵的高保真评估仅保留给少数精英个体作为细粒度校正器，可以在不牺牲最终规则质量的前提下大幅压缩搜索预算；其有效性来源于把评估资源按照“筛选—验证”分工重新分配，而非简单叠加两个评估模块。

第一单位：Institute of Automation, Chinese Academy of Sciences

通讯作者：Guoliang Fan

首次上传：2026-09

arXiv 摘要 ↗ PDF ↗官方 HTML ↗

研究设定
研究问题为混合整数线性规划（MILP）分支定界（B&B）中的分支变量选择，决策对象是每个分支步上从候选变量集合 C 中选取哪个变量进行分支；目标是在纯 CPU 环境下以低推理开销获得可竞争的分支策略，使求解效率（节点数与时间）优于默认启发式和已有 CPU 高效策略；关键约束包括不得使用 GPU 推理、在线评估开销必须可控、分支规则只修改分支规则而其余求解器设置保持默认（仅根节点允许生成割平面、关闭重启）；信息假设为可离线用强分支（strong branching）收集专家示范数据对 (X_t, a*_t)，并可在线调用求解器做昂贵的实例评估；环境为静态的离线演化搜索加在线求解评估，材料未说明是否涉及动态扰动。
研究动机
已有神经分支策略通常需要 GPU 推理，而 CPU 高效的符号表达式表达能力有限、难以刻画复杂逻辑。LLM 生成的代码提供了灵活且轻量的分支规则搜索空间，但在 LLM 演化框架中用真实实例做完整 B&B 评估代价过高，而纯离线模仿学习又存在分布漂移问题，因此需要在搜索效率与性能可靠性之间取得平衡。
核心洞察
论文的核心洞察在于：低保真模仿分数与高保真在线求解表现之间存在由分布漂移导致的系统性偏差，因此低保真代理不能完全替代真实评估。将低保真评估用作快速预筛选、把昂贵的高保真评估仅保留给少数精英个体作为细粒度校正器，可以在不牺牲最终规则质量的前提下大幅压缩搜索预算；其有效性来源于把评估资源按照“筛选—验证”分工重新分配，而非简单叠加两个评估模块。
技术挑战
  • 在 LLM 代码空间中搜索分支规则时，完整 B&B 评估代价极高，无法对所有候选逐一评估
  • 仅依赖离线模仿学习会因分布漂移导致评估失准，在部分基准上出现明显性能崩塌
  • 需要在低保真预筛选的召回与高保真验证的精度之间分配有限计算预算
  • 既要保持 CPU 上的近符号级低推理开销，又要具备超越简单符号规则的逻辑表达能力
  • 所发现的规则目前依赖具体基准分布，跨问题分布的泛化尚未解决
问题分析
作者利用分支变量选择问题的结构，将强分支示范数据构造为离线数据对 (X_t, a*_t)，其中 X_t 为候选变量特征、a*_t 为强分支选出的变量，从而把“分支决策与专家示范的一致性”定义为低保真目标 F_LF 的指标。基于此，作者用 F_LF 与 F_HF（真实实例上的求解表现）之间的散点关系来诊断分布漂移，指出在 MIS 与 CA 等基准上从最佳 F_LF 到最佳 F_HF 的性能退化最严重，并恰好对应 EoH 与 ReEvo 的失败案例，据此论证必须保留 F_HF 作为细粒度验证器，并据此设计双保真度评估分配机制。
方法
  • 使用 LLM 生成分支规则代码作为搜索空间，规则为轻量级、可在 CPU 上快速执行的程序
  • 采用双保真度演化框架 BiFE：F_LF 为低保真代理，F_HF 为高保真在线评估
  • 低保真 F_LF 定义为候选规则在离线强分支示范数据集 D 上的模仿准确率，即 arg max 分支变量与 a* 一致的比例，输入为 72 维候选变量特征（18 静态 + 54 动态），输出为标量分数
  • F_LF 作为快速预筛选器，仅对存活的精英候选选择性执行昂贵的真实实例 B&B 高保真评估
  • 高保真评估用于校正低保真代理因分布漂移带来的不准确，作为细粒度验证器
  • 实验在 SCIP 7.0.3 中实现，仅修改分支规则，根节点允许生成割平面，关闭求解器重启，其余参数为默认值
  • LLM 骨干模型为 DeepSeek-V4-Flash，各 LLM 方法使用一致的演化参数
实验
  • 基线分四类：手工启发式 SCIP 默认可靠伪代价分支 RPB；CPU 高效策略 FiLM、Symb4CO、GS4CO；通用神经策略 GNN（模仿学习）与 tMDP（强化学习），后缀 -GPU 表示 GPU 评估；LLM 算法设计方法 EoH、ReEvo、LLM4Branch
  • 评测在 5 个随机种子、20 个实例上进行，共 100 次求解尝试，每次时间上限 1000 秒，所有评估在同一硬件上进行
  • 摘要与正文报告所发现规则在 CPU 上优于 SCIP 求解器和其他基线，甚至超过某些基于 GPU 的神经策略
  • 搜索效率方面：与 LLM4Branch 相比，BiFE 在全部基准上所需时间少 3.9 倍至 20.6 倍，在 NNV 上达 9.2 倍，该预算包含演化搜索与一次性强分支样本采集开销，且两者规则性能无显著差异
  • 散点分析显示从最佳 F_LF 到最佳 F_HF 的性能退化在 MIS 和 CA 上最严重，与 EoH（MIS）和 ReEvo（CA）的失败案例相对应，验证了仅依赖 F_LF 的不足
  • 与 Symb4CO 和 GS4CO 相比，后者因官方实现将 RPB 与符号规则结合而增加推理成本，BiFE 仅依赖轻量规则，取得最佳时间效率
局限
  • 所发现的策略仍是基准特定的，演化搜索针对每个问题分布（如 CA、SC、MIS）独立进行与定制，某一基准上演化出的策略可能无法很好泛化到结构不同的 MILP 实例，迁移到新问题域需重新运行搜索过程

研究动机

问题分析
