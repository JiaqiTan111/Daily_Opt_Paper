核心洞察
代理辅助遗传规划的有效性不仅取决于能否借助代理模型识别有潜力的子代，还取决于表型表征如何控制表型冗余与维持行为多样性。表型表征编码的信息丰富程度决定了哪些子代被视为行为重复而被移除、哪些子代在预选择后存活，从而影响进化搜索实际可用的行为多样性；因此代理估计精度本身不足以完全解释不同编码方案带来的性能差异，去重与代理预选择具有互补作用。

该工作的核心价值不在于提出新的重构算法，而在于通过统一框架、统一测试系统和统一评价口径消除实现差异、潮流模型差异和测试系统差异带来的比较偏差；同时用与硬件无关的潮流计算次数作为成本度量，使不同算法能够在同一计算预算尺度上被衡量。这种受控复现和公平度量使得不同范式算法之间的相对表现能够被可靠观察，并揭示动态重构策略在考虑开关维护成本后仍可能带来显著损耗下降。
技术挑战
  • 不同已发表算法使用不同测试系统、不同潮流模型和不同实现细节，难以直接比较
  • 需要将启发式、元启发式和数学规划三类范式统一到同一开源框架中
  • 需要在公平计算预算下度量算法收敛所需计算量
  • 动态 DNR 策略需同时权衡系统损耗与断路器维护成本
问题分析
作者通过将八种代表性 DNR 算法在单一开源 Python 框架中重新实现，并在五个相同网络上以相同条件运行来实现受控比较；评价指标包括功率损耗、电压分布以及作为硬件无关成本度量的潮流计算次数；其中数学规划方法基于凸化简化的 DistFlow 潮流模型构建混合整数二次规划，从而将问题纳入可求解的数学规划形式。材料未说明作者是否进一步分析问题结构、分解或下界。
方法
  • 在单一开源 Python 框架中重新实现八种代表性 DNR 算法
  • 算法覆盖三大范式：启发式（环路切割、支路交换、贪心最小生成树、穷举搜索）、元启发式（遗传算法、选择性二进制粒子群优化器）和数学规划（基于凸化简化 DistFlow 潮流模型的混合整数二次规划）
  • 在五个网络上以相同条件进行基准测试
  • 报告功率损耗、电压分布以及收敛所需潮流计算次数
  • 在 196-bus Simbench 城市网络上评估动态 DNR 策略，权衡系统损耗与断路器维护成本
  • 公开全部实现、测试用例和结果脚本以支持直接扩展和复现
实验
  • 在五个网络上对八种 DNR 算法进行相同条件下的基准测试
  • 评价指标包括功率损耗、电压分布和收敛所需潮流计算次数
  • 在 196-bus Simbench 城市网络上，动态 DNR 策略可节省超过 26% 的系统损耗，同时权衡断路器维护成本
