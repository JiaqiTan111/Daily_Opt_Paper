研究设定
论文研究黑箱优化中的在线自动化算法设计问题：决策对象是在优化过程每一阶段由大语言模型智能体合成的新可执行算法，目标是在给定评估预算下最大化终端效用（搜索性能），关键约束是保持解的可行性与预算限制（材料未说明具体约束处理机制），信息假设是优化状态 s_t 可充分概括已评估解、近期进展和剩余预算等历史信息并满足马尔可夫性，环境为单目标、维度最高 30 的静态黑箱优化场景（材料未说明动态扰动或分布式约束）。
研究动机
现有基于大语言模型的自动化算法设计大多采用离线范式，算法设计与目标优化在时间上分离，部署后算法固定不变；而传统自适应优化器虽能响应优化状态变化，其调整仅限于预定义的参数、算子或策略，无法改变底层算法逻辑。因此在优化状态动态演化时，固定部署的算法可能不再适配，需要将算法本身视为状态依赖的决策变量，在目标优化运行中在线合成新算法。
核心洞察
论文的核心洞察在于：算法设计不应是一次性的离线产物，而应作为优化过程中随状态变化而在线更新的决策变量。其有效性来源于将程序合成嵌入目标优化回路：执行当前生成的算法既推进搜索又产生反馈，该反馈同时用于下一阶段算法合成和运行时证据解读方式的修正，从而在无需单独离线预训练的情况下，使设计空间超越预定义参数、算子或策略，缓解离线设计范式下设计与执行脱节以及固定算法难以适配状态演化的问题。
技术挑战
  • 在线合成可执行算法并保证其行为逻辑的新颖性与有效性
  • 多智能体设计视角之间的冲突需要协调
  • 运行时证据的解释方式需随执行反馈迭代修正
  • 在不引入额外离线预训练预算的前提下耦合设计与优化
  • 单目标、低维度设定向大规模、噪声、约束和多目标场景推广
问题分析
作者将目标优化与元层算法设计形式化为两个耦合的序贯决策过程，目标优化被建模为马尔可夫决策过程，状态 s_t 概括已评估解、近期进展与剩余预算，动作 a_t 给出下一步候选解，且假设 s_t 充分概括相关历史。在此框架下，算法 π 被表示为状态到动作的映射，在线设计则在每阶段根据 s_t 合成新算法。作者还通过附录中的性能差分析给出命题 1，用设计空间误差、表示误差和合成误差上界刻画 OnDesign 与理想在线设计器之间的期望终端效用差，并据此将 State Analysis 和 SAG Evolution 对应到当前与后续状态表示的决策相关信息，将 Multi-Agent Deliberation 对应到算法覆盖与合成。
方法
  • 将目标优化与算法设计视为耦合的序贯决策过程，状态 s_t 包含已评估解、近期进展与剩余评估预算，动作 a_t 指定下一步候选解，算法被表示为由状态到动作的映射。
  • 提出在线 LLM 基 AAD 范式：在每一阶段由 LLM 智能体从当前优化状态合成具有新行为逻辑的算法，执行该算法推进搜索并产生反馈，用于后续设计，无需单独离线算法预训练。
  • 提出 OnDesign 多智能体框架，包含 State Analysis、Multi-Agent Deliberation 和 SAG Evolution 三个模块。
  • State Analysis 负责从当前优化状态中提取决策相关信息；Multi-Agent Deliberation 协调相互竞争的设计视角以合成可执行算法；SAG Evolution 利用执行反馈修正运行时证据的解读方式，并影响后续算法合成。
  • 执行反馈同时用于两部分：生成后续算法，以及更新用于解释运行时证据的指导准则。
实验
  • 在两个主流黑箱优化范式、三个场景上进行评估：贝叶斯优化、进化连续优化、进化混合变量优化。
  • 在六个基准测试套件和一个工程问题上、跨多个问题维度进行实验。
  • 结果表明 OnDesign 在整体性能上优于传统优化器和离线 LLM 基 AAD 方法。

研究设定
研究网络化多智能体系统（MAS）在连续空间中的运动规划与决策问题：多个具有线性动力学（双积分器）的智能体需在存在多面体障碍物的环境中无碰撞地到达目标区域，目标可预先分配或由系统自行分配（区分必须访问与可选奖励目标），同时必须保证智能体间通信网络在规划过程中保持连通。决策对象为每个智能体的状态与输入轨迹、目标分配以及通信图的构造；目标是在燃料消耗与完成时间意义上进行经济机动并兼顾可选目标奖励；关键约束包括状态/输入有界、避障、智能体间避碰、以及标准连通性或k-hop连通性；信息假设为集中式MILP建模并配合滚动时域规划，通信区域被建模为固定边长的正方形；环境为静态障碍但智能体运动动态演化，文中未说明是否存在随机扰动。
研究动机
网络化多智能体系统的连通性维护在MILP运动规划中通常用子回路消除（SEC）约束建模，其不等式约束数量随系统规模呈指数增长，限制了可求解问题的规模。作者希望借助经典网络流思想，用多项式规模的流编码替代SEC，并进一步给出k-hop连通性的紧凑编码，从而降低模型复杂度、扩展可求解规模，并探讨其对分支定界求解性能的实际影响。
核心洞察
贡献有效的核心在于：标准连通性本质上等价于在通信图上以某源点为根存在覆盖全部节点的有向生成树/流，因此可用单商品流守恒约束代替指数级的子回路消除约束，将约束规模从指数降到多项式；而k-hop连通性可以借助分层/多商品流在固定跳数内传播可达性，用流变量的层级推进替代随跳数k增长的二进制变量，使二进制变量数从O(n_a^3 k)降至O(n_a^2)并与k解耦。其代价是引入大量连续流变量与额外不等式约束，增大了LP松弛规模，因此性能收益取决于二进制变量减少与LP松弛变大的权衡，而非单调改进。
技术挑战
  • SEC方法的约束数量随MAS规模指数增长，限制可求解规模
  • k-hop连通性的既有矩阵幂方法二进制变量随跳数k增长
  • 流编码引入大量连续变量与不等式约束，可能拖慢分支定界每节点的LP松弛求解
  • 理论最坏情况迭代次数的减少不一定转化为平均性能提升
  • 连通性约束需同时保证必要性与充分性以覆盖所有可能的网络拓扑
问题分析
作者从MILP建模角度分析连通性约束的编码方式：通过表2对比不同k-hop连通性方法在二进制变量、连续变量、不等式约束数量上的渐近复杂度，并论证流编码的必要性与充分性以保证对所有可能网络拓扑的覆盖。随后用统计评估方法分析理论复杂度与实际求解性能之间的差距，指出性能差距来自分支定界各节点上LP松弛的求解代价，与流编码引入的O(n_a^4 k)连续变量和不等式约束增长一致。
方法
  • 在基于既有工作的统一MILP模型上，将任务分配与连续空间运动规划联合建模，目标函数兼顾燃料、完成时间与可选目标奖励
  • 为通信图引入单商品流编码的标准连通性约束，替代SEC，并证明其必要性与充分性
  • 为k-hop连通性引入流编码，使二进制变量数降为O(n_a^2)且与跳数k解耦，代价是连续变量与不等式约束增至O(n_a^4 k)
  • 通过表2对矩阵幂方法与流方法在二进制变量、连续变量、约束数量及必要性/充分性上做复杂度对比
  • 采用商用分支定界求解器Gurobi进行求解，配合滚动时域规划策略，并讨论将二进制与连续变量解耦的学习型求解策略可能获益的场景
实验
  • 在100个随机化场景上对不同规模的MAS进行统计评估，比较流方法与SEC/矩阵幂基线的代价与优化时间
  • 给出了一个标准连通性下流方法与SEC方法的示意性对比实例（图2）
  • 实验设定：同构MAS，双积分器动力学，采样周期T=1秒，线速度界[-10,10]，加速度界[-5,5]，连通区域为边长2的正方形，权重γ_i=1、可选目标奖励r_v=10，最大规划时域N̄=12，使用Gurobi求解
  • 结果：在标准连通性问题中流方法优于SEC，在给定优化时间限制下可求解更大规模的MAS
  • 结果：k-hop流编码减少了二进制变量，降低了分支定界求全局最优的理论最坏情况迭代次数
  • 结果：k-hop流方法的这一理论优势未转化为平均性能提升，与基线相比在受限优化时间下未见收益

问题分析
作者将探索历史组织为结构化的发现树，每个节点表示一次尝试及其完整观测；历史树集合构成回放模拟器池。在离线阶段，固定历史树，对候选探索策略逐一在每棵历史树上进行回放评估：回放重置策略状态、从根出发，按策略选择批量子节点，但节点结果是预先记录的确定性返回，而非生成新候选。以此获得大量廉价、快速的离线反馈，并迭代产生多个策略版本。外层循环中，改进后的策略重新部署到在线探索，生成新的发现树并加入历史，扩大模拟器池。材料未说明作者是否使用下界、图表示或数学规划构造求解。
方法

  • 离线评估循环：在一个外层迭代内固定历史，构建并评估多个策略版本，从初始策略开始，利用回放反馈迭代改进。

研究设定
研究问题为自动改进约束规划（CP）模型：用户以 CPMpy 建模库提供原始约束模型以及三个小规模训练实例，目标是在固定求解时限内自动获得一个修改后的模型，使其在保持与原模型解集可行（即解注入原模型后仍可行）的前提下提升优化目标质量。决策对象是模型的结构性变换（如对称性破除、隐含约束、全局约束、变量表示与约束重构）。关键约束包括：只考虑优化问题（以固定时间限制内的目标质量衡量性能）、训练实例仅三个且较小、正确性必须经验验证而非构造性证明、智能体运行最多 80 步且无固定时间限制。信息假设为智能体可访问原始模型、三个训练实例以及验证工具，测试实例仅在评估阶段使用。环境为静态的离线模型改进问题，但引入迭代诊断-修复的动态智能体流程。
研究动机
CP 求解器的运行时间高度依赖建模选择，但改进约束模型通常需要人类专家经验；现有自动重构系统局限于预定义的手工转换规则库，只能应用事先编码并证明可靠的变换。因此需要一种能从开放式空间提出任意重构、并通过经验验证保证正确性的自动方法。
核心洞察
其有效性来源于将正确性保证从构造性证明转移到经验验证：大语言模型智能体在开放式空间中提出模型变体，并通过将变体的解注入原模型来检验可行性，从而允许模型提出不可靠甚至错误的候选，再由验证-修复循环诊断并修正这些错误；这种闭环使得智能体可以探索预定义规则库之外的变换，同时不牺牲最终返回模型相对于原模型的正确性。但摘要指出，在候选数量相当时，非智能体基线也达到相近改进率，说明本实验规模下总体增益并非仅由迭代诊断-修复贡献。
技术挑战
  • 大语言模型从无界空间提出的重构不可靠，可能包含错误或静默改变问题语义
  • 必须同时保证所提模型相对于原模型的正确性（解可行性）与性能提升（更快或更优目标）
  • 仅用三个小训练实例引导改进，且需泛化到更大的测试实例
  • 验证过程本身需在合理时间内完成，以支持多次迭代
问题分析
作者将问题建模为智能体与环境（模型、训练实例、验证工具）的迭代交互：智能体分析原模型并应用潜在优化策略，每次提出候选模型后由自动化验证程序检查其解注入原模型后的可行性，并在训练实例上比较求解器性能；若验证失败则诊断并修复。方法不依赖预定义的规则库或问题结构分解，而是依赖大语言模型的推理能力与经验评估信号。
方法
  • 输入为 CPMpy 原始模型与三个小规模训练实例，输出为智能体认为最佳的修改后模型（proposed model）
  • 大语言模型智能体迭代提出替代模型变体，应用对称性破除、隐含约束、全局约束、约束重构、变量表示等优化策略
  • 每个候选模型通过自动化验证：将其解注入原模型检验可行性，并在训练实例上并行比较求解器性能
  • 验证失败时智能体诊断失败原因并尝试修复，继续迭代
  • 选择并保存最佳模型，同时生成日志与结果摘要，日志记录所用技术及原因与验证结果
  • 过程限制最多 80 个智能体步骤，无固定时间限制
  • 使用 ReAct 风格智能体（agentic Python coder），底层模型通过 OpenRouter 访问
