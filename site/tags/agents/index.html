Kesheng Chen · Yamin Hu · Wenjian Luo

研究设定
研究面向不具备运筹优化专业背景的领域从业者，让智能体把自然语言需求翻译为可执行的优化模型或求解器程序，并在后续连续的自然语言修改请求下持续维护该优化问题。决策对象是优化程序、已接受方案、历史修改记录与候选解集合；目标是在多目标或单目标情形下输出可行且质量较高的方案或Pareto非支配解集；关键约束包括硬约束、目标向量、可行性校验以及有限搜索预算；信息假设是智能体可获得初始请求、公开数据表、累积的公开修改与公开验证反馈，但隐藏评测器与参考解仅离线使用；环境为动态环境，需求、资源与优先级会随请求序列变化。
研究动机
领域从业者理解自身业务约束，但可能缺乏运筹优化专业知识或专门支持；基于大语言模型的优化智能体虽然能把自然语言需求转化为模型或求解器程序，但真实运营是动态的，需求、资源和优先级不断变化，需要更新数据、约束和目标。以孤立请求为中心的方法难以为保留既有决策并复用有用搜索结果的快速适应提供支持。
核心洞察
论文的核心洞察在于：把自然语言修改后的优化问题视为需要持续维护的可执行状态，而不仅是每次重新生成模型。通过保留可执行优化程序、已接受方案、历史修改记录与候选解集合，后续修改可以在已有数值搜索状态上继续，从而在频繁修改下保持更新的有效性与搜索信息的连续性。
技术挑战
  • 自然语言修改可能指向多个早期实体或遗漏约束，需澄清消歧
  • 修改后要保证生成的优化程序可执行且满足硬约束
  • 在有限搜索预算与延迟下决定复用旧候选解还是重新初始化
  • 多目标动态修改下维持Pareto解集的多样性与非支配性
  • 生成代码运行在应用进程内带来隔离与安全风险
问题分析
论文将动态优化形式化为在累积自然语言修改下的优化问题：每一轮从请求与输入表出发，后续修改定义时刻t的可行集与目标向量；单目标要求输出一个可行且目标值小的方案，多目标要求输出互不支配的可行方案集。作者通过维护可执行状态、事件记录与候选解进行分解式处理，并将语言式问题构建与数学规划、进化搜索结合，用固定求解器执行并由隐藏评测器离线评分比较。
方法
  • MAPLE把优化程序、已接受输出、输入表与候选解组成状态 S_t=(D_t,W_t,A_t,P_t)，并保留早期修改事件记录 E_t
  • 语言侧根据自然语言请求构建与修订优化程序，固定求解器执行并校验必需输出字段与结构，失败则拒绝修订并保留先前状态
  • 修改通过后提交修订后的数据、工作台、已接受输出与搜索状态，并追加已接受事件
  • 搜索侧使用NSGA-II等既定求解器，在候选复用、种群修复、迁移与初始化之间选择重启策略
  • 重启选择读取公开历史与变更摘要，搜索使用工作台评估器；隐藏评分与参考解仅离线使用
  • 主比较中，一条模型输出序列提供优化程序与重启选择，数值搜索用十个随机种子重复，每个搜索200个候选、最多200代，工作台修复上限B=3
实验
  • 提出NLDO基准，包含15条轨迹与180次更新，覆盖选择、排班、人员排班、路径规划与云资源放置
  • 主评估中MAPLE完成全部轨迹，在线标量质量达到0.951，Pareto超体积比达到0.875
  • 与ReAct、Persistent ReAct、ORLM、OptiMUS、OR-LLM-Agent、OptimAI等比较，使用DeepSeek-V4-Pro（Preview），API ID为deepseek-v4-pro
  • 受控比较表明维护可执行状态可提升更新有效性，并能在大幅修改后保留有用搜索信息
  • 控制实验显示TSS降低无效输出，某些历史请求需要同时使用更新记录与已接受方案
  • 在破坏性路径变更后全新初始化有帮助，修复后的候选解在重命名与任务添加控制中仍然有用
局限
  • MAPLE依赖固定的决策类型、求解器路由与重启动作目录，需要新决策类型或数值算子的任务需要运行时扩展
  • 类型化算子保留表示成员资格，但可行性仍取决于生成的评估函数
  • LSM将参考锚定在保留事件与已接受结果上，当请求可能指代多个早期实体或约束未说明时需要澄清
  • 语义重启门依赖模型对更新的解释
  • 进化路径在有限预算内优化，修复保留候选会在搜索前增加工作量，复用与全新初始化的选择还取决于可用延迟
  • 当前实现在应用进程内运行生成的Python函数，实际使用需要更强的文件、导入、凭证和网络隔离
  • MAPLE面向批处理或人工监督的再优化，高影响决策应支持检查、人工批准与回滚

论文直接位于AI4OR与大语言模型优化智能体方向，与学习辅助搜索和多目标动态优化相关。其记忆增强的可执行状态维护、候选解复用与重启策略对生产调度中的动态扰动重优化具有明确的迁移潜力；但要迁移到柔性作业车间、流水车间或生产运输协同，需要把决策类型目录、领域约束校验与生成式建模模板扩展到相应问题（推测），并重新验证在有限计算预算下的可行性维持与解质量。

研究设定
研究问题是如何将自然语言描述的组合优化问题自动转化为QUBO（二次无约束二元优化）公式，决策对象为二元决策变量 x∈{0,1}^n 以及QUBO矩阵Q和常数偏移c，目标形式为 min E(x)=x^T Q x + c。关键约束是需要正确识别二元变量、约束、目标函数、惩罚项及合适的惩罚权重。信息假设是输入为自然语言问题描述，可附带结构化或非结构化测试用例。环境为静态（公式生成任务），材料未说明动态扰动或在线求解设定。
研究动机
QUBO是组合优化的核心公式，且与量子、混合量子-经典及量子启发式求解器兼容，但将自然语言问题描述翻译为正确QUBO公式困难、耗时且需要大量领域专业知识。现有LLM方法主要面向LP/MILP等求解器就绪公式，QUBO设定探索较少；AutoQUBO依赖形式化程序输入，LLM-QUBO主要关注MILP转QUBO且验证有限。因此需要端到端、反馈驱动的自动QUBO公式生成框架。
核心洞察
该工作的核心洞察在于：QUBO公式生成不是一次性翻译，而是一个需要识别变量编码、约束、目标与惩罚权重的多步骤结构化过程；通过多智能体分工与迭代自修复，可以在出现错误时反馈式重述问题，从而提升最终公式的正确性。摘要明确指出迭代自修复是性能提升的最重要组件，说明其有效性来自错误反馈闭环而非单一模型能力。
技术挑战
  • 自然语言描述到QUBO公式的翻译需要同时识别二元变量、约束、目标函数、惩罚项和惩罚权重，步骤多且易出错
  • QUBO公式的正确性验证需要确保自然语言规范、结构化公式、生成实现和小规模最优解相互一致
  • 领域多样、问题类型广泛，单一直接生成调用难以覆盖
  • 惩罚权重选择影响约束可行性，但材料未说明具体处理策略
问题分析
作者通过构建端到端多智能体框架将QUBO生成分解为多个步骤，包括理解问题、选择二元编码变量和约束、定义惩罚项等。作者还构建QUBOBench基准，包含12个应用领域、100个组合优化问题，用于跨领域评估。分析指出迭代自修复是最重要组件，说明作者通过消融式分析识别各组件贡献。但材料未说明作者是否利用问题结构、分解下界或图表示等更具体的优化分析手段。
方法
  • 提出端到端多智能体框架，从自然语言问题描述自动生成QUBO公式
  • 框架支持结构化或非结构化测试用例作为输入
  • 生成过程涉及多个步骤：理解问题、选择二元编码变量和约束、定义惩罚项等
  • 包含迭代自修复组件，在出现错误时进行反馈式重述或修正
  • 构建QUBOBench基准，含100个组合优化问题、覆盖12个应用领域，来源包括同行评审文献、竞赛和经典NP-hard问题
实验

  • 相比直接单次调用基线提升22%
  • 进一步分析识别出迭代自修复是贡献性能提升的最重要组件
  • 材料未说明基线具体设置、实例规模、约束可行性验证、解质量、运行时间、训练开销、公平计算预算、泛化和消融实验的完整细节

研究设定
研究问题为自动设计优化问题的启发式算法，决策对象是启发式算法的代码实现，目标是在给定问题实例和评估协议下最大化算法性能。关键约束包括代码的可执行性和性能评估成本。信息假设为环境可通过仿真或基准实例评估，研究过程为多轮迭代的静态环境。动态性体现为多智能体协调进行的多轮搜索过程，但问题本身可能是静态或动态的（涉及模拟驾驶场景）。
研究动机
现有基于LLM的进化方法依赖随机变异循环，缺乏长期战略规划和从历史失败中学习的正式机制，导致探索效率低且重复试验。
核心洞察
OR-Agent通过将启发式搜索组织为树状工作流，显式建模假设生成的分支和系统回溯，并引入分层反思系统（短期反思作为语言梯度，长期反思作为语言动量，内存压缩作为语义权重衰减），为研究动力学提供了原则性机制，从而平衡探索与利用，提高搜索效率。
技术挑战
  • LLM生成想法的冗余和多样性不足
  • 缺乏长期规划和从失败中学习的机制
  • 需要平衡探索与利用，避免重复试验
问题分析
作者借鉴优化理论，设计了层次化反思系统，将优化术语映射到语言层面，形成引导搜索的信号；利用树结构组织研究过程，显式管理分支和回溯，并通过协调生成想法来增加多样性。
方法
  • OR-Agent框架包含OR Agent、Lead Agent、Idea Agent、Code Agent、Experiment Agent，分别负责全局协调、管理研究流程、生成想法、实现代码、执行实验。
  • 搜索过程从已有启发式数据库采样父代，通过LLM驱动的想法生成和变异交叉操作产生新想法。
  • Idea Agent基于父代解决方案、当前研究流图和长期反思生成一组有区别的孩子想法，实现协调生成。
  • 引入分层反思：短期反思作为语言梯度，长期反思作为语言动量，内存压缩作为语义权重衰减。
  • 每个研究循环由Lead Agent决定扩展、回溯或终止，并更新启发式数据库和反思。
实验
  • 在经典组合优化问题（TSP, CVRP, bin packing）和模拟合作驾驶场景上进行实验，结果显示OR-Agent优于强进化搜索基线。具体数字未在摘要中提供。结论部分提及在十二个经典组合优化问题和复杂合作驾驶环境上取得最强整体性能，但具体数值未给出。

研究设定
研究问题是为脑电图（EEG）分析自动设计端到端可执行流水线，决策对象是从原始多通道记录映射到任务预测的完整程序化脚本，目标是在测试集上最大化复合效用（包含性能、新颖性和效率）。关键约束是候选脚本必须可执行且逻辑一致，且受限于资源受限的临床环境和神经生理学先验。信息假设包括数据集异质性、任务特定性，以及大模型计算成本过高。环境是静态数据集上的离线优化，但搜索过程是动态演化的。

核心洞察

问题分析
作者将流水线设计转化为离散优化问题，通过定义程序化空间S和可执行脚本s，将求解分解为加载、预处理、模型、评估四阶段，用LLM驱动生成代码。利用领域知识进行子空间初始化，限制搜索范围；通过多目标进化优化、自反式改进和复合奖励函数来引导搜索。作者利用问题结构（程序化流水线可分解为模块）、先验知识限制搜索空间，以及反馈信号（执行结果和性能指标）来指导搜索。

研究动机
