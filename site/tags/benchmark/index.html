研究设定
研究面向不具备运筹优化专业背景的领域从业者，让智能体把自然语言需求翻译为可执行的优化模型或求解器程序，并在后续连续的自然语言修改请求下持续维护该优化问题。决策对象是优化程序、已接受方案、历史修改记录与候选解集合；目标是在多目标或单目标情形下输出可行且质量较高的方案或Pareto非支配解集；关键约束包括硬约束、目标向量、可行性校验以及有限搜索预算；信息假设是智能体可获得初始请求、公开数据表、累积的公开修改与公开验证反馈，但隐藏评测器与参考解仅离线使用；环境为动态环境，需求、资源与优先级会随请求序列变化。

问题分析
论文将动态优化形式化为在累积自然语言修改下的优化问题：每一轮从请求与输入表出发，后续修改定义时刻t的可行集与目标向量；单目标要求输出一个可行且目标值小的方案，多目标要求输出互不支配的可行方案集。作者通过维护可执行状态、事件记录与候选解进行分解式处理，并将语言式问题构建与数学规划、进化搜索结合，用固定求解器执行并由隐藏评测器离线评分比较。
方法
  • MAPLE把优化程序、已接受输出、输入表与候选解组成状态 S_t=(D_t,W_t,A_t,P_t)，并保留早期修改事件记录 E_t
  • 语言侧根据自然语言请求构建与修订优化程序，固定求解器执行并校验必需输出字段与结构，失败则拒绝修订并保留先前状态
  • 修改通过后提交修订后的数据、工作台、已接受输出与搜索状态，并追加已接受事件
  • 搜索侧使用NSGA-II等既定求解器，在候选复用、种群修复、迁移与初始化之间选择重启策略
  • 重启选择读取公开历史与变更摘要，搜索使用工作台评估器；隐藏评分与参考解仅离线使用
  • 主比较中，一条模型输出序列提供优化程序与重启选择，数值搜索用十个随机种子重复，每个搜索200个候选、最多200代，工作台修复上限B=3

  • 主评估中MAPLE完成全部轨迹，在线标量质量达到0.951，Pareto超体积比达到0.875
  • 与ReAct、Persistent ReAct、ORLM、OptiMUS、OR-LLM-Agent、OptimAI等比较，使用DeepSeek-V4-Pro（Preview），API ID为deepseek-v4-pro
  • 受控比较表明维护可执行状态可提升更新有效性，并能在大幅修改后保留有用搜索信息
  • 控制实验显示TSS降低无效输出，某些历史请求需要同时使用更新记录与已接受方案
  • 在破坏性路径变更后全新初始化有帮助，修复后的候选解在重命名与任务添加控制中仍然有用
局限
  • MAPLE依赖固定的决策类型、求解器路由与重启动作目录，需要新决策类型或数值算子的任务需要运行时扩展
  • 类型化算子保留表示成员资格，但可行性仍取决于生成的评估函数
  • LSM将参考锚定在保留事件与已接受结果上，当请求可能指代多个早期实体或约束未说明时需要澄清
  • 语义重启门依赖模型对更新的解释
  • 进化路径在有限预算内优化，修复保留候选会在搜索前增加工作量，复用与全新初始化的选择还取决于可用延迟
  • 当前实现在应用进程内运行生成的Python函数，实际使用需要更强的文件、导入、凭证和网络隔离
  • MAPLE面向批处理或人工监督的再优化，高影响决策应支持检查、人工批准与回滚

研究设定
研究问题是如何将自然语言描述的组合优化问题自动转化为QUBO（二次无约束二元优化）公式，决策对象为二元决策变量 x∈{0,1}^n 以及QUBO矩阵Q和常数偏移c，目标形式为 min E(x)=x^T Q x + c。关键约束是需要正确识别二元变量、约束、目标函数、惩罚项及合适的惩罚权重。信息假设是输入为自然语言问题描述，可附带结构化或非结构化测试用例。环境为静态（公式生成任务），材料未说明动态扰动或在线求解设定。
研究动机
QUBO是组合优化的核心公式，且与量子、混合量子-经典及量子启发式求解器兼容，但将自然语言问题描述翻译为正确QUBO公式困难、耗时且需要大量领域专业知识。现有LLM方法主要面向LP/MILP等求解器就绪公式，QUBO设定探索较少；AutoQUBO依赖形式化程序输入，LLM-QUBO主要关注MILP转QUBO且验证有限。因此需要端到端、反馈驱动的自动QUBO公式生成框架。
核心洞察
该工作的核心洞察在于：QUBO公式生成不是一次性翻译，而是一个需要识别变量编码、约束、目标与惩罚权重的多步骤结构化过程；通过多智能体分工与迭代自修复，可以在出现错误时反馈式重述问题，从而提升最终公式的正确性。摘要明确指出迭代自修复是性能提升的最重要组件，说明其有效性来自错误反馈闭环而非单一模型能力。

  • QUBO公式的正确性验证需要确保自然语言规范、结构化公式、生成实现和小规模最优解相互一致
  • 领域多样、问题类型广泛，单一直接生成调用难以覆盖

研究设定

核心洞察

技术挑战

问题分析
作者从调度问题的约束结构出发，指出其形式虽多但约束关系来自少数反复出现的类型：活动间优先级、一次处理一个活动的析取资源、在容量内允许并发的累积资源，以及每个活动的多种执行模式；据此设计只要求模型识别这些结构的领域特定语言，由确定性编译器处理后端编码，并以独立验证器直接对照源实例验证所报告调度，从而把失败面从“建模与搜索”缩小到“语义识别”。
方法

论文研究如何自动生成优化基准问题，决策对象为基准问题的数学表达式结构，目标是在灵活表达空间中演化出能够区分不同算法性能的基准问题。关键约束包括保持可复现性和可控评估成本。信息假设方面，LLM作为生成算子接收文本提示并产生符号表达式，不依赖预定义的参数形式或树结构。环境为静态离线生成，不涉及动态扰动。案例研究限定为无约束单目标连续最小化问题。
研究动机
现有的人工基准（如COCO、CEC、ZDT等）因预定义和风格化构造限制结构多样性，难以捕捉真实问题的不规则结构；而源自真实问题的基准（如RWCMOP、Mazda CdMOBP）构建成本高且因保密和知识产权限制难以公开，损害可复现性和可扩展性。现有自动基准生成方法（参数生成器、进化实例生成器、遗传编程）均受限于预定义的结构约束，限制了生成问题景观的多样性和表达性。
核心洞察
将大语言模型作为进化算子嵌入进化循环，利用自然语言文本作为基准问题的表示空间，能够突破传统参数化或树结构表示的先验约束，在更灵活的表达空间中搜索具有特定几何特征（如变量缩放敏感性）的基准问题，从而生成能一致区分目标算法与对比算法性能差异的问题实例。
技术挑战
  • 现有自动基准生成方法受限于预定义参数空间或树结构，无法捕捉真实问题的不规则结构
  • 真实问题基准构建成本高且难以公开共享，影响可复现性
  • 需要设计进化循环使LLM生成的问题在保持有效性的同时具备足够的多样性
  • 需要定量验证生成的问题确实能区分不同算法的性能
问题分析
作者通过文献回顾指出传统和真实基准的局限性，进而论证自动生成方法的必要性，并分析现有自动生成方法在表示空间上的共性限制。在此基础上，提出用LLM作为生成算子替代预定义结构约束，通过进化框架在文本符号表达式空间中搜索问题。实验部分采用探索性景观分析来揭示生成基准的几何特征，以此分析问题结构与算法行为之间的关系。
方法
  • 将基准问题表示为文本符号数学表达式，作为LLM的输入输出格式。
  • LLM在进化框架中充当生成算子，接收当前问题种群并生成新的问题变体。
  • 进化过程以目标算法与对比算法在生成问题上的性能差异为选择信号，驱动问题演化。
  • 案例研究设定目标算法为遗传算法（GA），对比算法为差分进化（DE），生成无约束单目标连续最小化问题。
  • 生成的问题通过探索性景观分析提取几何特征，验证其与算法搜索行为的关联。

  • 案例研究生成无约束单目标连续最小化问题，目标算法GA在超过80%的试验中一致优于对比算法DE。
  • 探索性景观分析表明，有利于GA的基准对变量缩放高度敏感，反映出生成问题具有反映不同算法内在搜索行为的独特几何特征。

研究设定
研究问题为在代价高昂的黑盒函数优化中，当原始输入坐标与目标函数几何不匹配时，如何通过输入扭曲提高样本效率。决策对象为输入扭曲映射的选择，目标是最小化累积遗憾或提高优化收敛性。关键约束是保留高概率收敛保证，并且扭曲映射从有限库中选取。信息假设为高斯过程先验，且目标函数平滑。环境是静态的，即目标函数固定，但评估代价高且可能存在噪声（如在多智能体系统设计中）。
研究动机
高斯过程贝叶斯优化（GP-BO）在代价高昂的黑盒函数优化中表现优异，但标准的GP-UCB理论要求固定内核。然而，固定内核无法适应输入坐标与目标函数几何不匹配的情况，例如超参数呈对数尺度或存在局部峰值时，输入扭曲能显著提升样本效率。然而，已知的GP-UCB证明均要求固定内核，阻碍了动态选择扭曲映射。因此，作者提出一种方法，允许在有限库中动态选择扭曲映射，同时保留高概率收敛保证。
