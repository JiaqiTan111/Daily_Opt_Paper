研究设定
研究对象是混合整数线性规划（MILP）的通用变量级与约束级表示学习问题；决策对象为 MILP 二分图上的变量节点与约束节点的嵌入，目标是学到在保整性的仿射重构下具有不变性与等变性的通用表示，可用于多种下游 MILP 任务；关键约束是所利用的重构必须保持整数可行域、必须对任意输入实例有效，且不使用求解器产生的标签；信息假设为可获得等价重构对并知道所施加的重构形式。环境为静态离线预训练，论文摘要与节选未说明在线或动态扰动求解环境。
研究动机
MILP 可建模能源、交通、物流等大量真实决策问题，但大规模 MILP 求解依然计算昂贵，因此已有工作尝试把机器学习嵌入求解流程（如引导分支或预测高质量部分解）。这些方法需要能够捕捉可复用问题结构的通用 MILP 表示，而 MILP 没有规范形式：同一问题可用不同单位、二进制约定或变量参数化表达，得到的公式系数与界不同，但解集由仿射映射相联系，这一等价性可作为自监督信号。
核心洞察
把求解问题本身的结构对称性当作监督信号：MILP 的保整性重构分成两类——不改变变量、只改写约束系统的 re-description，以及可预测地变换变量的 substitution。前者要求变量嵌入不变，后者要求嵌入按已知变换等变，因此一个普通对比目标是错误的，必须采用等变自监督来同时编码这两种几何关系，从而在不依赖求解器标签的情况下把已知重构行为编码进隐空间。
技术挑战
  • 刻画对所有输入实例都有效的仿射重构族，并区分 re-description 与 substitution 两类不同对称性
  • 标准对比学习会强行对两类变换都施加不变性，从而破坏变量嵌入应有的等变性
  • 在没有求解器导出标签的情况下学习同时满足不变性与等变性的表示
  • 需要让学到的表示能迁移到未见问题类并服务于多个不同层级（实例、变量、约束）的下游任务
问题分析
作者从 MILP 的等价重构出发做理论刻画：先刻画对所有输入实例有效的仿射重构，指出其可分解为 re-description（保持变量不变，仅改写约束系统）与 substitution（类型保持的仿射变量替换，可预测地变换变量），并据此推导变量嵌入应满足的不变性与等变性归纳偏置，再把这一结构转化为对比式自监督目标。节选未给出定理细节与证明步骤。
方法
  • 把 MILP 表示为变量—约束二分图，用图神经网络编码变量与约束表示
  • 使用保整性的等价重构对作为自监督来源，不使用求解器导出标签
  • 理论上把有效仿射重构分为 re-description（变量不变，应不变）与 substitution（变量可预测变换，应等变）
  • 联合训练图编码器与超网络：超网络以所施加的 substitution 为输入，预测变量嵌入应当如何变换
  • 采用等变自监督/对比目标，使编码器对 re-description 保持嵌入不变、对 substitution 产生可预测变换
  • 下游使用时冻结编码器仅训练预测头，或与编码器联合微调
实验
  • 预训练使用 29 000 个 MILP-Evolve 实例，ReMILP 与 FORGE† 均预训练 20 000 步、学习率 10^{-3}
  • 图编码器为两层四头 GATv2 注意力、128 维隐状态，在 MILP 二分图上每层先由变量更新约束再由约束更新变量，并用 Jumping Knowledge 合并各层表示
  • 不变性/等变性评估：在 D-MIPLIB 的 23 个实例族测试切片上做最近邻检索，报告平均 Top-1 与 MRR，并在 substitution 情形使用超网络预测作为查询
  • 下游任务包括实例级 integrality-gap 预测（12 500 个留出的 MILP-Evolve 实例）、变量级 binary-solution 预测与约束级 constraint-activity 预测（D-MIPLIB 十个问题类、23 个实例族）
  • 下游头为两层 MLP；binary-solution 与 constraint-activity 为节点级预测，integrality-gap 经对两类节点注意力池化得到实例嵌入后输出标量
  • 集成 gap 指标为 |LP−IP|/(max(|LP|,|IP|)+10^{-5})；binary-solution 与 constraint-activity 用 KL 散度，并按实例族对基线做几何平均归一化
  • 冻结设定下 integrality gap 测试 MAE：Random 0.063±0.008，ReMILP 0.040±0.002，FORGE† 0.053±0.007，FORGE†+attn. 0.054±0.002；不变性检索 Random Top-1 0.289±0.009、MRR 0.375±0.011，等变性检索 Random Top-1 0.091±0.011、MRR 0.121±0.013，FORGE† 不变性 Top-1 0.120±0.040、MRR 0.171±0.049
  • 结果按 3 个随机种子取均值与标准差；摘要称这些表示在未见问题类上表现出预期的不变性与等变性，冻结时携带任务相关信息，并可作为微调的良好初始化；节选未给出下游各任务完整对比表、约束可行性、求解时间、训练总开销与公平计算预算的细节

研究设定
研究在硬信息视野约束下的组合优化问题：全局目标是一个集合覆盖，但每个节点只能看到自身的k跳邻域并据此独立提交其局部选择，这些局部承诺必须组合成一个全局可行的覆盖。论文形式化为局部集合覆盖，并实例化在加权多点中继（MPR）选择上——这是OLSRv2路由协议（RFC 7181）中NP难的2跳覆盖问题，其视野由协议决定而非模型设计者选择。目标是使所选中继集的代价（如ETX或能量等链路度量）最小化，同时保证2跳邻域全覆盖。决策是每个节点的局部选择，约束是每个2跳邻居必须被至少一个被选中继覆盖，信息假设是每个节点仅能获知其k跳邻域，静态环境（随机几何单位圆盘图与真实营级机动网络）。
研究动机
主流神经组合优化假设集中式求解器能读取整个实例，但在链路状态路由等真实网络中，每个节点只能依据有限视野做出不可撤销的局部选择，且这些选择必须组合成全局可行解。作者以此逆向设定为研究对象，探讨信息视野本身对可学习性与可解质量的根本限制，并利用路由协议提供的真实问题场景验证。
核心洞察
信息视野半径而非模型容量是决定性能的主导变量。在硬信息视野下，深度只能购买计算量而不能扩展可观测半径：L层GNN在决策节点读出时恰好等价于L跳选择器，任何确定性选择器若视野少一跳，则必然要么覆盖失败要么与最优解相差Δ倍。恰好达到2跳视野时，GNN可以精确复现RFC 7181的贪心规则及其(1+ln Δ₂)近似保证，因为2跳球正是协议提供的信息边界。因此，将学习组件置于该视野内的贪心骨架上，仅让网络学习代价感知的排序，就能在加权目标上超越经典局部贪心并维持构造性可行覆盖。
技术挑战
  • 信息视野硬约束下，确定性局部选择器可能因视野不足而无法同时满足覆盖可行性与接近最优。
  • 加权MPR目标上，即使公平的代价有效性贪心也留下明显经验差距，学习策略需在极局部视野内超越手工启发式。
  • 局部承诺必须组合成全局可行覆盖，需要构造性解码器将神经评分转化为保证覆盖的离散决策。
  • 在真实营级机动网络等分布外拓扑上保持泛化能力与100%可行性。
问题分析
作者通过理论分析与实证归因相结合的方式剖析问题。首先将问题形式化为局部集合覆盖，定义局部选择器的视野半径与全局可行性组合条件。随后证明两个理论结果：确定性选择器若视野少一跳，则必然覆盖失败或与最优解相差Δ倍；L层GNN在决策节点读出时恰好是L跳选择器，说明深度不能扩展半径。反过来，在恰好2跳视野下，O(Δ)深度的GNN可复现RFC 7181覆盖贪心，O(c_max Δ)宽度可复现度量感知的加权贪心，并继承(1+ln Δ₂)近似保证。实证上，作者将可行性分析与优化解耦，通过构造性解码器保证100%覆盖，使神经编码器专注于代价优化；并通过消融、泛化与真实网络迁移检查定位视野而非容量为主要变量。
方法
  • 问题形式化：将分布式局部承诺组合问题建模为局部集合覆盖，并实例化为加权MPR选择。
  • 理论边界：证明视野不足一小时的Δ倍最优性差距或不可行性，以及L层GNN等价于L跳选择器的容量-半径关系。
  • 构造性覆盖解码器：将神经评分贪婪地转化为每个节点的中继选择，保证组合后100%覆盖可行性。
  • GATv2编码器：在2跳视野内读取局部拓扑与链路度量，输出代价感知的中继排序。
  • 行为克隆训练：从CP-SAT整数规划最优解中克隆加权MPR决策，避免稀疏奖励与信用分配问题。
  • 模型选择：以解码后的验证集代价比作为选择标准，直接度量部署解码而非代理损失。
实验
  • 实验设置：随机几何单位圆盘图，n个节点均匀分布于单位正方形，半径r内连边，链路带与长度相关的整数度量；加权MPR目标为所选中继面向中心链路度量之和；CP-SAT整数规划求解每个实例至最优，定义cost/opt=1.0。

预训练策略已经在大范围调度状态空间中探索过，因而为离线微调提供了信息丰富的先验，使离线阶段不必仅依赖有限且可能低质量的历史数据覆盖度；同时，KL散度策略约束将微调限制在预训练策略附近，防止在低质量或分布偏移数据上过度偏离而崩溃。这一“先在线探索、后离线适应”的反向训练顺序，正是其相对独立离线RL和在线RL基线在分布偏移和低质量数据下更稳健的根本原因。

问题分析

研究设定
研究问题为一维装箱问题（1D-BPP）：将 n 个已知重量 w_i 的物品装入容量为 C 的相同箱子中，使所用箱子数最少且每箱总重不超过 C。决策对象是装箱过程中如何将两个可兼容的部分箱合并，直至无法继续合并。目标是最小化装箱数，关键约束为容量约束与物品不可拆分。信息假设为物品重量与容量均已知且离线，环境为静态组合优化环境，材料未说明动态扰动或在线到达设定。
研究动机
1D-BPP 是物流、制造与云资源管理中的核心 NP-hard 问题，精确方法难以扩展到大规模或结构困难实例，而多数学习型装箱方法面向 2D/3D 变体，针对 1D-BPP 的智能学习求解器仍很稀缺。作者希望构建一个端到端、尺寸无关的学习求解框架，在无需逐实例搜索、无需人工设计交叉变异或修复算子的情况下超越构造启发式并在部分结构族上比肩求解器增强方法。

问题分析

方法
  • 将 1D-BPP 的装箱过程形式化为物品兼容图上的马尔可夫决策过程，图中边表示两个部分箱可合并（重量之和不超过容量）。
  • 每个动作合并两个互相兼容的部分箱，形成新的部分箱，作为状态转移。
  • 使用图神经网络 actor–critic 策略从兼容图表示中提取关系特征；编码器为 GCN，L=3 层，维度 d=128，带残差与 LayerNorm，dropout 0.1。
  • actor 与 critic 为 MLP：actor 输入 2d 经 128→64→1，critic 输入 d 经 128→64→1。
  • 使用 PPO 训练，ε=0.2，c_v=0.5，c_e=0.01，K=4 个内部 epoch，Adam 优化器学习率 3×10^-4，梯度范数裁剪 1.0，折扣 γ=1（有限时域）。

研究设定
本文研究静态的带时间窗容量车辆路径问题（CVRPTW），决策对象为客户分组与路径顺序，目标是最小化总行驶成本或满足约束，关键约束包括车辆容量和时间窗。使用量子退火和模拟退火求解，将问题建模为QUBO。环境为静态的确定性实例，基准为Solomon。动态性和信息假设材料未说明。
研究动机
量子退火求解车辆路径问题时，随着客户数量增加QUBO规模过大，难以直接求解。已有的图粗化启发式依赖特定实例族且泛化性差，随机实例上不可靠。作者旨在通过自适应惩罚校准和GNN引导的图粗化，提高求解可行性并缩减问题规模，使量子退火更实用。
核心洞察
核心洞察在于：QUBO惩罚项的内部系数范围而非整体缩放是影响原始样本可行性的关键因素；通过剔除无效约束、归一化有效约束并缩放剩余惩罚，可显著减少约束违反而无需增加求解预算。同时，GNN可以学习统一的合并评分策略，替代需要手工调整的启发式，在不同实例族上具有更好的泛化能力。
技术挑战
  • QUBO规模过大导致量子退火无法直接处理
  • 现有粗化启发式需要针对实例族手动调参且随机实例上不可靠
  • QUBO惩罚系数设置不当导致约束违反率高
  • 量子退火硬件噪声和有限相干时间导致采样质量低
问题分析
作者通过将问题分解为QUBO建模、图粗化缩减、惩罚校准、求解与展开等阶段进行分析。图粗化通过合并兼容的客户节点减少变量数；惩罚校准通过统计约束的绑定情况，调整系数范围来改善条件数，从而提升原始样本的可行性；GNN则从图结构学习节点合并的优劣评分，实现自动化粗化。分析中使用了统计检验（如p值）验证改进的显著性，并通过控制变量（保持变量数不变）分离了条件数和问题规模的影响。

  • 自适应惩罚校准：移除无效约束，归一化绑定约束，调整剩余惩罚的系数范围
  • GNN引导的图粗化：训练GNN学习节点合并评分，将客户节点合并为超级节点，减少变量数
  • 通过模拟退火或D-Wave Advantage2求解缩减后的QUBO，再将解展开到原始图
  • 与手工调整的粗化启发式进行对比，评估不同客户数（N=10至100）下的可行性和问题缩减比
