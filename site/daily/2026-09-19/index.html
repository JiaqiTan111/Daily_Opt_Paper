研究设定
研究静态作业车间调度问题（JSSP），决策对象为在解码时间步上从可用操作集中选择下一个操作，目标为最小化最大完工时间（makespan），关键约束包括工序前后顺序约束与机器共享（析取）约束，实例以析取图表征。信息假设为训练阶段可采样随机 JSSP 实例并访问完整析取图，测试阶段给定未见实例进行零样本调度；环境为静态调度（半活动调度），论文明确指出状态转移的随机性（如加工时间波动）及动态工件到达、异构机器、频繁扰动等未纳入考虑。
研究动机

问题分析
作者将 JSSP 建模为析取图，操作节点通过前驱、后继与机器共享边连接，并以源节点与汇聚节点表示边界。作者区分初始状态生成函数与状态转移，将决策过程形式化为在每步从可用操作集 A(s_t) 中选择操作并立即安排到指定机器、保证零不必要空闲（半活动调度）。在此基础上，作者用变分推断将图结构编码为隐变量 z，推导结合最大熵强化学习的 ELBO 目标，并据此把训练拆分为表示学习阶段与策略学习阶段，从而在数学上解耦两个优化过程。

  • 采用变分图编码器 q_φ(z|G) 将 JSSP 实例映射为隐变量 z，再由解码器 g_ψ(z) 重构节点与边信息。
  • 表示学习阶段目标为 L_repr = β·L_KL + L_node + L_edge，以随机采样 JSSP 实例进行训练。

研究设定
论文研究多模态运动规划（M³P）问题，属于任务与运动规划（TAMP）的特例：机器人需要在离散工作模式（如抓取、行走、导航）之间切换，同时对连续运动进行联合推理，决策对象是模式序列与连续轨迹的联合解，目标是在混合离散-连续决策空间中生成可行且鲁棒的运动路径。关键约束包括符号约束与几何约束的紧耦合、非凸性以及需要采用近似、基于离散化的混合整数规划（MIP）形式。信息假设为环境为静态、模型与任务信息已知，作者在结论中明确指出该流程主要面向静态环境，不支持带移动障碍或时变约束的动态场景。
研究动机
现有 TAMP 与 M³P 方法多依赖领域特定启发式或局部最优性、可微性等假设，常将任务规划与运动规划解耦，导致融合较弱；纯符号方法（如 PDDL）高层推理高效但难以处理连续可行性。MIP 虽提供统一框架，但针对非凸机器人任务构建可求解的近似离散化 MIP 公式通常需要人工、领域特定地完成，难以规模化。因此作者希望让 LLM 借助求解器反馈自动生成可执行的 MIP 建模代码，使语言推理与基于优化的规划真正衔接。
核心洞察

技术挑战
  • M³P 同时包含离散模式转移与连续动力学，形成大规模且符号约束与几何约束紧耦合的混合决策空间。
  • 非凸机器人任务需要近似、离散化的 MIP 形式，而这类形式通常由人类专家手工、领域特定地构建。

问题分析
作者把 M³P 建模为 MIP 变量、约束与目标的分解问题，并利用问题结构将任务拆解为模态级离散化原语与跨模态耦合约束两类构件，由 LLM 依据任务描述组合这些构件并生成可执行程序。在训练环节，作者采用结果驱动的奖励，用求解器对生成代码的执行结果进行评估，从而为模型提供可验证的学习信号；同时构建了覆盖单模态与多模态组合的基准，用以检验模型在未见过任务难度上的泛化。
方法
  • 用强化学习微调大语言模型，将 M³P 任务分解为 MIP 的变量、约束和目标，而不是直接输出答案。
  • 模型生成使用 MIP 优化库与约束接口的可执行 Python 代码，由求解器执行以获得稳健且可验证的解。
  • 采用结果驱动、面向求解器的奖励进行训练，使模型学会组合模态级离散化原语并合成跨模态耦合约束。
  • 采用 GRPO 进行训练，使模型学习组合离散化 API 并构造 MIP 分解来求解 M³P 任务，而非依赖记忆的模式。
  • 面向非凸机器人规划的近似、基于离散化的 MIP 形式，区别于以往 LLM 优化工作所针对的精确 MIP/MILP。

研究设定
研究问题为多车道道路上自车与多个反应型对手车辆交互的规划控制；决策对象包括整数型机动决策（换道与安全区域选择）和连续运动量，目标是在场景树采样下兼顾跟踪性能与对隐藏对手参数的不确定性削减，关键约束为混合整数非线性规划(16)及其安全/交互约束，信息假设为对手行为由隐藏参数驱动的多模态不确定性、场景树采样其可能交互，环境为动态闭环仿真中的交互式驾驶。

核心洞察

技术挑战
  • 混合整数非线性规划(16)为NP-hard，求解时间随交互场景复杂度急剧增长
  • 多对手多车道下场景树规模膨胀，整数变量与连续运动耦合
  • 需保持安全关键场景下预测决策的可解释性与最优性

问题分析
作者先建立含多车多车道的交互式驾驶系统模型，将对偶 MPC 表述为含整数机动决策与连续运动的混合整数非线性规划(16)，并用对手可能交互的场景树处理多模态不确定性；随后把该 MINLP 表示为变量节点、约束节点和边构成的二部图，将求解最优整数决策的问题转化为图上的节点分类/分布预测问题，利用训练实例共享的结构先验，由GNN预测每个决策的最优值分布，再用置信度阈值固定部分整数变量，仅在剩余模糊变量上调用求解器（如SCIP）完成分支定界。
方法
  • 构建多对手多车道对偶MPC问题(16)：联合优化整数机动决策（换道取{-1,0,+1}、安全区域取Q）与连续运动，场景树采样对手可能交互，目标包含跟踪与信息寻求
  • 把(16)的变量、约束及其边关系建成图G，作为GNN输入；变量节点V与约束节点C先经各自MLP嵌入为V1、C1
  • 约束侧消息传递：MLP由两端节点嵌入与边特征E计算每条边消息，约束节点聚合更新为C2；变量侧再聚合更新后的约束节点得到V2
  • 最后由MLP把每个变量嵌入V2映射为标量分数，对组成决策z的二值变量分数做softmax，得到p_z(ζ)=Pr(z*=ζ)，换道无变化选项分数设为零
  • 训练：在随机交通闭环仿真中收集每个MINLP的图G及其由SCIP求解全问题得到的最优机动决策{z*}，以交叉熵 -∑ log p_z(z*) 最小化训练GNN
  • 推理：用GNN预测的分布固定高置信度整数决策，仅将模糊决策留给分支定界求解，得到缩减后的问题并求解
