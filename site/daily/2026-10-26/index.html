求解混合整数线性规划的分支-过滤方法

A branch-and-filter method for mixed-integer linear programming

Nikos Dimou

核心洞察

这种有效性来自把非凸连续优化中的 penalty-free 过滤思想移植到整数树搜索：用不可行性度量与依赖当前 incumbent 的目标坐标构成过滤器，作为节点准入的历史记录，再配合锚定全局松弛下界的漏斗机制来保证目标有进展；当过滤器和漏斗机制都无法保证足够进展时，强制进入恢复阶段。这样，搜索不再只依赖启发式的节点选择，而是由历史过滤记录和恢复机制共同保证整数不可行性趋于零、目标值渐近最优。

为什么值得看：对关注约束可行性、全局最优保证和公平计算预算的调度与优化研究者而言，该文提供了一种把节点接受机制与收敛性证明绑定的新视角，可用于思考学习辅助搜索中启发式节点选择缺乏进展保证的问题；其迭代复杂度界和恢复预言机的设计思路，也可作为评估精确方法与学习方法的理论参照，但需注意其计算代价与调度问题结构之间的差距。

研究设定
研究一般形式的混合整数线性规划：最小化 c^T x，约束为 Ax ≤ b，x 在整数变量与连续变量之间混合，参数为有理数，目标是获得全局最优解，或者判定问题不可行；采用树搜索，在松弛下界、分支动作和节点接受机制下逐步逼近整数可行性，环境是静态的，不涉及动态扰动或随机性；关键信息假设为最优值有界、存在根本松弛，以及恢复预言机在有限步内终止。
研究动机
经典树搜索（BB、BC、branch-and-price）虽然能保证全局最优，但搜索策略（best-bound、深度优先、best-projection、best-estimate 等）主要依据启发式信息选择节点，其选择准则并不构成向整数可行性和最优性推进的充分条件。作者希望让节点接受机制本身承担解析控制作用，由此获得收敛性与复杂度保证。
核心洞察
这种有效性来自把非凸连续优化中的 penalty-free 过滤思想移植到整数树搜索：用不可行性度量与依赖当前 incumbent 的目标坐标构成过滤器，作为节点准入的历史记录，再配合锚定全局松弛下界的漏斗机制来保证目标有进展；当过滤器和漏斗机制都无法保证足够进展时，强制进入恢复阶段。这样，搜索不再只依赖启发式的节点选择，而是由历史过滤记录和恢复机制共同保证整数不可行性趋于零、目标值渐近最优。
技术挑战
  • 过滤准入只使用当前过滤集，却需要关于全部已准入记录的信息，因此从当前记录过渡到历史记录需要额外论证
  • 恢复预言机要求有限步终止，这在一般情况下难以满足，需要额外假设（如整数变量有界）才能实现
  • 单元删除恢复过程在最坏情况下可能需要穷举探索，计算代价高
  • 如何在保持全局收敛保证的前提下选择替代最优性度量或替代机制尚不清楚
问题分析
作者把 MILP 重写为在混合整数可行集 X = P ∩ (Z^p × R^q) 上最小化线性目标，并以松弛下界 f_low 作为全局锚点。分析路径是：先形式化过滤器 (h, g) 的准入与删除准则，证明被删记录链满足单调性引理，从而把“当前过滤集”的准入测试提升为历史记录之间的比较；再在 F1–F3 假设下证明算法要么在有限步内判定不可行，要么收敛到全局最优；最后通过固定整数线性规划恢复，把外层迭代复杂度界定为 O(ε^{-1})。恢复预言机则用单元删除算法实现，把子问题分解为有限个 LP 或析取规划子问题。
方法
  • 定义过滤器机制：以整数不可行性度量和 incumbent 依赖的目标坐标作为二维记录，节点只有不被过滤集支配时才被准入，并在支配关系下删除旧记录
  • 引入漏斗机制，锚定全局松弛下界，保证目标坐标的渐近进展
  • 当过滤器和漏斗机制都无法提供足够进展时，转入恢复阶段，调用恢复预言机 (OR1)–(OR3) 之一
  • 恢复预言机的实现之一是单元删除算法：在整数变量有界假设下，通过有限次连续 LP 求解或析取规划子问题，返回过滤可行的点或判定空集
  • 给出三种 BF 变体：恢复阶段分别用分支定界 (BF-BB)、分支切割 (BF-BC) 和所提单元删除 (BF-CD) 实现
  • 理论结果：在温和假设下，算法要么有限步判定不可行，要么收敛到全局最优；并给出 O(ε^{-1}) 的外层迭代复杂度界
实验
  • 实验分两组：第一组比较单元删除恢复预言机与现有实现，看谁能更快输出过滤可行点；第二组在 BF-BB、BF-BC、BF-CD 三种变体与开源求解器 SCIP、商业求解器 Gurobi 之间比较求解 MILP 到数值最优的性能
  • 实验环境为 2.10GHz 12 代 Intel Core i7-1260P、16GB RAM、Python 3.13.16、Gurobi 13.0.3 用于 LP 与辅助 MILP 求解；BF-BB 与 BF-BC 用 Gurobi 求解所选节点的混合整数子问题，采用最大不可行分支
  • 摘要与节选未给出具体实例规模、加速比、解质量差距或运行时间数字；作者提到 BF-CD 常能快速返回分数过滤可行点，而 BB/BC 实现更常完成节点整数优化，但反复的析取求解可能使完整 CD 阶段昂贵，CD 与 BB 回退的混合可加速收敛
局限
  • 恢复预言机的有限步终止条件一般难以满足，除非附加假设
  • 单元删除恢复在最坏情况下可能需要穷举探索，计算上可能很昂贵
  • 两种目标度量的优劣缺乏解析研究；作者明确指出仍有很大改进空间
与你的研究关系
论文研究的是 MILP 精确求解的树搜索机制，属于数学规划与组合优化的基础方法，与 AI4OR 中的精确求解器内核、学习辅助搜索的节点选择以及约束可行性保证直接相关。它与神经网络辅助求解、强化学习或智能体优化的关联是推测性的：若要迁移到柔性作业车间或分布式生产调度，需要先把调度问题建模为 MILP，再把过滤器的不可行性度量对应到调度约束违反度，把目标坐标对应到 makespan 或能耗等目标，并验证恢复预言机在调度结构下的有限终止性；这些迁移条件论文均未讨论。
证据与不确定性

全文仅为节选，缺少具体实验数字、实例规模和完整算法伪代码；恢复预言机的三种结果 (OR1)–(OR3) 的完整定义、F1–F3 假设的精确表述以及 BF 与 SCIP、Gurobi 的比较结论，只能依据摘要和可见片段判断，无法核实实际性能优势。

论文提出一种带过滤机制的 MILP 树搜索框架，并给出收敛性与复杂度保证：We develop a new tree-search framework for mixed-integer linear programming problems, which incorporates a filter mechanism as a node-acceptance device.
算法在温和假设下要么有限步判定不可行，要么收敛到全局最优：Under mild assumptions, the introduced method either certifies infeasibility in finitely many iterations, or converges to global optimality.
给出 O(ε^{-1}) 的外层迭代复杂度界：we establish a total outer iteration complexity bound of order $\mathcal{O}(\varepsilon^{-1})$ to certification of an $\varepsilon$-optimal mixed-integer solution through fixed-integer linear programming recovery
实验比较 BF 与基准求解器，覆盖 BB、BC 和单元删除三种恢复实现：We finally perform several numerical experiments to study the performance of branch-and-filter against benchmark solvers, under a branch-and-bound, a branch-and-cut, and a novel cell-deletion realization of the proposed restoration oracle.
现有搜索策略的选择准则并不构成向整数性推进的充分条件：Although these strategy rules exploit information relevant to feasibility and optimality, their selection criteria are not based on conditions sufficient for progress towards integrality.
单元删除恢复过程可能计算昂贵，最坏情况下需要穷举探索：this particular procedure can be computationally expensive
作者承认 BF 仍有很大改进空间：Although branch-and-filter is accompanied by some promising computational results, there is plenty of room for improvement.

R²E：面向自动化奖励函数设计的角色驱动奖励进化框架

$R^2E:$ A Role-driven Reward Evolutionary Framework for Automated Reward Function Design

Shouhao Chang · Xuan Liu · Hongye Zhu · Xinning Chen · Shigeng Zhang

核心洞察

核心洞察在于把奖励函数设计从无差别采样转变为显式的结构化协作搜索：通过为LLM分配具有互补目标的角色（探索者追求新颖性以扩展搜索空间、守护者做保守精修以提升训练稳定、进化者通过交叉变异重组高性能结构），并用动态调度逐步从广泛探索转向聚焦利用，从而在探索与稳定之间取得平衡；同时以固定容量的全局精英池保存历史最优奖励，作为跨角色协作与后续世代的持久参考，缓解迭代回退导致的优化不稳定。

为什么值得看：对关注学习辅助搜索与LLM智能体优化机制的研究者，该文提供了一个可借鉴的结构化搜索框架：用互补角色替代单一提示采样、用精英池提供跨代记忆、用动态调度平衡探索与利用，这些机制与进化算法和搜索策略设计相关，可启发调度规则自动生成或多智能体协同搜索的实验设计；同时其以归一化得分和多种子评估报告结果的做法也值得参考。

模型细分主题：基于大语言模型的自动化奖励函数设计与奖励空间搜索

模型原始标签：大语言模型、奖励函数设计、进化搜索、多角色协作、强化学习、机器人控制

第一单位：Hunan University

通讯作者：Xuan Liu

首次上传：2026-10

arXiv 摘要 ↗ PDF ↗官方 HTML ↗

图片来自论文官方 arXiv 页面，仅用于论文导航与学术阅读；版权归论文作者或相关权利人所有。

研究设定
研究问题是在强化学习尤其是复杂机器人控制任务中自动设计奖励函数，以减少人工试错。决策对象是每一代生成的奖励函数代码，目标是在给定任务描述与环境代码条件下搜索出使策略性能最优的奖励函数；关键约束包括训练稳定性、探索空间覆盖与历史优质奖励的保留，信息假设是可获取环境代码、任务描述与训练反馈，环境为迭代式的奖励生成—策略训练—评估—进化循环，材料未说明是否处理非平稳或在线动态扰动。
研究动机
手工奖励工程依赖领域专家且难以扩展；逆强化学习与偏好强化学习虽减少专家依赖，但数据成本高且表示不透明。已有基于大语言模型的奖励生成框架（如Eureka）采用单一提示下的无差别采样，多样性主要来自随机性而非结构化搜索，且历史反馈利用不足，容易在迭代回退时丢弃高性能奖励，导致奖励空间探索不充分和优化不稳定。
核心洞察
核心洞察在于把奖励函数设计从无差别采样转变为显式的结构化协作搜索：通过为LLM分配具有互补目标的角色（探索者追求新颖性以扩展搜索空间、守护者做保守精修以提升训练稳定、进化者通过交叉变异重组高性能结构），并用动态调度逐步从广泛探索转向聚焦利用，从而在探索与稳定之间取得平衡；同时以固定容量的全局精英池保存历史最优奖励，作为跨角色协作与后续世代的持久参考，缓解迭代回退导致的优化不稳定。
技术挑战
  • 无差别采样导致奖励空间探索不足
  • 历史反馈利用有限导致优化不稳定
  • 探索新颖性与训练稳定性之间的平衡
  • 跨角色协作缺乏共享记忆介质
  • 复杂机器人任务中奖励搜索容易陷入局部最优
问题分析
作者通过对比Eureka的迭代流程指出其两个结构性问题：单调提示下候选多样性主要来自随机性，且迭代T+1性能回退时仅以T+1为参考而丢弃T的高性能奖励。据此作者将搜索过程分解为初始广泛探索阶段与角色驱动进化阶段，用全局精英池保留历史最优作为跨代参考，并用动态调度公式（细节在附录D.2，节选未给出）协调探索者、守护者与进化者的生成比例，从而利用问题结构在探索与利用之间进行阶段性转移。
方法
  • 第一阶段初始迭代：基于环境代码与任务描述进行广泛探索生成奖励候选，经IsaacGym或Bi-DexHands任务训练评估后，以Top 5初始化容量K=5的全局精英池
  • 第二阶段角色驱动迭代：每轮共生成N=16个候选，由探索者、守护者、进化者三个LLM角色按动态调度策略分工生成，探索者促进新颖性、守护者做保守精修、进化者通过交叉与变异重组高性能奖励
  • 动态调度策略随迭代逐步将搜索从广泛探索转向聚焦利用，具体公式在附录D.2，节选未给出
  • 全局精英池作为跨角色协作介质，保留并排序历史最优奖励，新候选若性能超过池中最差候选则替换之，保证池质量持续提升
  • 第三阶段结束：搜索结束后选取全局精英池中Top 1奖励，在五个随机种子上重新评估作为最终输出
  • 代码已公开于 https://github.com/ChangYuandao/R2E
实验
  • 在IsaacGym与Bi-DexHands共14个任务上评估，其中IsaacGym含6个移动与操作任务，Bi-DexHands含8个需要复杂双臂协调的任务
  • IsaacGym结果以均值±标准差报告，并以(Sparse)与(Human)归一化计算平均归一化得分；表中Ours在Ant、Anymal、Quadcopter、AllegroHand、FrankaCabinet、ShadowHand上平均归一化得分为2.4908，高于Eureka的1.4578、REvolve的1.8500与RF-Agent的2.1512
  • Bi-DexHands以5个随机种子的成功率均值与误差条比较，节选称R²E在所有环境中取得最高平均成功率并保持有竞争力的稳定性，但未给出完整数字
  • 节选包含候选数与迭代数缩放实验：8候选40迭代、16候选80迭代、24候选120迭代，对应指标随规模提升，24候选120迭代时Ant为7.9834±0.2569、AllegroHand为24.4028±0.3644、归一化得分为0.9534±0.0135，但该缩放实验的完整表格与训练开销未在节选中给出
  • 最终Top 1奖励在五个随机种子上重新评估以报告结果
局限
  • 作者在结论中明确提出：如何保留失败奖励函数中的经验并与成功经验共同使用尚待解决，该记忆应跨迭代持久化
  • 作者明确提出：如何决定进化何时停止尚需进一步研究
