研究设定
研究问题为 AutoML 中的 CASH 问题，即联合进行算法选择与算法特定超参数调优；决策对象是在候选算法及其各自的条件超参数空间中进行配置选择，目标是在有限评估预算下高效搜索高维、结构化、条件化的配置空间以找到高性能配置；关键约束包括冷启动困难、CASH 空间高维且结构化、算法间与算法内需协调探索与利用、现有方法使用平坦优化历史导致跨算法观测混合并掩盖配置细化轨迹；信息假设方面，BO 将配置视为抽象数值向量缺乏先验知识，LLM 可提供语义先验和领域知识；环境为静态的黑盒优化设定，通过迭代评估配置的性能反馈进行搜索，未涉及动态扰动或在线环境变化。
研究动机
降低机器学习应用的专业知识门槛需要自动化算法选择与超参数调优。纯 BO 方法将配置视为抽象数值向量，无法引入先验知识，导致高维条件搜索空间需要大量评估且存在冷启动问题。LLM 通过语义先验可缓解冷启动，但现有基于 LLM 的优化器难以泛化到高维结构化 CASH 空间。CASH 要求同时在候选算法之间和算法特定超参数空间内部协调探索与利用，而现有方法依赖平坦优化历史，混合了跨算法的观测并掩盖了配置细化轨迹。因此需要一种能结构化组织优化轨迹、协同 BO 与 LLM 优势的框架。
核心洞察
将蒙特卡洛树搜索（MCTS）树作为算法选择、超参数细化和 BO-LLM 提议器协同的共享状态，可以显式地隔离算法特定历史并保留配置细化轨迹，使跨算法的层次化探索与算法内的局部利用在同一轨迹中自然协调；同时，随着代理模型可靠性提升，提议策略从 LLM 驱动逐步过渡到 BO 驱动，能够在不同优化阶段动态利用语义先验或定量代理模型的各自优势。
技术挑战
  • 高效上下文利用：CASH 具有层次化结构，现有 LLM 优化器使用平坦历史混合跨算法观测，难以在有限上下文窗口内有效利用结构化优化历史
  • 算法间与算法内的协调探索与利用：需要在候选算法选择和算法特定超参数空间内部同时平衡探索与利用
  • 高维结构化条件搜索空间：CASH 空间高维且条件化，纯 BO 缺乏先验知识导致冷启动和大量评估需求，纯 LLM 无法拟合代理模型且难以量化不确定性
问题分析
作者分析了现有方法的不足：BO 将配置视为抽象数值向量，缺少先验知识，在高维条件搜索空间中需要大量评估且存在冷启动；纯 LLM 优化器不拟合代理模型、不量化不确定性，且受限于上下文窗口无法充分利用完整优化历史；现有 LLM-BO 混合方法仍局限于非结构化和低维问题，未探索高维结构化 CASH 空间。基于此，作者提出将优化轨迹结构化为 MCTS 树，利用树结构隔离算法特定历史，通过路径感知选择性记忆机制为 LLM 提供结构化上下文，并设计可靠性感知的提议器策略根据代理模型质量自适应选择 LLM 或 BO 提议。
方法
  • 提出 LB-MCTS 框架，使用蒙特卡洛树搜索（MCTS）树作为算法选择、超参数细化和 BO-LLM 提议器协同的共享状态，统一优化轨迹
  • BO 提供算法特定的代理模型，用于定量搜索和算法内超参数细化
  • LLM 利用路径感知的选择性记忆（Selective Tuning Memory, STM）生成语义提议和反思，STM 机制隔离算法特定历史并组合全局与局部记忆以增强推理
  • 反思机制将数值反馈转化为可复用的语言指导，进一步强化 STM
  • 可靠性感知的提议器策略：随着代理模型改善，自适应地从 LLM 驱动提议转向 BO 驱动提议，在统一搜索轨迹内实现协同
  • MCTS 实现跨算法和算法内子树的探索-利用权衡
实验
  • 在 104 个 AMLB 数据集上进行实验，LB-MCTS 一致优于基于 BO、基于 LLM 及混合基线
  • 最终平均排名为 2.16，第二优基线 RB 的排名为 3.49
  • 在测试集上评估验证集最优配置，LB-MCTS 取得领先平均排名 3.05，并在统计上显著优于所有基线

  • 消融研究支持搜索结构、记忆机制和 BO-LLM 协作的贡献（附录 C.11、C.12）
  • 附录 C.7 分析 API 成本和墙钟开销，显示 LB-MCTS 以约 0.127 美元的经济成本取得这些增益

模型细分主题：概率型服务选项下的动态信息展示与需求管理：序列决策建模、强化学习近似真实概率与采样混合整数规划优化信息展示

研究设定
研究在服务提供者于预订时向客户展示“获得有限容量高级服务结果（如快递柜）的概率”这一场景下的需求管理问题。决策对象包括两类：一是每个到达订单的状态下向客户展示的概率信息（显示概率），二是订单的服务结果分配（分配到基础结果如包裹店，或容量受限的高级结果如快递柜）。目标是优化聚合客户效用/满意度，同时受限于透明度约束（显示概率与真实概率的偏离程度）。关键约束包括：高级结果容量有限、基础结果容量视为充足、概率必须真实或受透明度约束限制、分配方案为非预期型（non-anticipatory）。信息假设为：客户依赖展示概率做选择但无法验证其准确性；真实概率内生于系统状态、客户选择、未来需求与分配策略，而非静态属性。环境为无限时域序列决策过程，需求随机到达，容量不确定（快递柜可用性取决于客户取件行为）。
研究动机
服务提供者面临客户参与带来的容量不确定性：若为每笔预订保证服务，需保守定义可行性，导致收益损失与容量利用不足。为在事后处理容量不足，提供者可将客户重定向至后备选项或降级服务，但这将风险与不便转移给客户。在预订时披露预测服务水平的概率，既可支持客户做出符合自身偏好的知情选择，又可作为需求塑造工具，引导客户在服务选项间重新分布，减少需求集中。然而，由于真实概率内生于系统状态而非提供者控制的静态属性，且客户无法验证信息准确性，提供者可能操纵显示概率以引导客户选择，形成一种新的需求管理杠杆，因此需要研究透明度约束及其对各方的影响。
核心洞察
论文的核心洞察在于：在概率型服务选项中，真实的服务概率并非静态产品属性，而是内生于系统状态、未来需求、客户选择与分配策略的递归结果。因此，提供者可以通过策略性地偏离真实概率来主动塑造需求分布，从而提升聚合系统性能；但这一信息杠杆的可行性取决于客户无法验证概率准确性这一信息不对称。作者进一步证明，在非预期型分配方案下，完全透明对应的显示概率存在唯一可行解，从而为透明度约束提供了理论锚点。该洞察之所以有效，是因为它将“信息展示”从被动的信息传递转变为内生的决策变量，并通过递归方程与透明度约束将提供者的操纵动机与客户效用之间的权衡显式建模。
技术挑战
  • 真实概率的精确计算在现实规模下不可行：需要递归枚举所有状态转移直到订单被分配，计算树规模随问题规模组合爆炸。
  • 显示概率与分配决策相互耦合：显示概率影响客户选择进而影响未来订单构成，分配决策影响可用容量，两者共同决定真实概率，需联合优化以满足透明度约束。
  • 概率展示决策空间连续且需嵌入客户选择行为：需要有效搜索连续概率空间并准确刻画客户对概率信息的反应。
  • 透明度约束下可能存在多组显示概率产生相同客户选择与目标值，需惩罚不必要的偏离以确保提供者仅做必要扭曲。
  • 真实概率依赖于策略与状态，需在训练中近似策略相关的未来事件概率，并评估近似质量。

研究问题为多母线接入的大规模数据中心负荷如何影响长期发输电协同扩展规划；决策对象是多年期的输电线路投资（TEP）与发电容量投资（GEP）；目标是最小化15年净现值总系统成本；关键约束是嵌入机组组合（UC）的运行约束；信息假设为基于修改的 IEEE 24 节点可靠性测试系统（RTS-24）与 ERCOT 校准的可再生能源出力曲线；环境为多年度静态规划（非在线动态环境，材料未说明不确定性处理方式）。
研究动机
超大规模数据中心的快速扩张给电网扩展规划带来挑战，而现有研究大多关注运行灵活性，较少考察其对长期投资决策的影响，因此作者希望量化数据中心负荷对发输电协同扩展规划方案与成本的影响。
核心洞察
该研究揭示的关键效应是：当原有可再生能源已接近满发利用、弃电空间可忽略时，新增数据中心负荷几乎全部由增量火电承担，这种供给结构变化会改变电网与电源两类投资的相对经济性，使最优方案从以输电加固为主转向以新建燃气机组为主，即合理选址的发电容量可以在经济上替代输电网络加固。
技术挑战
  • 在多年期规划中嵌入机组组合会带来大规模混合整数线性规划的计算复杂性
  • 需要在多个母线间合理分配数据中心负荷以反映选址差异
  • 需区分运行成本与资本投资在总成本中的主导地位及其对规划方案的影响
问题分析
作者通过构建多年期、嵌入机组组合的混合整数线性规划模型，将数据中心负荷按电压等级、发电裕度、可再生共址条件和网络连通性分配到四个母线，并在 RTS-24 系统上对比基准情形与加负荷情形，从净现值总成本、节点边际电价、弃电量以及最优投资构成（输电 vs 发电）等维度分析负荷带来的规划响应。
方法
  • 将发输电协同扩展规划表述为多年期、嵌入机组组合的混合整数线性规划（MILP）
  • 在修改的 IEEE 24 节点 RTS-24 系统上使用 ERCOT 校准的可再生能源出力曲线构造算例
  • 将 500 MW 数据中心负荷（约为基准年峰值的 17.5%）依据电压等级、发电裕度、可再生共址和网络连通性分配到四个母线
  • 以15年净现值总系统成本为目标，比较基准情形与加负荷情形下的最优投资方案、LMP 与弃电情况
实验
  • 在 RTS-24 加 ERCOT 校准可再生能源曲线算例上，加入 500 MW 数据中心负荷（约基准年峰值 17.5%）使15年净现值总系统成本上升 1,794 百万美元（+61.6%），系统平均节点边际电价上升 45.2%
  • 运行成本主导资本投资，占比为 84.2% 对 15.8%
  • 可再生能源弃电仍可忽略：既有可再生能源已接近满发利用，新增需求几乎全部由增量火电满足
  • 最显著的方案变化是负荷使最优规划从纯输电方案转为纯发电方案，用一个 400 MW 联合循环燃气轮机替代基准情形中的 230 kV 输电加固，表明合理选址的发电可替代网络加固
